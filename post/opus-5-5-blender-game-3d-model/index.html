클라우드 오퍼스 5.5와 블렌더로 게임 3D 모델 만드는 8단계 방법

2026-10-18 · 수정 2026-11-01 · 차하나 PD

클라우드 오퍼스 5.5와 블렌더를 연결해 게임용 3D 모델과 애니메이션을 만드는 과정을 단계별로 정리한 글입니다.

한눈에 보기

  • 오퍼스 5.5가 파이썬 코드를 작성하고, 블렌더에서 모델을 부분별로 구축합니다.
  • 모든 모델을 코드로 취급하는 것이 핵심입니다.
  • 최종 결과물은 리깅, 메쉬, 애니메이션 클립을 포함한 하나의 FBX 파일입니다.

주요 내용

  • 1단계 연결: 오퍼스 5.5를 블렌더 MCP를 통해 블렌더에 연결합니다.
  • 2단계 입력: 참조 이미지 2~3개와 간단한 브리프("구리 헬멧, 네이비 수트, 유리 탱크. 호스와 장갑은 분리해서 유지")를 전송합니다.
  • 3단계 구축: 부츠, 수트, 헬멧, 장갑, 탱크 순서로 부분별로 모델을 만듭니다.
  • 4단계 리깅: 별도의 스크립트에서 리깅하며, 호스, 로드, 탱크용 추가 뼈를 넣습니다.
  • 5단계 재질: 재질을 하나의 1024 텍스처 아틀라스로 베이킹합니다.
  • 6단계 애니메이션: idle, walk, capture 클립을 만듭니다.
  • 7단계 내보내기: 리깅, 메쉬, 모든 클립을 포함해 하나의 FBX로 내보냅니다.
  • 8단계 테스트: 엔진에서 확인하며, 백팩이 안정적으로 유지되고 유령을 포획할 때 호스가 붙어 있는지 점검합니다.

이렇게 활용해 보세요

  • 참조 이미지와 짧은 브리프만으로 시작해, 부위별로 나눠 모델링하는 방식을 따라 해 볼 수 있습니다.
  • 소품(호스, 로드, 탱크)은 본체 리깅과 분리된 스크립트에서 뼈를 추가해 관리하면 수정이 쉽습니다.
  • 재질은 텍스처 아틀라스 하나로 합쳐 두면 게임 엔진에서 불러오기가 간편합니다.
