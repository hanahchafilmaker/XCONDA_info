Opus 5.5 공개 일주일, GitHub 트렌딩 10개 중 8개가 영상·애니메이션… 코드로만 만든 영화 'OPUSCAR 98'

2026-10-01 · 박찬혁 감독

Claude Opus 5.5 공개 일주일 만에 GitHub 인기 레포의 대부분이 영상·애니메이션 쪽으로 쏠렸습니다. 43가지 영화 스타일을 코드만으로 구현한 Lemo-Opuscar와 98년 치 작품상 수상작을 6분 25초에 담은 'OPUSCAR 98'이 대표 사례로 소개됐습니다.

X(트위터) 크리에이터 鸟哥(@NFTCPS)가 Claude Opus 5.5 공개 후 일주일 만에 GitHub에서 벌어지고 있는 변화를 소개했습니다. 이번 주 가장 핫한 레포 10개를 살펴보니 8개가 비디오·애니메이션 관련이었다는 내용입니다.

어떤 활용이 나오고 있나

  • 뮤직비디오(MV) 제작
  • 단편 영화 제작
  • 한 줄 프롬프트로 3D 게임 제작

대표 사례: Lemo-Opuscar

  • 43가지 영화 스타일, 각각 코드만으로 완성한 단편으로 구성
  • 스타일을 고르고 내 이야기를 가져오면, 코딩 에이전트가 영화를 연출하는 방식
  • 새로 추가된 스타일: 동판화(Copperplate Engraving), SF 홀로그램 HUD, 1950년대 미드센추리 카툰, 실크스크린 여행 포스터

특별 상영작: OPUSCAR 98

  • 1927~2025년, 98년 치 작품상 수상작을 담은 6분 25초 영상
  • 캐릭터 Clawd 하나가 98편의 수상작을 차례로 지나가며, 각 작품을 그 영화에 어울리는 화풍으로 다시 그려냄
  • 모든 프레임, 음표, 컷 편집이 Claude Opus 5.5가 작성한 코드로 만들어짐

시사점

AI가 코드를 짜는 것을 넘어, 코드가 곧 영상 제작 도구가 되는 흐름이 뚜렷해지고 있습니다. 영상 제작 자동화에 관심 있는 크리에이터라면 참고해 볼 만합니다.
