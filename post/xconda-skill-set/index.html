저희가 실제 제작에 쓰는 Claude 스킬과 지침을 XCONDA 이용자 누구나 무료로 쓰실 수 있도록 묶었습니다. 시나리오를 컷으로 나누고, FLEXBOARD 프롬프트와 글콘티를 만들고, 씨댄스 영상 프롬프트까지 다듬는 과정을 Claude가 함께합니다. 모든 파일은 구글 드라이브에서 내려받으실 수 있습니다.

📦

XCONDA 스킬 3종 세트

  1. FLEXBOARD 스킬: 시나리오 → FLEXBOARD 프롬프트 + 글콘티
  2. 영상 프롬프트 편집기 지침 (v5.4): 시나리오 → 씨댄스 2.5 프롬프트, 한·영 2열 편집기
  3. FLEXBOARD 작성 규칙 문서: 글콘티·프롬프트·산출 문서 규격

시작 전에: FLEXBOARD 체험판

FLEXBOARD를 처음 쓰신다면 체험판에서 먼저 화면을 둘러보세요. 데모로 체험하는 판이라 직접 입력할 것이 없습니다.

👉 FLEXBOARD 체험판 열기

  1. 체험할 도구로 Flex Board를 고릅니다. (Blocking Board도 함께 체험할 수 있습니다.)
  2. 데모를 하나 고른 뒤, 화면 안내 순서대로 설정 채우기 → 에셋 채우기 → Generate Text Preview → Generate images를 눌러 봅니다.
  3. 점선 칸을 클릭하면 데모 내용이 자동으로 채워집니다.

체험판에서는 새 프로젝트 만들기, 레퍼런스 추가, 컷 수정, 영상 생성이 막혀 있습니다. 전체 기능은 XCONDA에서 쓰실 수 있습니다.

① FLEXBOARD 스킬

시나리오를 붙여 넣으면 Claude가 컷을 나누고 두 가지를 함께 만들어 줍니다.

  • FLEXBOARD 프롬프트: 씬 하나를 프롬프트 문서 하나로 정리합니다. FLEXBOARD에는 이것만 붙여 넣으면 됩니다.
  • 글콘티: 컷마다 길이, 카메라, 동작, 대사, 효과음, 레퍼런스(@에셋)를 적은 표입니다. 키 이미지가 의도대로 나왔는지 대조하거나 편집할 때 봅니다.

내려받기

  • 📦 스킬 파일 내려받기 (flexboard-script-prompt-v1.3.0.zip) · 드라이브에서 열기
  • 📄 설치 안내서 PDF (flexboard-skill-guide.pdf): 화면 캡처와 함께 설치 과정을 설명합니다.

설치 방법

  1. 위 링크로 flexboard-script-prompt-v1.3.0.zip을 내려받습니다. 내려받기가 안 되면 「드라이브에서 열기」를 누른 뒤 오른쪽 위 다운로드 버튼(↓)을 누르세요.
  2. Claude(claude.ai)에 로그인한 뒤 Customize > Skills로 들어갑니다.
  3. + 버튼을 누르고 Create skill > Upload a skill을 고릅니다.
  4. 내려받은 zip 파일을 압축을 풀지 말고 그대로 올립니다.
  5. 새 대화창에 시나리오를 붙여 넣고 "글콘티 만들어줘"라고 입력합니다. 시나리오 없이 스킬만 불러도 무엇을 준비하면 되는지 먼저 안내해 줍니다.

실제 제작에서 어떻게 쓰는지는 9컷의 저주, 지금 XCONDA로 줄이는 법: 컷이 튀지 않게 만드는 5단계 글의 3단계에서 보실 수 있습니다.

② 영상 프롬프트 편집기 지침 (v5.4)

시나리오를 씨댄스용 프롬프트로 바꿔 주는 XCONDA 프롬프트 편집기 지침입니다. 왼쪽 한국어만 고치면 오른쪽 영문이 따라오는 편집기 화면을 만들어 줍니다. 영어 프롬프트가 부담스러운 분께 특히 좋습니다.

내려받기

  • 📄 지침 파일 내려받기 (Xconda_prompt_guide_html_v5.4.txt) · 드라이브에서 열기

설치 방법

이 파일은 스킬이 아니라 프로젝트 지침으로 넣습니다. 설치 방법이 ①과 다릅니다.

  1. 위 링크로 지침 파일을 내려받습니다.
  2. Claude에서 새 프로젝트를 만듭니다.
  3. 내려받은 파일을 메모장으로 열고 내용을 전부 복사해(Ctrl+A → Ctrl+C) 프로젝트 지침에 붙여넣습니다.
  4. 그 프로젝트에서 새 대화를 열고 엑스콘다만 보냅니다. 모드 [1]~[8] 메뉴가 뜨면 설치된 것입니다.

⚠️

프로젝트 지침에는 이 파일 하나만 넣습니다. 다른 버전이나 다른 판의 지침이 함께 있으면 서로 부딪힙니다. 정리하면 ①은 Skills에, ②는 프로젝트 지침에 넣습니다.

편집기 화면 쓰는 법은 탁월한 선택, 영상 프롬프트 편집기 글에 화면과 함께 자세히 있습니다.

③ FLEXBOARD 작성 규칙 문서

①번 스킬이 어떤 규칙으로 글콘티와 프롬프트를 만드는지 정리한 문서입니다. 설치할 필요는 없습니다. 결과물을 이해하거나, 스킬 없이 직접 쓰거나 고칠 때 참고하세요.

문서내용
📄 글콘티 규격 (script_glconti.md)글콘티는 움직이는 1~5초의 설계도. 컷마다 적어야 할 항목과 형식
📄 프롬프트 작성 규칙 (prompt_writing.md)씬 하나에 프롬프트 하나, 다섯 블록 구조로 쓰는 규칙
📄 문서 산출 규격 (html_output.md)스킬이 내주는 파일 두 개(전체판·복사용)의 구성

어떤 순서로 쓰면 좋을까요

  1. 시나리오를 준비합니다.
  2. ① FLEXBOARD 스킬로 컷을 나누고 FLEXBOARD 프롬프트와 글콘티를 만듭니다.
  3. XCONDA FLEXBOARD에서 키 이미지를 뽑아 컷을 확인합니다.
  4. ② 프롬프트 편집기로 씨댄스 2.5 영상 프롬프트를 완성하고, XCONDA에서 영상을 생성합니다.
