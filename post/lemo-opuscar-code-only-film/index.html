영상 생성 AI 없이 코딩만으로 영화를 만든다는 오픈소스 프로젝트 Lemo-Opuscar를 소개하는 글입니다.

  • 영상 생성 AI를 쓰지 않고, 코드만으로 장면과 영상을 완성하는 오픈소스 프로젝트입니다.
  • Claude Opus 5.5가 직접 코드를 작성해 장면을 그리고, 움직임·음악·내레이션을 조합합니다.
  • 현재 59종의 스타일을 제공하며, 아카데미 작품상 수상작 98편을 재해석한 시연 영상을 공개했습니다.

주요 내용

Lemo-Opuscar는 영상 생성 AI를 사용하지 않는 것이 특징입니다. Claude Opus 5.5가 코드를 직접 작성해 장면을 그리고, 그 위에 움직임, 음악, 내레이션을 더해 영상으로 완성하는 방식입니다.

현재 제공하는 스타일은 59종입니다. 원문에는 80년대 일본 애니메이션, 16비트 픽셀 게임, 종이책 애니메이션, 3D 미니어처, 다큐멘터리 등이 예로 소개되어 있습니다.

프로젝트 측은 아카데미 작품상 수상작 98편을 각기 다른 스타일로 재해석한 6분 31초 분량의 시연 영상도 공개했습니다.
