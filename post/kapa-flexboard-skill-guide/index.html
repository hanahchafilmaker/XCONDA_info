2. 설치 방법

  1. 위 zip 파일을 내려받아 압축을 풉니다. 그러면 PDF 안내서와 flexboard-script-prompt-v1.3.0.zip이 나옵니다.
  2. 클로드(claude.ai)에 로그인한 뒤 Customize > Skills로 들어갑니다.
  3. + 버튼을 누르고 Create skill > Upload a skill을 고릅니다.
  4. flexboard-script-prompt-v1.3.0.zip을 압축을 풀지 말고 그대로 올립니다.
  5. 새 대화창에 시나리오를 붙여 넣고 "글콘티 만들어줘"라고 입력해 봅니다. 시나리오 없이 스킬만 불러도 무엇을 준비하면 되는지 먼저 안내해 줍니다.

⚠️

헷갈리기 쉬운 부분: 처음 받은 zip(가이드 묶음)은 풀어야 하고, 그 안에서 나온 스킬 zip은 풀지 않고 그대로 올립니다.

3. 참고 문서 3종

스킬이 어떤 규칙으로 글콘티와 프롬프트를 만드는지 정리한 문서입니다. 설치에는 필요 없고, 교육 중 결과물을 이해하거나 직접 고칠 때 참고하세요.

문서내용
글콘티 규격 (script_glconti.md)글콘티는 움직이는 1~5초의 설계도. 컷마다 적어야 할 항목과 형식
