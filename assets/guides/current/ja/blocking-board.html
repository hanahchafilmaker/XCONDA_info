— 概要 · ツール紹介 —

Blocking Boardが解決すること

映像を生成する前に俳優・空間・カメラが衝突しないかを確認するデジタルリハーサルツール。

1
PLAN / 平面図
位置・経路・小道具を整理します。
2
PREVIEW / 3D
シーンを再生して高さ・視線・衝突を確認します。
3
OUTPUT / カット
結果をタイムラインとプロンプトにつなげます。
— メモ 01 · 核心概念 —

映像を生成する前に、Blocking Boardは 俳優・空間・カメラが衝突しないかを確認することを 可能にします — デジタルリハーサルツールです。

— メモ 02 · 順序 —

平面図で位置と経路を設定し、3Dステージで高さと視線を検討します。結果はカット・タイムライン・プロンプトにつながります。

「回す前に視覚的に検討して調整する」

自動生成そのものより重要なのは、 検討可能な中間状態を作ることです.

台本→平面図→3Dステージ→カット / 出力

— インストール · ローカルWebアプリ —

アプリを実行して作業スペースを準備します

Blocking BoardはローカルWebアプリです。開始に必要なのはプロジェクトフォルダとブラウザだけです。

— ステップ 01 · 依存関係のインストール —

リポジトリのルートで次を実行します npm ci.

— ステップ 02 · ビルド —

npm run build — アプリバンドルをビルドします。 —

— ステップ 03 · ローカルサーバー —

node tools/static-server.js 8010 を実行し、 local server address をブラウザで開きます。

# リポジトリのルートで実行
$ npm ci
$ npm run build
$ node tools/static-server.js 8010

# ブラウザで開く
local server address

ファイルをダブルクリックして開くのではなく、ローカルHTTPサーバーを使ってください。

— 入力 · 1-Click —

台本を構造化して1-Clickでドラフトを生成

自然言語をステージデータに変えます。フィールドが明確なほど結果が安定します。

— ステップ 01 · 入力 —

サンプルを選んで入力形式を確認するか、台本を貼り付けます。動作は動詞で記述し、保持する姿勢と移動を区別します。

— ステップ 02 · 空間 —

空間設定を選びます。指定がなければ、シーンは空の空間から始まります。

— ステップ 03 · 1-Click —

1-Click で俳優・空間・経路・カメラのドラフトレイアウトを作成します。レポートで漏れと警告を確認してください。

— 注意 —

再実行すると、現在のシーンが新しい分析結果に置き換えられます。 まず保存してください。

Actors / Props
シーン内の主体
名前・体型・相互作用の対象を明確に指定します。
Camera
台数 · ショット · 動き

Time · Action
時間別アクション
「0〜3秒：キャラクター — アクション」形式を使います。

— ステージング · 空間 / 俳優 / 経路 —

空間を配置したうえで俳優と経路を置きます

自動配置は出発点にすぎません。空間を整え、俳優を置いたうえで、平面図に経路を描きます。

— ステップ 01 · 空間 —

左パネルで Add Objectを選択し、カテゴリを選んで壁・ドア・窓・家具を平面図に配置します。

— ステップ 02 · 俳優 —

俳優を配置し、名前・体型・開始位置・方向を指定します。

— ステップ 03 · 経路 —

平面図でウェイポイントをクリックして経路を描きます。 Enter で確定、 Esc でキャンセルします。

— ステップ 04 · 微調整 —

3Dツールでは、 E で移動 · R で回転 · T でサイズ調整。 平面図のグリッド1マス = 1 m — これをスケール基準として使います。 —

Chapter 07カメラ

07
— カメラ · マルチカム —

カメラとショットサイズを設計します

各カメラの役割を決め、ショットサイズ・画角・追跡対象・動きを設定します。

— メモ 01 · カメラ管理 —

カメラパネルで CAM1~4を管理します。各カメラごとにショットサイズ、画角（FOV）、追跡対象、動きを設定します。

— メモ 02 · ショットサイズ —

WIDE は俳優の全身を収め、 MEDIUM は会話を担当し、 CLOSE はリアクションを捉え、 OTS は肩越しビューに使用します。

— メモ 03 · パネル設定 —

レンズとFOV、追跡対象、カメラの動き、角度、高さZ（m）を確認します。

— Tip —

レンズの数値に悩む前に、 そのショットが何を見せるべきかをまず決めてください。.

— 時間 · カットとセリフ —

タイムラインにカットとセリフを配置します

カットは物語時間の単位です。俳優の動きとセリフが不自然に重ならないよう配置します。

— ステップ 01 · カット —

マスタータイムラインにカットを追加し、長さとカメラを設定します。カット間の空白区間と連続性の警告を確認します。

— ステップ 02 · セリフ —

セリフは別トラックで管理します。 誰がいつ話すかを確認し、 セリフをアクション区間に合わせます。

— ステップ 03 · 再生 —

下部タイムラインの再生・一時停止・スクラブを使います。特定のフレームで姿勢を確認し、全体の動きで衝突を検討します。

— メモ · FPSとカーブ —

FPSは最終映像の速度を、カーブは動きの速度の変化を調整します。

— まとめ · 締めくくり —

良いブロッキングは次の担当者に確信を与えます

台本から書き出しまで、一つのシーンを検討する手順のまとめ。

一つのシーンの順序

台本 → 空間 → 俳優 → カメラ → タイミング → チェック → 書き出し。問題が起きたら前のステップに戻って修正します。

シーンに入るとき

出来事とアクションを時間区間で書き、俳優・小道具・カメラに一貫した名前を使います。

検討するとき

平面図で経路を計画し、3Dでシーンを再生します。視線・衝突・連続性の警告を解消します。

渡すとき

レビュー後、英語プロンプト、ショットリスト、PNG、ショットブックPDFを書き出します。最終入力は「シーン / タイトル / 俳優 / 小道具 / カメラ / 時間 · アクション」の順序で構成します。
