처음 시작하는 AI 웹드라마 제작법

시나리오부터 완성된 1편까지를 하나의 흐름으로 만드는 방법. 이미지와 비디오를 따로 만드는 것이 아니라, 플렉스보드와 블로킹보드, 비디오제너레이터를 순서대로 연결해 1편을 완성합니다. 프롬프트 작성 상세 가이드와 같은 문서형으로 다시 썼습니다.

목차
  1. 1편 만들기란 — 시나리오부터 완성된 1편까지
  2. 기획·시나리오 — 1편의 뼈대를 정합니다
  3. 레퍼런스 확보 — 인물과 장소를 이미지로 고정합니다
  4. 텍스트 스토리보드 — 글 단계에서 컷을 확정합니다
  5. 스토리보드 이미지 — 컷마다 이미지로 확인합니다
  6. 블로킹보드 리허설 — 영상 생성 전에 동선을 검토합니다
  7. 비디오 생성 — 프롬프트 스킬로 컷 영상을 만듭니다
  8. 사운드·편집 — 1편으로 마무리합니다
  9. 1편 완성 체크리스트 — 보내기 전에 한 번 더 확인합니다
  10. 마무리 — 1편 만들기의 핵심 정리

1. 1편 만들기란 — 시나리오부터 완성된 1편까지

웹드라마 1편 만들기는 시나리오부터 완성된 1편까지를 하나의 흐름으로 만드는 일입니다. 큐브베리의 AI 영상 제작은 시나리오에서 시작해 XCONDA에서 영상을 만들고, 사운드를 입히고, 편집으로 마무리하는 7단계로 정리됩니다. 이 설명서는 그 7단계를 1편 만들기에 맞게 풀어쓴 것입니다.

단계내용주요 도구
01 준비시나리오 확정시나리오
02 준비레퍼런스 이미지 확보FlexBoard 스킬, GPT 이미지, Turn
03 준비텍스트 스토리보드FlexBoard
04 준비스토리보드 / 블로킹FlexBoard, Turn, Blocking Board
05 영상비디오 생성Video Generator (Seedance 등)
06 후반사운드사운드 도구
07 후반편집·마무리Premiere Pro
이 흐름은 이미 검증된 방식입니다. 큐브베리는 XCONDA의 Turn·FlexBoard·Blocking Board로 공간·캐릭터·동선을 관리해 KOCCA 콘텐츠랩 AI 웹드라마 4편(2026, 현역 감독 4팀)을 만들었습니다. 1편의 컷 수와 분량은 편별 기획에 따라 정합니다.

2. 기획·시나리오 — 1편의 뼈대를 정합니다

1편 만들기는 기획과 시나리오에서 시작합니다. 1편의 이야기, 등장인물, 장소를 정하고, 컷 구성을 나눕니다. 이 단계에서 인물과 장소가 정해지지 않으면 다음 단계의 레퍼런스를 만들 수 없습니다.

2-1. 기획 — 1편의 이야기·인물·장소 정하기

1편의 줄거리, 등장인물, 주요 장소를 정합니다. 인물마다 이름, 외모, 의상을 정합니다. 장소마다 공간의 특징(문·창문·가구 배치)을 정합니다.

2-2. 시나리오 — 시나리오 작성, 컷 나누기

시나리오를 쓰고 컷으로 나눕니다. 컷마다 누가, 어디서, 무엇을 하는지, 카메라가 어디에 있는지를 정합니다. 컷 수는 기획에 따라 정합니다. 플렉스보드는 6컷부터 36컷까지 스토리보드를 만들 수 있습니다.

2-3. 상태 장부 — 컷마다 이어져야 할 상태를 적어둡니다

인물의 의상·표정·부상 상태, 손에 든 소품, 주변 소품, 배경의 문·창문·가구 위치, 등장인물 수를 컷마다 적어둡니다. 이 장부가 뒤에서 컷 일관성을 지키는 기준이 됩니다. 비디오 AI는 이전 컷을 기억하지 않으므로, 사람이 단계마다 다시 지시해야 합니다.

시나리오에 캐릭터 이름을 넣어 AI가 얼굴과 의상 레퍼런스를 연결하게 합니다. 이름이 없으면 AI가 인물을 구분하지 못합니다.

3. 레퍼런스 확보 — 인물과 장소를 이미지로 고정합니다

시나리오가 정해지면 인물과 장소의 레퍼런스 이미지를 확보합니다. 인물마다 얼굴 이미지(캐릭터 시트), 장소마다 배경 이미지(배경 시트)를 만듭니다. 이 레퍼런스가 이후 모든 단계의 기준이 됩니다.

3-1. 캐릭터 시트 — 인물마다 얼굴 이미지

인물마다 얼굴 이미지를 만듭니다. GPT 이미지와 FlexBoard 스킬로 얼굴 레퍼런스를 확보합니다. 의상·표정·부상 상태도 함께 정합니다. 이 시트가 컷마다 같은 인물을 유지시키는 기준입니다. 시트 만드는 자세한 규칙(중립 회색 배경, 전신 숏다리 방지 5가지, 확인 질문)은 프롬프트 작성 상세 가이드를 봅니다.

3-2. 배경 시트 — 장소마다 배경 이미지

장소마다 배경 이미지를 만듭니다. Turn으로 만든 4면 배경 시트(정면·좌·우·후면)도 여기에 속합니다. 배경 시트가 컷마다 같은 공간을 유지시키는 기준입니다.

3-3. Turn 활용 — 필요하면 Turn으로 공간·컷 이미지 만들기

Turn으로 360° 가상 세트를 만들어 배경 시트를 만들거나, 세트 안에서 바로 컷 이미지를 뽑습니다. 자세한 Turn 흐름은 웹사이트 사용설명서의 Turn 챕터를 봅니다.

원칙: 인물과 장소가 정해지지 않으면 다음 단계의 레퍼런스를 만들 수 없습니다. 레퍼런스 확보를 건너뛰고 바로 생성하면 컷마다 인물과 장소가 바뀝니다. 레퍼런스 이미지는 에셋 라이브러리에 저장해 1편 내내, 다음 편에서도 재사용합니다.

4. 텍스트 스토리보드 — 글 단계에서 컷을 확정합니다

레퍼런스가 준비되면 플렉스보드에서 텍스트 스토리보드를 만듭니다. 시나리오를 컷별 지시문으로 나누고, 컷마다 글과 효과음을 씁니다. 글 단계에서 컷 순서와 구도를 확정하는 것이 크레딧을 아끼는 방법입니다.

4-1. 진입 — Flex Board 선택, 새 프로젝트

스토리보드 카테고리에서 Flex Board를 선택하고, 작업 공간에서 New Project로 새 프로젝트를 만듭니다.

4-2. 레퍼런스 연결 — 캐릭터·배경 레퍼런스 넣기

확보한 캐릭터 시트와 배경 시트를 프로젝트에 연결합니다. 이 레퍼런스가 컷마다 인물과 공간을 유지시킵니다.

4-3. 컷별 글 — 컷마다 지시문·효과음 작성

시나리오를 컷으로 나누고 컷마다 지시문을 씁니다. 텍스트 미리보기에서 컷 카드와 설명, 효과음을 확인합니다.

4-4. 확정 — 글 단계에서 컷 순서·구도 확정

텍스트 단계에서 컷 순서와 구도를 확정합니다. 이미지 생성 전에 글을 고치는 것은 크레딧이 들지 않습니다. 글 단계에서 충분히 다듬은 뒤에 이미지로 넘깁니다.

확인 순서: 컷 카드 → 컷 설명 → 효과음 → 컷 순서. 이 네 가지를 확인한 뒤에 이미지 생성으로 넘깁니다.

5. 스토리보드 이미지 — 컷마다 이미지로 확인합니다

텍스트 스토리보드가 확정되면 이미지를 생성합니다. 컷마다 이미지를 만들고, 구도·인물·배경이 맞는지 확인합니다. 마음에 안 드는 컷만 골라 고칩니다. 일관성은 두 엔진이 맡습니다. 배경은 Turn이, 캐릭터는 Art Director Pro가 지킵니다.

5-1. 이미지 생성 — 이미지 그리드, 컷별 대조

이미지를 생성하면 그리드에서 각 이미지를 설명과 대조합니다. 컷마다 구도·인물·배경이 맞는지 확인합니다.

5-2. 컷별 수정 — 안 맞는 컷만 골라 다시 만들기

마음에 안 드는 컷만 골라 프롬프트를 고쳐 다시 생성합니다. 컷 다시 만들기는 20 크레딧부터입니다. 같은 장면을 유지한 채 앵글이나 카메라 무빙만 바꾸고 싶으면 이미지를 드래그해 원하는 컷으로 교체합니다.

5-3. 단일 컷 수정이 더 쌀 때 — 키 이미지부터 고치기

안 맞는 컷이 있으면 프롬프트만 바꿔 여러 번 돌리기보다, 해당 장면의 키 이미지 하나를 고쳐 다시 넣는 것이 크레딧이 덜 듭니다.

일관성 엔진: Turn(AI VirtualSet)은 배경 일관성을 맡습니다. 사진 1장으로 만든 360° 세트 안에서 카메라를 돌려 앵글을 고르기 때문에 문·창문·가구 위치가 컷마다 유지됩니다. Art Director Pro는 캐릭터 일관성을 맡습니다. 4개의 AI 에이전트가 순서대로 검증·수정·전파하며, 의상·표정·부상 상태가 컷마다 이어집니다. 한 프레임을 바꾸면 나머지가 자동으로 따라옵니다.

6. 블로킹보드 리허설 — 영상 생성 전에 동선을 검토합니다

스토리보드 이미지가 확정되면, 복잡한 움직임 장면은 블로킹보드로 리허설합니다. 평면도에 배우와 카메라를 놓고 3D로 재생하며 인물·공간·카메라가 부딪히지 않는지, 시선이 맞는지 확인합니다. 리허설 없이 바로 생성하면 충돌·동선 오류를 뒤에서 고쳐야 합니다.

6-1. 1-Click — 시나리오를 붙이면 초안 생성

시나리오를 붙여넣으면 배우, 공간, 동선, 카메라 초안이 만들어집니다.

6-2. 2D 평면도 — 평면도에서 배치·동선 조정

2D 평면도에서 배우와 카메라 위치, 이동 경로를 조정합니다.

6-3. 3D 미리보기 — 3D 무대에서 재생 확인

3D 무대에서 장면을 재생하며 인물·카메라 움직임을 확인합니다.

6-4. 연출 점검 — 충돌·시선 검사, 문제 수정

연출 점검에서 충돌과 시선을 검사합니다. 문제가 나오면 평면도로 돌아가 배치·동선을 고칩니다. 여러 인물이 교차하는 장면은 이 단계에서 위치와 이동 경로를 미리 정하는 것이 권장됩니다.

6-5. 내보내기 — 프롬프트·샷 리스트·샷북으로 내보내기

검토가 끝난 장면은 영어 프롬프트(Seedance용), 샷 리스트, 평면도와 프레임 PNG, 샷북 PDF로 내보낼 수 있습니다. 장면을 재생해 프리비즈 영상(WebM)으로도 내보낼 수 있습니다.

블로킹보드는 웹사이트에서 무료 베타로 쓸 수 있고, 카드가 필요 없습니다. 자세한 블로킹보드 사용법은 별도 블로킹보드 가이드(13챕터)를 봅니다.

7. 비디오 생성 — 프롬프트 스킬로 컷 영상을 만듭니다

스토리보드와 리허설이 확정되면 비디오제너레이터로 컷 영상을 생성합니다. 핵심은 프롬프트입니다. 상태 장부를 프롬프트에 그대로 옮기고, 키 이미지를 기준으로 생성합니다. Seedance 프롬프트는 최대 30,000자까지 들어가므로 길이는 걱정하지 않아도 됩니다.

7-1. 프롬프트 스킬 — 키 이미지 기준 프롬프트 생성

XCONDA 프롬프트 스킬은 키 이미지를 기준으로 Seedance용 프롬프트를 만듭니다. 4감독 체계와 10블록 구조로 정리되어 있고, 한국어와 영어를 나란히 보며 편집할 수 있습니다. 상태 장부 내용을 한국어로 넣고, 영어 문장이 맞게 번역되었는지 확인합니다. 프롬프트 작성의 자세한 규칙은 프롬프트 작성 상세 가이드를 봅니다.

7-2. 모델·옵션 — 모델과 비율·해상도·길이·고화질 선택

Seedance 2.5 기준 한 번에 최대 30초, 1080p까지 만들 수 있습니다. 옵션에서 화면 비율, 해상도, 길이, 고화질을 정합니다. 전체 모델 사양표는 웹사이트 사용설명서의 비디오제너레이터 챕터를 봅니다.

7-3. 컷별 생성·확인 — 컷마다 생성하고 일관성 확인

컷마다 생성하고, 인물·공간·상태가 이어지는지 확인합니다. 안 맞는 컷이 있으면 해당 장면의 키 이미지부터 고쳐 다시 생성합니다.

컷 일관성 5단계: ① 공간은 Turn으로 고정한다 ② 인물·구도는 FlexBoard로 고정한다 ③ 이어져야 할 상태는 레퍼런스와 프롬프트로 넘긴다 ④ 상태 장부를 프롬프트에 그대로 옮긴다 ⑤ 보내기 전에 한 번 더 검토한다. 이 순서를 지키면 컷마다 인물과 장소가 바뀌는 문제를 줄일 수 있습니다.

8. 사운드·편집 — 1편으로 마무리합니다

컷 영상이 완성되면 사운드를 입히고 편집해 1편으로 마무리합니다. 큐브베리의 제작 흐름은 XCONDA에서 영상을 만들고, 사운드를 입히고, Premiere Pro에서 편집으로 마무리하는 순서입니다.

8-1. 사운드 — 음악·효과음 입히기

컷마다 음악과 효과음을 입힙니다. 텍스트 스토리보드 단계에서 정한 효과음을 기준으로 맞춥니다.

8-2. 편집 — 컷을 이어 1편으로

생성된 컷 영상을 순서대로 이어 1편으로 편집합니다. Premiere Pro에서 마무리합니다.

8-3. 다듬기 도구 — 필요하면 웹사이트 도구로 다듬기

얼굴 교체가 필요하면 Face Swap, 의상 교체는 ClothSwap, 표정 변환은 Expression Transformer, 화질 보강은 AI Upscaler(최대 4배), 색감 통일은 CineGrade AI를 씁니다. 다듬은 뒤에는 캐릭터 일관성 확인을 다시 거칩니다.

편집·마무리 단계에서 수정 요청이 나오면, 편집자가 수정하고 다시 생성하는 사이클을 반복합니다. 만족할 때까지 이 사이클을 돌립니다.

9. 1편 완성 체크리스트 — 보내기 전에 한 번 더 확인합니다

1편을 완성하기 전에 아래 항목을 확인합니다. 이 체크리스트는 큐브베리 제작 현장에서 실제로 쓰는 검토 항목입니다. 하나라도 어긋나면 해당 컷부터 고칩니다.

  • 모든 컷에서 등장인물 수가 맞는가
  • 의상의 색상·단추·소매가 컷마다 같은가
  • 손에 든 소품과 주변 소품이 바뀌지 않았는가
  • 배경의 창문·문·가구 위치가 컷마다 같은가
  • 인물의 표정·부상 상태가 이어지는가
  • 컷 순서와 숏 길이·카메라 무빙이 의도와 맞는가
  • 빠진 컷이 없는가
  • 상태 장부가 프롬프트에 그대로 옮겨졌는가
  • 키 이미지와 생성 영상이 대조되는가
  • 사운드(음악·효과음)가 컷에 맞게 들어갔는가
  • 편집본이 1편으로 이어지는가
  • Turn 세트·캐릭터 시트·배경 시트가 라이브러리에 저장되었는가 (다음 편 재사용)
안 맞는 컷이 있으면 프롬프트만 바꿔 여러 번 돌리기보다, 해당 장면의 키 이미지 하나를 고쳐 다시 넣는 것이 크레딧이 덜 듭니다. 복잡한 움직임 장면은 블로킹보드로 다시 검토합니다.

10. 마무리 — 1편 만들기의 핵심 정리

웹드라마 1편 만들기의 핵심은 순서입니다. 시나리오 → 레퍼런스 → 텍스트 스토리보드 → 스토리보드/블로킹 → 비디오 생성 → 사운드 → 편집. 이 순서를 지키면 컷마다 인물과 장소가 바뀌는 문제를 줄이고, 크레딧을 아낄 수 있습니다.

10-1. 핵심 원칙 — 기억은 AI에 맡기지 않는다

비디오 AI는 이전 컷을 기억하지 않습니다. 공간은 Turn으로, 인물·구도는 FlexBoard로, 이어져야 할 상태는 레퍼런스와 프롬프트로 사람이 직접 고정합니다.

10-2. 에셋 — 만든 것은 라이브러리에 저장한다

캐릭터 시트, 배경 시트, Turn 세트, 키 이미지, 스토리보드 프로젝트를 라이브러리에 저장해 다음 편에 재사용합니다. 에셋이 쌓일수록 다음 편이 빨라집니다.

10-3. 다음 편 — 1편의 에셋으로 2편을 시작한다

다음 편은 1편의 캐릭터 시트·배경 시트·Turn 세트를 그대로 불러와 시작합니다. 인물과 장소가 이미 고정되어 있으므로, 새 편은 시나리오와 컷 구성에만 집중하면 됩니다.
