A single workflow from script to finished episode. Rather than creating images and videos separately, connect FlexBoard, Blocking Board, and Video Generator in order to complete an episode. This guide has been rewritten in the same detailed text format as the Prompt Writing Guide.

1. What goes into an episode — from script to finished production

Producing an episode of a web drama means connecting everything from the script to the finished episode into one workflow. CUBEBERRY’s AI video production process can be summarized in seven stages: start with a script, create video in XCONDA, add sound, and finish with editing. This guide explains those seven stages as a practical episode-production workflow.

This workflow has already been tested in production. Using XCONDA’s Turn, FlexBoard, and Blocking Board to manage spaces, characters, and movement paths, CUBEBERRY produced four KOCCA Content Lab AI web dramas (2026, with four teams of working directors). The number of cuts and the running time of an episode are determined by the plan for that episode.

2. Planning and script — establish the episode’s foundation

Episode production begins with planning and the script. Decide the story, characters, and locations, then break the episode into cuts. If the characters and locations are not established at this stage, you cannot create the references needed for the next stage.

2-1. Planning — define the story, characters, and locations

Define the episode’s plot, characters, and main locations. Give each character a name, appearance, and costume. For each location, define the characteristics of the space, including the placement of doors, windows, and furniture.

2-2. Script — write the script and divide it into cuts

Write the script and break it into cuts. For each cut, decide who is doing what, where they are, and where the camera is positioned. The number of cuts depends on the production plan. FlexBoard can create storyboards containing 6 to 36 cuts.

2-3. Continuity ledger — record the states that must carry across cuts

For each cut, record the characters’ costumes, expressions, and injury states; props held in their hands; surrounding props; the positions of doors, windows, and furniture in the background; and the number of characters present. This ledger becomes the reference for maintaining continuity in later cuts. Video AI does not remember the previous cut, so a person must specify these details again at each stage.

Include character names in the script so the AI can connect the face and costume references. Without names, the AI cannot distinguish the characters.

3. Prepare references — establish characters and locations as images

Once the script is settled, prepare reference images for the characters and locations. Create a facial image—a character sheet—for each character and a background image—a background sheet—for each location. These references become the basis for every later stage.

3-1. Character sheets — a facial image for each character

Create a facial image for each character. Use GPT Image and the FlexBoard skill to prepare facial references. Establish the costume, expression, and injury state at the same time. This sheet is the reference that maintains the same character across cuts. For detailed sheet-creation rules—a neutral gray background, five rules to prevent shortened legs in full-body shots, and confirmation questions—see the Prompt Writing Guide.

3-2. Background sheets — a background image for each location

Create a background image for each location. This includes four-sided background sheets made with Turn: front, left, right, and rear. The background sheet is the reference that maintains the same space across cuts.

3-3. Using Turn — create spaces and cut images when needed

Use Turn to create a 360° virtual set and derive background sheets from it, or extract cut images directly inside the set. For the detailed Turn workflow, see the Turn chapter in the Website User Manual.

Principle: until the characters and locations are established, you cannot create the references needed for the next stage. If you skip reference preparation and generate immediately, the characters and locations may change from cut to cut. Save reference images in the Asset Library and reuse them throughout the episode and in subsequent episodes.

4. Text storyboard — finalize cuts at the writing stage

Once the references are ready, create a text storyboard in FlexBoard. Divide the script into instructions for individual cuts and write the text and sound effects for each cut. Finalizing the cut order and composition at the writing stage saves credits.

4-1. Enter — select Flex Board and create a new project

Select Flex Board in the Storyboard category, then create a new project using New Project in the workspace.

4-2. Connect references — add character and background references

Connect the prepared character sheets and background sheets to the project. These references keep the characters and space consistent across cuts.

4-3. Text for each cut — write instructions and sound effects

Divide the script into cuts and write instructions for each one. In the text preview, check the cut cards, descriptions, and sound effects.

4-4. Finalize — establish cut order and composition in text

Finalize the cut order and composition at the text stage. Revising text before image generation does not consume credits. Refine the text thoroughly before moving on to images.

Check in this order: cut cards → cut descriptions → sound effects → cut order. Complete these four checks before moving on to image generation.

5. Storyboard images — check every cut visually

Once the text storyboard is finalized, generate the images. Create an image for each cut and check the composition, characters, and background. Revise only the cuts you are unhappy with. Two engines handle consistency: Turn protects the background, while Art Director Pro protects the characters.

5-1. Image generation — compare each image in the grid

After generating images, compare each image in the grid with its description. Check whether the composition, characters, and background are correct for each cut.

5-2. Revise individual cuts — regenerate only what does not work

Select only the cuts you are unhappy with, revise their prompts, and generate again. Recreating a cut starts at 20 credits. To keep the same scene while changing only the angle or camera movement, drag an image to replace the intended cut.

5-3. When revising a single cut is cheaper — correct the key image first

If a cut is wrong, correcting and reusing one key image for that scene can use fewer credits than repeatedly running generations with only the prompt changed.

Consistency engines: Turn (AI VirtualSet) handles background consistency. Because you choose angles by moving the camera inside a 360° set created from one photograph, the positions of doors, windows, and furniture remain consistent across cuts. Art Director Pro handles character consistency. Four AI agents validate, revise, and propagate changes in sequence, carrying costumes, expressions, and injury states across cuts. Change one frame and the others automatically follow.

6. Blocking Board rehearsal — review movement before video generation

Once the storyboard images are finalized, rehearse scenes with complex movement in Blocking Board. Place actors and cameras on a floor plan and play back the scene in 3D to check that people, the space, and cameras do not collide and that eyelines match. If you generate without rehearsing, you will have to correct collisions and movement errors later.

6-1. 1-Click — paste a script to create a draft

Paste in a script to create a draft of the actors, space, movement paths, and cameras.

6-2. 2D floor plan — adjust placement and movement paths

Adjust actor and camera positions and movement routes in the 2D floor plan.

6-3. 3D preview — check playback on the 3D stage

Play back the scene on the 3D stage and review character and camera movement.

6-4. Direction checks — inspect collisions and eyelines, then correct issues

Inspect collisions and eyelines in the direction review. If a problem appears, return to the floor plan and correct the placement or movement paths. For scenes in which multiple characters cross paths, it is recommended that you establish positions and movement routes at this stage.

6-5. Export — prompts, shot lists, and shot books

Reviewed scenes can be exported as English prompts for Seedance, a shot list, floor plans and frame PNGs, and a shot book PDF. You can also play back the scene and export a previsualization video in WebM format.

Blocking Board is available as a free beta on the website, with no card required. For detailed instructions, see the separate 13-chapter Blocking Board guide.

7. Video generation — create cut videos with the prompt skill

Once the storyboard and rehearsal are finalized, generate the cut videos with Video Generator. The key is the prompt. Transfer the continuity ledger directly into the prompt and generate using the key image as the reference. Seedance prompts accept up to 30,000 characters, so prompt length need not be a concern.

7-1. Prompt skill — generate a prompt based on the key image

The XCONDA prompt skill creates prompts for Seedance based on key images. It is organized around a four-director framework and a ten-block structure, and lets you edit while viewing Korean and English side by side. Enter the continuity ledger information in Korean and check that the English sentences have been translated correctly. For detailed prompt-writing rules, see the Prompt Writing Guide.

7-2. Model and options — choose the model, aspect ratio, resolution, duration, and quality

With Seedance 2.5, you can generate up to 30 seconds at up to 1080p in one run. Set the aspect ratio, resolution, duration, and high-quality option. For the full model specifications table, see the Video Generator chapter in the Website User Manual.

7-3. Generate and review each cut — check continuity

Generate each cut and check whether the characters, space, and states carry through correctly. If a cut does not match, correct that scene’s key image first and generate again.

Five stages of cut consistency: ① Establish the space with Turn. ② Establish the characters and composition with FlexBoard. ③ Carry the required states forward through references and prompts. ④ Transfer the continuity ledger directly into the prompt. ⑤ Review once more before sending. Following this order helps reduce changes in characters and locations from cut to cut.

8. Sound and editing — finish the episode

Once the cut videos are complete, add sound and edit them into a finished episode. CUBEBERRY’s production flow is to create video in XCONDA, add sound, and finish editing in Premiere Pro.

8-1. Sound — add music and sound effects

Add music and sound effects to each cut. Match them to the sound effects established at the text-storyboard stage.

8-2. Editing — connect the cuts into one episode

Arrange the generated cut videos in sequence and edit them into one episode. Complete the finishing work in Premiere Pro.

8-3. Refinement tools — use the website’s tools as needed

Use Face Swap for face replacement, ClothSwap for costume replacement, Expression Transformer for expression changes, AI Upscaler for image-quality enhancement (up to 4×), and CineGrade AI to unify color. After refinement, check character consistency again.

If revision requests arise during editing and finishing, repeat the cycle in which the editor makes changes and the affected content is regenerated. Continue this cycle until the result is satisfactory.

9. Episode completion checklist — check again before delivery

Before completing the episode, check the following items. This checklist reflects the review items used in CUBEBERRY’s actual production work. If any item fails, correct the work starting with the affected cut.

  • Is the number of characters correct in every cut?
  • Are costume colors, buttons, and sleeves the same across cuts?
  • Have the props held by characters and the surrounding props remained unchanged?
  • Are the positions of background windows, doors, and furniture consistent across cuts?
  • Do the characters’ expressions and injury states carry through correctly?
  • Do the cut order, shot duration, and camera movement match the intended direction?
  • Are any cuts missing?
  • Has the continuity ledger been transferred directly into the prompts?
  • Have the key images been compared with the generated videos?
  • Has the sound—music and effects—been matched to the cuts?
  • Does the edit form one coherent episode?
  • Have the Turn sets, character sheets, and background sheets been saved to the library for reuse in the next episode?
If a cut is wrong, correcting and reusing one key image for that scene can use fewer credits than repeatedly running generations with only the prompt changed. Review complex movement scenes again in Blocking Board.

10. Summary — the essentials of producing an episode

The key to producing a web drama episode is the order of operations: script → references → text storyboard → storyboard/blocking → video generation → sound → editing. Following this order helps reduce changes in characters and locations between cuts and saves credits.

10-1. Core principle — do not rely on AI to remember

Video AI does not remember the previous cut. A person must establish the space with Turn, the characters and composition with FlexBoard, and the states that must carry forward through references and prompts.

10-2. Assets — save what you create to the library

Save character sheets, background sheets, Turn sets, key images, and storyboard projects to the library and reuse them in the next episode. The more assets you accumulate, the faster the next episode becomes.

10-3. The next episode — start episode 2 with assets from episode 1

Start the next episode by loading the character sheets, background sheets, and Turn sets from episode 1. Because the characters and locations are already established, you can focus on the script and cut structure for the new episode.
