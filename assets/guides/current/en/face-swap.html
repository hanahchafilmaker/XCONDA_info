— Purpose —

What does Face Swap do?

It replaces a specific face in an original image with another face. The background, outfit, pose, lighting, and framing are kept as intact as possible, so you can quickly change only the impression of the person's face.

— Use Cases —

Why use it, and when?

Use it to compare casting candidates, model looks, or character faces in the same shot without reshooting. It saves time on work that needs quick results, such as ad drafts, lookbooks, and video storyboards.

01

Comparing casting candidates

When comparing casting candidates, model looks, or character faces in the same shot without reshooting.

02

Keep the pose and outfit, change the face

When you like the pose and outfit in the existing image but need to change only the face.

03

Replacing a reference

When replacing a reference that is sensitive for portrait rights, or when comparing different actor/model versions within a single scene.

Chapter 15Share and delete confirmation
P. 015
15
— Confirm Dialogs —

Share and delete confirmation

Sharing and deleting each go through a confirmation popup to prevent mistakes.

— Public share —

Share confirmation popup

Pressing the external-link icon shows a popup asking whether to share the media publicly. OK proceeds with the share, and Cancel closes without sharing.

— Delete —

Delete confirmation popup

Pressing the trash icon asks whether to delete the selected result media. Only press OK if the result needs to be deleted; if it should be kept, press Cancel.
