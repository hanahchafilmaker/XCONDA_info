쉽게 정리한 게시 원칙 Quick Guide

Notion에 글을 쓰고 Published(공개)를 체크하면 사이트에 반영됩니다. 잊기 쉬운 핵심만 모았습니다.

01새 행 추가Notion DB에서 새 페이지 만들기
02필수값 입력Title · Type · Date
Published는 OFF
03본문 작성헤딩 · 목록 · 이미지·토글
04게시 승인검수 끝난 뒤
Published 체크
05사이트 확인약 10분 내 반영
지연 시 수동 실행
💡
Published는 '저장'이 아니라 '공개 승인'입니다.
Notion은 입력하는 즉시 저장됩니다. Published 체크 전까지는 사이트에 나타나지 않으니, 제목·본문·이미지를 모두 검수한 뒤 마지막에 체크하세요.

1. 꼭 채워야 할 값

  • Title 필수 — 글 제목. 중요한 단어를 앞쪽에.
  • Type 필수 — 공지 · 뉴스 · 가이드 · 블로그 · FAQ 중 하나. 노출 섹션을 결정합니다.
  • Date 필수 — 실제 게시일. 정렬 기준이 됩니다.
  • Published 필수 — 검수 완료 후 ON. OFF면 사이트에 노출되지 않음.
  • Summary — 목록 카드에 보일 1~2문장 요약. FAQ는 짧은 답변.
  • Cover — 목록 썸네일 이미지(외부 https:// URL 권장). 비우면 노션 커버→본문 첫 이미지 순서로 자동 사용.

2. Changes(변경사항) 쓰기 — 뉴스/업데이트용

한 줄이 한 항목이 됩니다. 줄 맨 앞에 종류 태그를 붙이세요.

[New] Turn 스튜디오 추가 - 360도 공간 고정 기능 [Improved] Director's Cut 생성 속도 30% 개선 [Fixed] 모바일에서 모달 스크롤 버그 수정
  • 태그: [New] 신규 [Improved] 개선 [Fixed] 수정 (또는 [신규] [개선] [수정])
  • 태그는 줄 맨 앞에 써야 종류로 인식됩니다.
  • 태그가 없으면 기본으로 개선(Improved)이 됩니다.
  • 영문은 Changes EN에 따로 작성하세요.

3. 긴급 공지 설정 (장애·점검·결제 영향 등)

Type공지
PinnedON ✓
ImportantON ✓
Date오늘
PublishedON ✓

게시 순서: 제목에 영향 범위·상태 명시 → Summary에 사용자 행동 → 본문에 시작 시각·영향·대응 → Pinned+Important+Published → 수동 동기화 → 사이트 확인

⚠️
Pinned는 꼭 필요한 항목만 유지하세요. 여러 공지가 고정되어 있으면 날짜가 최신인 고정 공지가 먼저 노출됩니다.

4. 이미지 · 링크 운영

  • 장기 노출 이미지는 외부 공개 https:// URL 사용. Notion에 직접 올린 파일은 URL이 만료되어 깨질 수 있습니다.
  • 썸네일은 Cover → 노션 페이지 커버 → 본문 첫 이미지 순서로 자동 결정됩니다.
  • 공유 링크는 상세 모달의 공유 버튼으로 복사(#post=페이지ID). 미공개 글은 링크로도 열리지 않습니다.

5. 게시 전·후 체크리스트

게시 전

  • Title이 짧고 구체적인가
  • Type이 올바른 섹션인가
  • Date가 실제 공개일인가
  • Summary만으로 핵심이 전달되는가
  • 본문 헤딩·목록·링크·이미지 검수 완료
  • 업데이트면 Changes가 한 줄 한 항목인가
  • 긴급 공지면 Pinned+Important 체크
  • 모든 검수 끝난 뒤 Published ON

게시 후

  • Actions 동기화 성공했는가
  • 올바른 섹션·순서에 나타나는가
  • 목록 제목·요약·날짜 정상인가
  • 상세 모달 본문·이미지·링크 정상인가
  • 이미지·외부 링크가 새 창에서 열리는가
  • 모바일에서도 읽기 편한가

안 보일 때

  • Published 체크 확인
  • Title·Type·Date 입력 확인
  • Actions 최근 실행이 초록색인가
  • 지연이면 Actions → 수동 실행
  • 목록과 상세 모달 재확인
🔎
가장 빠른 진단: ① Published → ② Title/Type/Date → ③ Actions 최근 실행 초록색 확인 → ④ 사이트 새로고침 → ⑤ 목록·상세 재확인.
ℹ️
반영 시간: 자동 동기화는 약 10분(외부 스케줄러 설정 시)부터 수 시간(GitHub 기본 스케줄)까지 걸릴 수 있습니다. 급하면 GitHub Actions → Notion 동기화 → Run workflow ↗를 수동 실행하세요(약 2분).
