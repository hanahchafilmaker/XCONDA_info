Make.com + Buffer 연동 가이드 Quick Guide

Notion에 공지를 올리면 Make 시나리오가 실행되어 X(트위터)와 인스타그램에 자동 업로드됩니다. 확인 필수 항목만 모았습니다.

01Notion 작성Type=공지 · Published ON
Title · OG 이미지 입력
02Make 시나리오 실행us2.make.com 시나리오 6736108
X · 인스타 동시 업로드 시도
03Buffer 업로드suggestions.buffer.com으로 전송
예약 또는 즉시 발행
04SNS 배포됨 체크Notion에서 자동 체크(V)
수동 확인 필요 시 처리
05결과 확인X 업로드 확인 완료
인스타그램 연동 확인 필요
💡
확인 필수: X는 자동 업로드 확인 완료. 인스타그램은 프로페셔널 계정이 에이콘다로 설정되어 있어 연동 확인이 필요합니다.

1. Notion 필드 설정 (공지 작성 시)

Type공지
Published체크(true) ✓
SNS 배포됨미체크(false) → 자동 배포 후 체크(V)
Title입력 필수
OG 이미지입력 필수

Notion에 공지를 등록한 후 Make 시나리오가 트리거되면 X와 인스타그램에 글이 올라갑니다.

2. 플랫폼별 연동 현황

X (트위터)

확인 완료 자동 업로드 정상 동작함.

인스타그램

확인 필요 프로페셔널 계정이 에이콘다로 되어 있음. 연동 상태 확인 후 처리.

⚠️
인스타그램 연동이 완료되지 않으면 해당 게시물은 인스타에 올라가지 않습니다. 누락 건은 수동으로 업로드하세요.

3. 관련 링크

  • Make.com 시나리오 편집 ↗ — 시나리오 실행 이력 및 모듈 설정 확인
  • Buffer 제안함 ↗ — 업로드 대기 중인 콘텐츠 확인

4. 확인 체크리스트

  • Notion에 Type=공지, Published=ON, SNS 배포됨=미체크 상태인가
  • Title과 OG 이미지가 입력되었는가
  • Make 시나리오가 정상 실행되었는가 (에러 이력 확인)
  • X에 글이 정상 업로드되었는가
  • 인스타그램 연동이 정상인가 (에이콘다 프로페셔널 계정 확인)
  • Notion의 SNS 배포됨 체크박스가 자동으로 V 처리되었는가
  • 누락된 플랫폼이 있으면 수동으로 업로드했는가
ℹ️
문의: 나서영(기획) 기획자님. 다른 연동이 필요한 플랫폼이 있다면 알려 주세요.
