이미지 프롬프트는 몇 자까지 쓰는 게 좋나요?

2026-11-12 · 수정 2026-11-12

이미지 프롬프트는 영어 기준 약 600자 이내로 쓰는 것을 권장합니다. 이미지 생성 모델을 제공하는 BytePlus의 권장 사항이며, 프롬프트가 이보다 길어지면 모델이 세부 내용을 지나치게 따지면서 이미지 품질이 떨어질 수 있습니다. 강제로 막는 제한이 아니라 권장 기준입니다.

핵심(누구가, 어디서, 무엇을 하는지, 분위기)을 먼저 쓰고, 세부 묘사는 결과를 확인한 뒤 수정하면서 하나씩 더하는 방식이 좋습니다.

예시: "A young woman in a red coat standing on a rainy Seoul street at night, neon signs reflected on wet pavement, cinematic mood."

출처: BytePlus ModelArk 이미지 생성 API 문서 (https://docs.byteplus.com/en/docs/modelark/image-generation-api)
