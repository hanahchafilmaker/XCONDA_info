FLEXBOARD로 컷별 스토리보드 만들기 7단계 (AI 영상제작 과정 EP.03)

2026-10-19 · 김재환 PD

시나리오를 컷별 스토리보드로 만들고, 문제 있는 컷만 골라 고친 뒤 시댄스(Seedance) 2.5로 넘기는 FLEXBOARD 사용법을 7단계로 정리했습니다.

이 글에서 배우는 것: 시나리오를 컷별 스토리보드로 만들고, 문제 있는 컷만 골라 고친 뒤 시댄스(Seedance) 2.5로 넘기는 방법

이런 분께: AI 영상을 처음 만들어 보는 분, 영상을 돌리다 크레딧을 낭비한 경험이 있는 분

준비물: XCONDA 계정과 크레딧, 시나리오 한 장면, (있다면) Turn으로 만든 배경 이미지. 이미지 생성과 재생성 버튼에는 필요한 크레딧이 화면에 표시됩니다.

이 글은 "AI 영상제작 과정" 연재 중 스토리보드 편입니다. 지난 글 「XCONDA Turn으로 360도 세트 만들기」에서 만든 배경과 키 이미지를 여기서 사용합니다.

FLEXBOARD는 어디에 있나요

XCONDA 왼쪽 메뉴에서 Studio로 들어가 Storyboard를 열면 FLEXBOARD 카드가 보입니다. "시댄스 2.5에 최적화된 스토리보드 도구"라고 적힌 카드입니다. 카드를 누르고 New Project를 선택하면 시작합니다.

1단계: 프로젝트 설정

화면 위쪽에 작업 단계가 세 개의 버튼으로 표시됩니다.

  1. Project settings: 프로젝트 기본 설정
  2. Scene Settings: 시나리오, 인물과 배경, 컷 수 설정
  3. Edit Panel: 만들어진 컷을 보고 고치기

이 글의 1~5단계가 앞의 두 버튼, 6~7단계가 Edit Panel에 해당합니다. 먼저 세 가지를 정합니다.

  • 작업 방식
  • 이미지 모델: 화면 왼쪽 위 드롭다운에서 컷 이미지를 그릴 모델을 고릅니다. 현재 고를 수 있는 모델은 네 가지입니다.
  • 프로젝트 이름: 나중에 목록에서 찾기 쉬운 이름으로 적습니다. 예: "웹드라마_1화_대청마루씬"

2단계: 시나리오, 장르, 분위기 적기

Scenario 칸에 장면을 적습니다. "누가, 어디서, 무엇을, 어떤 감정으로"가 들어가면 컷을 검토하기 쉬워집니다. 일이 여러 개 일어나면 순서대로 적습니다.

예를 들면 이렇습니다.

비 오는 밤, 한옥 대청마루. 수연이 깨진 도자기 조각을 들고 서 있다. 대문 쪽에서 발소리가 들리고, 수연은 조각을 등 뒤로 숨긴다. 문이 열리고 어머니가 들어온다. 두 사람은 말없이 서로를 바라본다.

그다음 Genre(예: Suspense)와 Tone / Mood(예: Tense)를 고르고 Save project로 저장합니다.

3단계: 인물과 배경 등록하기 (Reference Assets)

컷이 바뀌어도 같은 인물, 같은 장소가 나오게 하는 단계입니다. Reference Assets 영역에 Cast(인물) 카드와 Background(배경) 카드를 등록합니다.

  1. Add Cast를 눌러 인물 카드를 만듭니다. 카드마다 @image1, @image2 같은 이름표(토큰)가 자동으로 붙습니다.
  2. 카드에 얼굴 이미지와 알아보기 쉬운 이름을 넣습니다. 예: 수연, 어머니
  3. 반복해서 나오는 소품도 카드로 등록할 수 있습니다. 예: 깨진 도자기
  4. 배경 카드(Background)를 추가합니다. 지난 글에서 Turn으로 만든 공간 이미지를 여기에 넣으면 좋습니다.

토큰이 하는 일: 컷 설명 안에 "@image1"처럼 표시되어, 이 컷에 누가 나오는지 한눈에 보입니다. 영상 프롬프트에서도 같은 방식으로 인물을 가리키게 됩니다.

주의: 인물은 한 사람당 카드 하나로 등록하세요. 카드를 교체하거나 지운 뒤에는 토큰 번호와 컷 설명이 여전히 맞는지 다시 확인해야 합니다.

4단계: 컷 수와 컷 길이 정하기

  • Number of Panels: 컷 수를 정합니다. 화면 예시는 9컷입니다.
  • Shot Length: 컷 하나의 길이를 정합니다. 4초에서 30초 사이로 조절할 수 있습니다.

예를 들어 9컷 × 15초로 설정하면 단순 합계는 약 2분 15초입니다. 실제 완성 길이는 이후 영상 작업에 따라 달라질 수 있습니다.

컷 수는 장면이 바뀌는 지점을 기준으로 정하세요. 위 예시라면 "도자기를 든 수연 / 발소리 / 숨기는 손 / 문이 열림 / 어머니 등장 / 마주 보는 두 사람"처럼 나눌 수 있습니다.

5단계: 이미지보다 글로 먼저 확인하기 (Text Preview)

화면 아래 노란 Text Preview Generate 버튼을 누르면, 이미지를 만들기 전에 컷별 글 콘티가 먼저 나옵니다. 각 CUT 카드에서 세 가지를 확인합니다.

  • 장면 설명이 의도한 순서대로 나왔는가
  • @image 토큰이 맞는 인물을 가리키는가
  • 아래쪽 SFX(효과음) 설명이 장면 분위기와 맞는가

컷 순서나 인물, 장면 전환이 어색하면 이미지를 만들기 전에 시나리오나 컷 수로 돌아가서 고칩니다. 글 단계에서 고치는 것이 가장 빠릅니다.

6단계: Edit Panel에서 컷 확인하기 (Panel 보기와 Sheet 보기)

이미지를 생성하면 Edit Panel 단계로 넘어갑니다. 모델 선택 옆의 Panel / Sheet 버튼으로 보는 방식을 바꿀 수 있습니다.

보기화면언제 쓰나
Panel컷마다 카드 하나. 이미지 아래에 Edit 버튼, 장면 설명, 대사(Dialogue), 효과음(SFX)이 함께 나옴컷 하나하나를 읽고 고칠 때
Sheet설명 없이 컷 이미지만 크게 한 장에 모아서 보여줌전체 흐름을 한눈에 볼 때

Sheet로 먼저 전체 흐름을 봅니다. 글 없이 그림만 이어서 보면, 실제 영상처럼 컷이 이어지는지 판단하기 쉽습니다.

  • 컷 순서가 뒤바뀌거나 빠진 장면은 없는가
  • 앞뒤 컷이 자연스럽게 이어지는가 (의상, 소품, 조명, 시선 방향)
  • 같은 인물이 컷마다 같은 얼굴로 나오는가

화면 오른쪽 위에는 세 가지 버튼이 있습니다.

  • Download CUT ZIP(Panel 보기) / Download Sheet(Sheet 보기): 컷 이미지를 한꺼번에 내려받거나, 시트 한 장으로 내려받습니다. 팀원이나 클라이언트에게 콘티를 공유할 때 씁니다.
  • Regenerate images: 이미지를 다시 생성합니다. 버튼에 필요한 크레딧이 표시되니 누르기 전에 확인하세요.
  • Clear Sheet: 시트를 비웁니다. 되돌리기 어려울 수 있으니 내려받은 뒤에 쓰는 것이 안전합니다.

7단계: 문제 있는 컷만 골라 고치기

잘 나온 컷은 그대로 두고, 문제 있는 컷만 고칩니다. Panel 보기에서 고칠 컷 카드의 Edit를 누르면 그 컷만 따로 수정할 수 있습니다. 컷 카드에는 다음 도구가 있습니다.

도구하는 일
Edit빠른 수정 창 열기
+컷에 쓰이는 요소 추가
휴지통컷 삭제
↓ / ↑컷 이미지 내려받기 / 외부 이미지로 교체

↑(올리기)를 쓰면 Turn에서 만든 키 이미지를 그 컷에 바로 넣을 수도 있습니다. 프롬프트로 잘 안 나오는 구도를 해결할 때 유용합니다.

빠른 수정 (Quick Edit)

  1. 고칠 컷의 Edit를 누르고, 창 위쪽의 컷 번호(예: CUT 04)가 맞는지 확인합니다.
  2. 필요하면 Reference images에 참고 이미지를 추가합니다.
  3. Edit prompt에 바꿀 내용을 한 문장으로 적습니다. @토큰으로 인물을 가리킬 수 있습니다.
  4. 대상 컷과 지시 내용, 크레딧 안내를 확인하고 Apply edit를 누릅니다.

지시문 쓰는 요령: 바꿀 것과 유지할 것을 함께 적으세요. 예: "안경만 바꾸고, 자세와 배경은 그대로 유지" 예: "@image1의 표정만 놀란 표정으로, 손에 든 도자기와 배경은 그대로"

자세한 수정 (Detailed Edit) 카메라를 바꾸고 싶을 때 씁니다. 오른쪽에서 세 가지를 조절합니다.

  • Shot Size: 화면에 얼마나 담을지 (예: Extreme Wide Shot, Close-up)
  • Camera Angle: 카메라 높이와 기울기 (예: Low Angle, Dutch Angle)
  • Camera Movement: 카메라 움직임 (예: Handheld, Track Out)

화면 예시에서는 "POV · Low Angle · Handheld"였던 긴장감 있는 근접 구도를 "Extreme Wide Shot · Dutch Angle · Track Out"으로 바꿔, 넓게 기울어진 화면에서 카메라가 뒤로 빠지는 구도로 다시 만들었습니다. 설정을 확인한 뒤 Regenerate를 누르면 되고, 이때도 화면에 표시되는 크레딧을 확인하세요.



참고 이미지 순서 바꾸기 컷 생성에 쓰이는 인물과 배경 카드는 목록으로 관리됩니다. 인물은 인물끼리, 배경은 배경끼리 끌어서 순서를 바꿀 수 있고, Reset to automatic selection을 누르면 기본 선택으로 돌아갑니다. 순서를 바꾼 뒤에는 컷 이미지를 다시 생성해야 반영됩니다.

시댄스로 넘기기 전 최종 점검

스토리보드가 완성되면 영상 단계로 넘어갑니다. 넘기기 전에 아래를 확인하세요.

  • Sheet 보기로 컷이 자연스럽게 이어지는지 확인했는가
  • 모든 컷의 이미지와 설명이 맞는가
  • 인물 토큰이 컷마다 정확한가
  • 빠진 컷은 없는가
  • 컷 길이, 화면 크기, 카메라 각도, 카메라 움직임이 컷의 의도와 맞는가

여기서 확인한 컷 이미지가 영상 프롬프트의 기준이 됩니다. 구도를 고치는 비용은 이 단계가 가장 작습니다. 영상으로 넘어간 뒤에 구도를 고치려면 영상을 여러 번 다시 돌려야 하기 때문입니다.

자주 하는 실수

  • 글 콘티를 건너뛰고 바로 이미지를 만든다: 컷 순서가 틀린 채로 이미지를 만들면 다시 만들어야 합니다.
  • 같은 인물을 카드 여러 개로 등록한다: 토큰이 헷갈리고 얼굴이 섞일 수 있습니다.
  • 수정 지시문에 바꿀 것만 적는다: 유지할 것을 적지 않으면 다른 부분까지 바뀔 수 있습니다.
  • 잘 나온 컷까지 다시 생성한다: 문제 있는 컷만 골라 Panel 보기에서 Edit로 고치세요.
  • Panel 보기로만 검토한다: 글을 읽다 보면 그림이 실제로 이어지는지 놓치기 쉽습니다. Sheet 보기로 그림만 이어서 보는 단계를 꼭 거치세요.
  • 중간에 이미지 모델을 바꾼다: 컷마다 그림 느낌이 달라질 수 있습니다.
