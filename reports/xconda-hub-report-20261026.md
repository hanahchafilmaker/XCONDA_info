## 2. 완료 항목

### ①-1 다국어 본문 번역 (핵심 성과)
- 본문이 있는 글 **20편 전부 × 3언어** 번역 — 표·콜아웃·체크리스트·코드까지 10가지 블록 형식 지원
- **Q&A 73건 × 3언어**, 그중 65건에 「게시용 출처」 블록(정책명·조항·URL) 포함
- 번역 파일만 추가하면 **페이지·사이트맵·hreflang·`llms.txt`·언어 전환 링크가 같은 빌드에서 자동 생성**
- 이미지·영상·첨부는 번역하지 않고 **한국어 원문 위치를 따라 자동 배치** (구조가 어긋나면 빌드가 경고)

### ①-2 · ①-3 문서화 · 자동 검증
- `README.md` 신설(진입점·명령·구조) + 링크/명령 회귀 테스트
- 배포 워크플로가 **게시 전에 스모크 테스트 실행** → 깨진 상태로 배포되지 않음

### ①-4 검수 진행률 도구
- `npm run i18n:progress` — **285항목(95 × 3언어)** 중 검수 완료/초안/번역 없음 집계
- 기계 점검이 문제를 찾은 항목을 **검수 우선순위**로 정렬해 리포트 생성
- CI 실행 요약(Actions → Summary)에도 자동 표시 → **새 글이 번역 없이 들어오면 즉시 노출**

### ①-5 언어별 공유 카드 (OG)
- 커버가 없는 글·언어 홈·언어 목록에 **그 언어 제목으로 그린 1200×630 카드 44장**(ko/en/ja/zh 각 11장)
- 한·중·일 줄바꿈 금칙 처리, 폰트는 저장소에 넣지 않고 생성 시에만 사용
- Q&A 개별 글은 **의도적으로 제외**(219편 × 4언어 ≈ 876장·25~30MB) — 필요 시 옵션으로 켤 수 있음

### ①-6 레거시 정리 · 기술 부채
- `redesign-xconda-website-ui/`(18파일 288KB, `src/`와 중복되는 옛 프로토타입) 삭제
- `dev.html` **noindex** 적용 — 개발용 껍데기가 검색에 노출되던 경로 차단(빌드가 홈으로 옮기지 않도록 회귀 테스트 포함)

### 그 이전 단계(요약)
- GEO 기준 허브 재구성: 홈·섹션·글별 정적 HTML, JSON-LD(Organization/Brand/Article/HowTo/FAQ), 사이트맵·`llms.txt`
- 공용 번들 분리로 **글당 전송량 553KB → 30KB**
- OG 이미지 자체 호스팅(노션 프록시 만료 대비), 관련 글 추천, 언어별 실제 URL
- www 기능 페이지 원고 **20개 × 2언어(42 HTML)** + 검사·산출물 워크플로

## 4. 품질 체계 (배포 전 자동 실행)

1. **단위 테스트 159건** — 주소 규칙 · SEO 메타 · 사이트맵 · 번역 구조 · 워크플로 설정 · 문서 링크
2. **스모크 테스트** — 실제 번들을 브라우저 환경에서 실행해 화면·언어 전환·공유·글 열기 확인
3. **번역 QC** — 연락처·주소 불일치(오류), 숫자 누락·통화·미번역 영어·제목 중복(경고)
4. **번역 구조 검사** — 번역 블록 종류/수가 원문과 다르면 경고(이미지 위치 어긋남 방지)
5. **www 원고 검증** — 형식·길이·허브 링크·JSON-LD·canonical·hreflang

> 이 중 하나라도 실패하면 **배포가 중단**됩니다. 실제로 이 체계가 이번 작업에서 오탐·누락 6건을 배포 전에 잡아냈습니다.

## 6. 리스크 · 유의사항

| 리스크 | 내용 | 대응 |
|---|---|---|
| 번역 품질 | 3개 언어 모두 **AI 1차 초안** 상태 | 항목별 `review` 표기 → 진행률 관리. 검수 전에는 "번역" 고지 문구 유지 |

| 공유 카드 노후화 | 글 제목이 바뀌면 카드가 옛 제목 유지 | 제목 변경 시 `npm run og:cards` 재실행 |
