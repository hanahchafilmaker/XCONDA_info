글 타입과 필수값 가이드 Quick Reference

Notion에 글을 올릴 때 어떤 타입을 선택해야 하고, 어떤 항목을 꼭 채워야 하는지 한눈에 정리했습니다.

01타입 선택공지 · 뉴스 · 블로그 · 가이드 · FAQ
02필수값 입력Title · Type · Date · Published
03유형별 추가Pinned · Important · Version · Changes 등
04게시 승인검수 후 Published ON
💡
Published는 '저장'이 아니라 '공개 승인'입니다.
Notion은 입력하는 즉시 저장되지만, Published를 체크해야만 사이트에 노출됩니다. 모든 검수가 끝난 뒤 마지막에 체크하세요.

1. 글 타입과 노출 섹션

Type 값이 해당 글이 사이트 어디에 나타나는지 결정합니다. 아래 다섯 가지 중 하나를 선택하세요.

공지

서비스 안내, 점검, 이벤트, 정책 변경. Pinned면 히어로 배너와 공지 목록 최상단에 노출.

뉴스

기능 출시, 성능 개선, 버그 수정, SNS 소식. Changes 필드로 변경사항을 배지 목록으로 표시.

블로그

칼럼, 인터뷰, 인사이트 등 장문 콘텐츠. 작성자(Author)가 카드 하단에 표시됨.

가이드

시작하기, 사용법, 매뉴얼. Tool 필드로 해당 툴의 상세 가이드를 대체할 수 있음.

FAQ

자주 묻는 질문. Title은 질문, Summary는 짧은 답변으로 작성.

ℹ️
Type을 적어 두면 자동으로 섹션을 옮기지 않습니다. X 링크가 있는 글이라도 Type=공지로 적어 두면 공지사항에 그대로 표시됩니다.

2. 꼭 채워야 할 값 (모든 타입 공통)

필드필수 여부입력 기준사이트에서 하는 일
Title 필수ON짧고 구체적인 한 문장. 중요한 단어를 앞쪽에 배치목록 제목, 검색 결과, 상세 모달 제목
Type 필수ON공지 · 뉴스 · 가이드 · 블로그 · FAQ 중 선택노출되는 사이트 섹션 결정
Date 필수ON실제 게시일 또는 업데이트 공개일날짜 표시, 공지·업데이트 최신순 정렬
Published 필수ON검수 완료 전 OFF, 공개 승인 시 ON체크된 글만 사이트에 노출 (OFF면 초안)

3. 타입별 추가 권장 필드

공지

  • Pinned — 상단 고정 및 히어로 배너 노출
  • Important — 빨간 점과 강조 제목 표시
  • Summary — 사용자가 지금 해야 할 행동 작성

뉴스

  • Version — 예: v2.5.0
  • Changes — 한 줄에 한 항목: [New] / [Improved] / [Fixed]
  • Link — 원본 SNS 게시물 링크

가이드

  • Category — 시작하기, 사용법 등
  • Tool — 해당 툴 이름과 동일하게 선택
  • Order — 정렬 순서 (작은 숫자가 먼저)

블로그

  • Author — 카드 하단과 상세 모달에 표시
  • Category — 워크플로우, 튜토리얼 등

FAQ

  • Summary — 짧은 답변 (목록에 바로 노출)
  • Order — 정렬 순서

공통 선택값

  • Summary — 목록 카드에 보일 1~2문장 요약
  • Category — 필터와 분류 배지
  • Cover — 썸네일 이미지 (외부 https:// URL 권장)
  • Tags — 검색에 도움 되는 핵심어 2~5개

4. Changes 작성 규칙 (뉴스/업데이트용)

한 줄이 한 항목이 됩니다. 줄 맨 앞에 종류 태그를 붙이세요.

[New] Turn 스튜디오 추가 - 360도 공간 고정 기능 [Improved] Director's Cut 생성 속도 30% 개선 [Fixed] 모바일에서 모달 스크롤 버그 수정
  • 태그는 줄 맨 앞에 써야 종류로 인식됩니다.
  • 태그가 없으면 기본으로 개선(Improved)이 됩니다.
  • 영문은 Changes EN에 따로 작성하세요.

5. 게시 전 최종 체크리스트

  • Title이 짧고 구체적인가
  • Type이 올바른 사이트 섹션인가 (공지·뉴스·블로그·가이드·FAQ)
  • Date가 실제 공개일과 일치하는가
  • Summary만 읽어도 핵심이 전달되는가
  • 본문 헤딩·목록·링크·이미지를 검수했는가
  • 뉴스라면 Changes가 한 줄 한 항목인가
  • 긴급 공지라면 Pinned + Important를 체크했는가
  • 모든 검수 끝난 뒤 Published를 ON으로 변경했는가
