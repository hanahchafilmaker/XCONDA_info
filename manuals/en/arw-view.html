— Purpose —

Arrow View — What it does

Generates different camera-angle views from a single image. Draw an arrow on the image and the AI generates the scene as seen from that direction. Traditional approach: adjust camera angles in 3D software, or rely on other AI angle tools that require spatial reasoning. Arrow View approach: draw one arrow on the image — done. No 3D knowledge needed, fully intuitive.

— Note —
Skip 3D modeling, rendering, and spatial reasoning — one arrow changes the viewpoint.

— Use Cases —

When to use it

1. Product shot angle expansion — turn a single front-on product shot into top-view, side-view, 45° angles, and more. 2. Aerial top-view generation — get accurate top-down views, a known weak point of generative AI. 3. Storyboard angle variation — show the same scene from multiple camera angles during storyboard work. 4. Architecture / interior viewpoint shifts — re-frame a spatial image from a different viewpoint. 5. Ad creative variations — make banner, poster, and social cuts from one source image.

— Note —
Most effective wherever one shot → many angles is the goal — products, aerial views, storyboards, spatial work, and ad creatives.

Chapter 04Features

— Features —

Arrow View — Key features

Arrow-based viewpoint targeting — draw an arrow on the image to set the camera direction intuitively. No 3D knowledge required. Free-form angle generation — top-view, low-angle, side-view, diagonal — any viewpoint change is possible. Original tone preserved — the source image's color, lighting, and texture stay intact; only the viewpoint shifts.

— Note —
Three pillars: direction targeting → viewpoint shift → tone preservation.

Chapter 05Tips
P. 005
05
— Tips —

Usage tips

Drawing the arrow: start → end is the direction the camera moves. Short arrow = small angle change; long arrow = bigger shift. A clearer arrow direction yields a more accurate result. Good source image: clear subject, simple background, high resolution. Results may be unreliable when: requesting extreme angle changes that expose areas not visible in the source, when the background is busy, or when key sides of a subject aren't visible in the original.

— Note —
Short clear arrow + clean source + reasonable angle change produces the most reliable result.

— Entry —

Opening Arrow View

Click the 15th icon in the left vertical sidebar. The icon is a right-pointing arrow. Clicking it opens the Arrow View workspace.

— Note —
Xconda's sidebar lays out tools with unique icons in a fixed order. Arrow View is the right-arrow icon.

— Upload —

Uploading the image

Click the upload area to pick an image. The screen displays Upload an image to get started. Once uploaded, the source image appears in the editing area. If no image is present, the Generate button stays disabled.

— Note —
Nothing else proceeds without an image — upload first.

Chapter 08Draw Arrow

— Draw —

Draw arrow direction

Drag on the image to draw an arrow. The viewpoint follows the arrow from start point to end point. Once drawn, the status shows Draw arrow direction and the Generate button activates. Without an arrow, Generate stays disabled.

— Note —
Image + arrow — both must be present to enable Generate.

Chapter 09Clear New

— Reset —

Clear Arrow / New Image

Clear Arrow — removes the arrow currently drawn on the image. New Image — swaps the uploaded image for a different one. To redraw the direction, click Clear Arrow and draw a fresh arrow on the image.

— Note —
Use Clear Arrow to redirect on the same image; use New Image to start over with a different source.

Chapter 11Review

— Review —

Reviewing the result

When generation finishes, the result appears in the right-hand result area. The original image with the drawn arrow remains on the left, so you can review the direction and the output side by side.

— Note —
Compare left (source + arrow) and right (result) side-by-side to confirm the viewpoint matches your intent.

Chapter 12Redo
P. 012
12
— Redo —

Edit / redo

If the result doesn't match the intended direction, click Clear Arrow. Remove the old arrow and draw a new one in the correct direction. To work from a different source image, click New Image.

— Note —
The standard workflow is to vary arrow length and angle across multiple generations, then pick the best result.

Chapter 13Download
P. 013

— Download —

Download

Click the download icon on the right of the result image to save the generated result. The result card also shows a delete icon — click it to remove that result from the workspace.

— Note —
Download the keepers and delete the rest — the closing step that keeps the workspace tidy.
