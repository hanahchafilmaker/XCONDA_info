— Image Size —

Select an image aspect ratio

Click the ratio button below the prompt input to choose from 12 aspect ratios.

— General —

The 12 ratios are selected based on the output medium — video, SNS, print, and so on. The most commonly used ratios are 16:9 (landscape wide), 9:16 (vertical), and 1:1 (square).

— Note —

Supported aspect ratios may differ by selected model. When changing models, if a previously selected ratio is unsupported it may be automatically reset to the default value, so verify the ratio after model selection.

Chapter 11Resolution
P. 011
11
— Resolution —

Select a resolution

Click the resolution dropdown next to the ratio button to choose from 3 resolutions.

— Model-specific support —

Supported resolutions differ by selected model. Z Image only supports 1K, while other models can choose between 1K, 2K, and 4K. The default resolution may also vary by model, so verify the resolution after model selection.

— Note —
When changing models, if the previously selected resolution is unsupported, it may be automatically adjusted to an available value.
— 01 —
1K
Fast generation, for draft review
— 02 —
2K
Default recommended resolution
— 03 —
4K
Highest quality, for print and commercial use
