What does ClothSwap do?

Why use this feature?

Apply multiple outfit options to the same person without reshooting. Speed up pre-production decisions on wardrobe choices, styling direction, and ad/lookbook concepts.

Compare options before production

Visualize color tones, silhouettes, and material directions side-by-side in minutes. Internal reviews and client approval rounds shrink significantly.

Chapter 07Source Image

— Source —

Upload the source image

Use Drop Image Here or Click to Upload to load the image whose outfit you want to swap.

— Upload —

Drag & drop or click

Drop a file into the image area, or click the area to pick a local file. Once uploaded, a preview replaces the placeholder.

— Guideline —

What makes a good source

Results are most stable when the full garment is visible and the boundaries between arms and body are clear. Heavy shadows, aggressive crops, or extreme pose distortion hurt output quality.

— Reset —

Remove the upload

The uploaded image can be removed with the X button in the top-right corner, then replaced with another file.

— Recommended —
Front-facing, full-body shots with even lighting and a clean background produce the most reliable results.

— Brush —

Adjusting the brush size

Use the Brush Size slider to set the brush width. Go large for wide clothing areas, and small for delicate edges like collars and cuffs.

— Large —

Cover wide surfaces fast

Use a larger brush for big flat areas like the center of a top or pants. A bigger brush keeps the masking workflow efficient on broad surfaces.

— Small —

Precision on edges

Switch to a smaller brush for delicate edges: collars, cuffs, waistlines, button rows. Sloppy edges may leave traces of the original garment in the output.

— Tip —
Fill the interior fast with a large brush, then trace the outline with a small brush — that two-pass approach is the most efficient.

Chapter 09Mask
P. 009
09
— Mask —

Paint the clothing area

Paint the part of the outfit you want to swap directly on the Source Image. Only the painted region is replaced — anything you miss may retain the original garment.

— Rule —

Only painted areas get swapped

The painted region is exactly what gets replaced. Anything you miss keeps the original garment, so cover the entire outfit carefully.

— Coverage —

Full body of the outfit + edges

Include not just the main body but also collars, cuffs, hems. Missing edges will leave the silhouette of the original garment visible in the output.

— Avoid —

Don't paint face, hands, background

Keep face, hands, hair, and background out of the brush area. Painting over those parts may distort the person's appearance in unintended ways.

— Checklist —
Top, bottom, collar, cuffs, button row, hem — confirm all are inside the mask before generating.

Chapter 11Upload
P. 011

— Upload —

Uploading the reference outfit

The reference image carries the color, shape, texture, and style direction of the new garment. The image you pick directly shapes the output mood.

— Role —

Style signal carrier

The reference passes color, shape, texture, and style direction to the result. Think of it as a visual instruction saying “dress the person in this kind of garment.”

— Preferred Format —

Standalone garment shots work best

Mannequin shots or flat lay images where the garment stands alone work best. The more unrelated detail in the reference, the more noise can leak into the result.

— Replace —

Cancel or swap upload

The uploaded reference can be removed via the X button in the top-right and replaced with another image.

— Recommended —
A clean-background image showing the full silhouette in a single frame gives the most stable result.

— Generate —

Generate

Press Generate once the Source Image, brush mask, and Reference Clothing are all in place. On the current test screen, each generation uses 6 credits.

— Condition —

All three inputs ready

Source Image, brush mask, and Reference Clothing must all be filled in for Generate to activate.

— Cost —

Credit deduction

Each generation deducts 6 credits on the current test screen. Generation will not proceed if your credit balance is insufficient.

— Best Practice —
Double-check the mask and reference one more time before pressing Generate — it cuts down re-runs.

Chapter 13Confirm

— Confirm —

Confirmation dialog

Pressing Generate opens the “Would you like to generate an image?” confirmation. OK starts generation, Cancel returns to the previous screen.

— OK —

Start generation

OK kicks off the actual generation and deducts credits. Progress is shown in the result area while it runs.

— Cancel —

Return without generating

Cancel returns to the previous screen without generating. Your inputs remain intact, so you can edit and retry immediately.

— Safety —
The confirmation step exists to prevent accidental credit spend. Review, then press OK.

— Result Card —

Reviewing the result card

When generation finishes, the result image appears as a card in the right-hand result area. Repeat generations stack downward so you can compare them side by side.

— Display —

New card on the right

A new card is added to the right-hand result area each time generation completes. The card shows the result image as a thumbnail.

Compare multiple takes

Multiple generations stack downward, so you can compare different outfit options applied to the same model in one view.

— Workflow —
Compare candidates → download only the final pick → delete the rest. That's the efficient close-out flow.

Chapter 15Review
P. 015
15
— Review —

Reviewing the output

The result preserves the source person's face and pose while applying the reference outfit's color and shape to the masked area. Before final use, check the garment boundary, sleeves, neckline, and any overlapping items.

— Preserved —

Face & pose held intact

The output keeps the source person's face and pose, while the garment area takes on the reference outfit's color and shape.

— Applied —

Reference color & shape

The reference garment's color, silhouette, and details transfer to the result. It may not be a 100% match — generate multiple takes and pick the best one.

— Inspect —

Edges & overlaps

Before final use, verify that garment boundaries, sleeves, neckline, and overlapping items like bag straps are rendered naturally. If something looks off, refine the mask and regenerate.

— Checkpoints —
Garment boundary · cuffs · neckline · bag/accessory overlap — check these first.

— Manage —

Download / Delete

Hovering over a result card reveals the download and delete icons. Download saves the result image; the trash icon removes the selected result.

— Download —

Download icon

Pressing the download icon saves the result image as a local file. Use this for any candidate you plan to take outside the app.

— Delete —

Trash icon

The trash icon removes the selected result card. Clearing rejected takes keeps the result panel tidy.

— Reveal —
Icons appear only on hover — the card otherwise stays a clean image-only thumbnail.

— Confirm Delete —

Delete confirmation

Pressing the trash icon opens the “Delete this media?” confirmation. Delete removes it; Cancel keeps the result.

— Delete —

Confirm deletion

Delete permanently removes the selected card. Deleted results are not recoverable, so confirm with care.

— Cancel —

Keep the result

Cancel leaves the card intact. It's safer to keep candidates until comparisons against other takes are complete.

— Wrap-Up —
Final pick downloaded → unneeded cards cleared → session done. That's the standard closing sequence.
