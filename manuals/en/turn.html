— Overview —

What Turn Does

Turn creates a 360° environment and produces a final image from your chosen viewpoint.

— Note 01 —

Turn first builds the space, then lets you pick a camera angle in 3D Preview, and finally adds the subject and direction in Production.

— Note 02 —

Freeze Frame is the reference shot; Final Still is the finished result with subject, action, lighting, and style applied.

Why Use Turn

Compare multiple creative directions inside the same space — quickly.

Test lighting, subject placement, and stylistic moods in different versions before the actual shoot.

Useful when you need to show fast visual proposals to clients — ad cuts, product editorials, e-commerce details, or storyboards.

When to Use Turn

When background generation, partial editing, and subject compositing are needed in one flow.

— Note 01 —

Start from prompt only when you have no reference, or attach 1 image (or 4-direction images) to anchor the spatial layout more precisely.

— Note 02 —

Edit the generated environment per direction in Cube Map, then apply face and wardrobe references at the end with Cast Reference.

The Full Turn Workflow

Reference → HDRI → Production → Final Still.

— Note 01 —

— Inpaint —

Add or Modify with a Prompt

Type into the field to add or change an object inside the mask.

— Note 01 —

After defining a mask, enter a new prompt in Replace with — Turn will add an object at that position or alter the existing detail.

— Note 02 —

Keep the brush slightly larger than the target rather than too wide; that yields more reliable results.

Chapter 17Clear

— Clear —

The Clear Button

Clear erases the brush mask you painted.

— Note 01 —

If you brushed the wrong area or want to reselect, pressing Clear removes the brush marks on the current face.

— Note 02 —

Clear is not a regenerate button — it only resets your selection, nothing else.

Chapter 18Regen

— Regen —

The REGEN Button

REGEN regenerates the entire face from scratch.

— Note 01 —

Use REGEN when a face looks awkward or its overall composition does not work.

— Note 02 —

Unlike Inpaint, this rebuilds the directional image entirely, so the variation is much larger.

Chapter 30Input Modes

— Input Modes —

When to Use Each Input Mode

Four reference patterns, each suited to a specific situation — pick whichever fits the task at hand.

— Mode 01 —
Prompt Only

Use this when you need to draft a space quickly or have no reference image yet.

— Mode 02 —
Single Image

Use this when you want to extend an existing background image into a 360° space, keeping its mood as the anchor.

— Mode 03 —
4-Direction Images

Use this when the front, left, right, and back of the space need to stay clearly defined.

— Mode 04 —
Cube Map Edit

Use this after generation, when you want to change only specific elements — windows, furniture, props, subjects, or wall details — on a single face.

Chapter 31Summary

— Summary —

Final Summary

A condensed view of the Turn workflow — the role of each stage and the purpose of each output.

The Full Flow

Turn connects background generation, 3D viewpoint selection, partial editing, subject direction, and final still creation into one continuous workflow.

Stage Roles

Reference prepares the input ingredients, HDRI fixes the space and viewpoint, and Production applies the subject and cinematic detail.

Output Distinction

Freeze Frame is the intermediate reference; Final Still is the directed final image. Their purposes differ, so download and manage each separately.
