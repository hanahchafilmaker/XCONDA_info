— Overview · End-to-End Workflow —

The Workflow at a Glance

Move through the four stages at the top in order: 1. PRE-PRODUCTION → 2. LOCATION_SCOUTING → 3. CAMERA_TEST → 4. MASTER_STILL.

1
PRE-PRODUCTION
Create a 360° space from a reference image or a written description. (Video 4)
2
LOCATION_SCOUTING
Rotate the view in 3D Preview and adjust the room size or walls. (Videos 1, 2, and 4)
3
CAMERA_TEST
Add a subject and style to the Freeze Frame to create a key image. (Video 3)
4
MASTER_STILL
Final master-still stage. This stage is not shown in the demo videos.
— Step 01 —

The complete sequence shown in the videos is: Upload one image → Analyze Space → Confirm Room Layout (mark the wall area) → generate a 360° space → open 3D Preview → (if needed) adjust the room size / edit the walls → FREEZE FRAME → add direction in Step 3 → create a key image.

— Step 02 —

The stage tabs at the top unlock as you progress. At the start of the videos, 1. PRE-PRODUCTION is the only active stage. After the space is generated, 2. LOCATION_SCOUTING becomes active. After Freeze Frame, 3. CAMERA_TEST becomes active.

Upload FRONT Image→ Analyze Space→ Confirm Room Layout→ 360° Space→ 3D Preview / Wall Edit→ FREEZE FRAME→ Key Image
— Note —

Based on the demo narration — ① “Turn creates a virtual studio set from a single image.” ② “If the room is too large, reduce its width and depth; you can also make the ceiling higher.” ③ “In Wall Edit, you can freely add or remove objects.” ④ “Set the composition, write a prompt, then add photos of the subject and outfit to complete the key image.”

— Step 1 · Space Build —

Create a 360° space from a single image

One photo of a hanok and one click on “Analyze Space” create a fully rotatable 3D space.

— Step 01 · Upload an Image —

Upload a hanok photo in the FRONT slot. After the upload, the large button on the right changes from Create Space from Description to Analyze Space. A save indicator appears in the upper left, such as “Auto-saved at 9:34 AM.”

— Step 02 · Analyze the Space —

Analyze Space opens the “Confirm Room Layout” dialog. It contains four estimated values: Room Width (m) 8 Room Depth (m) 6 Ceiling Height (m) 3.5 Camera Height (m) 1.2. Notice: “These are not exact measurements taken from a single photo. Please review the estimated dimensions and wall area.”

— Step 03 · Mark the Wall Area —

“Drag the four corners to select only the wall.” Drag the four purple points on the image to align them with the floor-wall boundary (narration: “Select Space, then move the points up to the floor-wall boundary like this.”). On the right, “Unwrapped Front Wall Result” immediately confirms whether the selection is correct.

— Step 04 · Combined Prompt —

Check the box Unwarp the selected front-wall area and use it as a generation reference; then review the “Space Design · Expand from One Reference” block, including Common Wall Finish, Common Molding & Wood Finish prompts, then start generation.

— Result —

When generation is complete, a fully rotatable virtual 3D space is created and the 2. LOCATION_SCOUTING tab opens.

Adjust Room Size & Camera

Adjust the room width, depth, and ceiling height on the spot without regenerating the space.

— Open —

Select the green Room Size · Camera button to open the “Room Size & Camera” dialog. The same four fields (room width, room depth, ceiling height, and camera height) are available here.

— Make It Smaller —

As the narration says, “If the room is too large,” Room Width 8→4, Room Depth 6→4 are example reduced values to enter. The dialog explains: “The ceiling rafters and indirect lighting are inferred by extending the upper elements in the photo. The floor is assumed to be a wooden floor suitable for sitting. All furniture-like elements are designed as structures integrated into the walls.”

— Make It Taller —

ceiling height raises the ceiling while keeping the same room. As the narration says, “You can also make the ceiling higher.”

— Apply —

The purple Apply Room Size · No Additional Generation button applies the settings without generating a new image, using the existing surface images to reflect only the new proportions (nearby note: “Uses existing surface images”). On the right, select Close to cancel.

Rotate the generated space freely to check the composition, then lock it with Freeze Frame.

Click and drag the screen to rotate the camera through 360°. ELEVATION (horizontal angle) and FOV values appear in real time at the lower left.

— Step 2 · Wall Edit —

Wall Edit: Modify Objects by Direction

Combine references and the brush on six directional cards to add or remove the objects you want.

— Entry —

At the upper left, select Wall Edit to display the six directional cards (LEFT / FRONT / RIGHT / BACK / UP (ZENITH) / DOWN) side by side. The narration says: “Select Wall Edit; you can freely add or remove any object in here.”

— FACE REFERENCE —

Each card has a + Add Reference Image (DRAG & DROP) area. When you add an image, the REF LINKED badge, ACTIVE label and the note “Applied directly to INPAINT and REGEN,” along with the controls Apply As Is / Change / CLEAR appear.

— Brush —

Drag on the image to paint a red mask. Adjust its size with the BRUSH 40PX slider.

— Action Buttons —

Four buttons appear at the bottom of each card: INPAINT (REF) (purple = edit the masked area) · REGEN (REF) (orange = regenerate the entire face) · CLEAR (clear the mask) · REPLACE (green = replace). Below, Reference instructions or requested changes (optional)… you can enter an instruction to send with it.

— Edit Examples —

Add Objects and Replace Wallpaper

A single reference image can guide prop placement or replace the entire wallpaper.

— Example 1 · Place an Object —

On the LEFT card, add a reference of blue hydrangeas, then paint the mask and run the edit. A vase appears on the shelf in 3D Preview — “Shall we place the prepared reference image on the bookshelf? You can see it sitting nicely on the shelf.”

— Example 2 · Replace Wallpaper —

On the BACK card, add a sunflower-wallpaper reference, enter an instruction such as “Remove the molding and change only the wallpaper to sunflower wallpaper,” and run it. The narration says, “You can see that all the wallpaper has changed to sunflowers.” Rotate the view to confirm the same wall is applied consistently throughout the 3D space.

— Key Differences —

INPAINT edits only the painted area (add, remove, or replace objects), REGEN regenerates the entire image for that direction, REPLACE replaces the selected area with a reference image, CLEAR clears only the mask.

Use FACE ID CALIBRATION (LIKENESS PRIORITY: MAX, UPLOAD) to upload a subject photo, and OUTFIT REFERENCE (ADD IMAGE) to add an outfit photo. The narration says, “Add a photo of the subject and an outfit photo to complete the key image.”

— Tips · Avoid Common Mistakes —

Common Mistakes & Tips

Six practical tips shown in the demo videos.

— Tip 01 —

When you upload an image, the home button changes from “Create Space from Description” → “Analyze Space”. Changes to this label are expected; select it to continue to “Confirm Room Layout.”

— Tip 02 —

To get a clean unwrapped front wall, align all four corners with the floor-wall boundary. If too much of the ceiling rafters is included, move the points lower.

— Tip 03 —

The props stay in place when you change the room size. 'Apply Room Size · No Additional Generation' applies only the proportions without regeneration, so you can try different values without worrying about credits.

— Tip 04 —

Make the brush slightly larger than the object you want to change, then paint the mask. Use the BRUSH 40PX slider to adjust the size. If you paint the wrong area, select CLEAR to clear it.

— Tip 05 —

For object placement, use INPAINT; for replacing an entire surface such as wallpaper, use a linked reference plus an instruction; if the result looks off, use REGEN. Each tool has a different purpose, so choose accordingly.

— Tip 06 —

For a key image, follow this order: composition (prompt) → subject photo → outfit photo. Use FACE ID and OUTFIT together to preserve both the face and clothing.

— Summary · Wrap-Up —

Final Summary

Everything about Turn confirmed in the four demo videos.

What Is Turn?

Turn is a local cinematic workspace that creates a fully rotatable 360° 3D virtual studio set from one image or a description. Interior walls are perspective-corrected; outdoor scenes expand into a cubemap of landscape, sky, and ground.

Key Workflow Confirmed in the Videos

① Upload a FRONT image → Analyze Space → Confirm Room Layout (review dimensions + drag the four corners) → generate a 360° space. ② Rotate and zoom in 3D Preview; adjust room size or camera and edit walls as needed (references, brush, INPAINT / REGEN / REPLACE). ③ FREEZE FRAME → add direction, CINEMA STYLE, and subject/outfit photos in Step 3 → GENERATE_STILL → key image.

Understanding the Outputs

Freeze Frame = a capture of the reference composition before direction is added (DOWNLOAD FREEZE FRAME). Final Still = the final image with the subject, style, and lighting applied (GENERATE_STILL_1K / 2K HQ). They serve different purposes, so they have separate download buttons.

Note

This guide is based on the screens and narration in four demo videos (About Turn, 18 sec · Adjusting Room Size, 10 sec · Editing Objects, 27 sec · Creating a Key Image, 7 sec). Some labels, including “Generate the Desired View,” may be inferred because of the video resolution.
