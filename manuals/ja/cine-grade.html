— 目的 —

CineGrade AI の機能

CineGrade AI は、リファレンスの映画スチールが持つカラーグレーディング・コントラスト・雰囲気を自分の写真に適用します。編集したい写真とスタイルのリファレンスをアップロードすると、AI がリファレンスの色の方向性を読み取り、元の写真をその新しい色調に変換します。

— 理由 —

この機能を使う理由

写真の構図と被写体をそのままに、色と空気感だけを素早く変えられるからです。本番のカラーグレーディング前にルックを試したり、短いターンアラウンドでクライアントに複数の色調候補を見せたりするのに有効です。

— 構図を保持 —

被写体はそのまま、色だけ変化

構図・被写体・ポーズ は元のままで、変わるのは色・コントラスト・雰囲気だけです。カットを組み直さずにグレーディングの方向性を素早く試せます。

— 色作業の加速 —

グレーディング前にルックを事前検証

本番のカラーグレーディングに入る前に狙いのルックをシミュレーションでき、判断の往復が減り、最終工程にかける時間も短くなります。

— 自分の写真 —

編集する写真をアップロード

左のボックスは、グレードをかける元の写真をアップロードする場所です。被写体がはっきりし、背景が整理され、露出が安定した写真ほど、リファレンスのグレードを重ねた効果を評価しやすくなります。

— アップロード —

写真を登録する

左のボックスをクリックするかファイルをドラッグ＆ドロップして、グレードする写真をアップロードします。アップロードすると、ボックス内のプレースホルダーがプレビューに変わります。

— ガイドライン —

良い写真の条件

被写体と背景がはっきりしており、 露出が安定している写真ほどグレードを評価しやすくなります。著しく露出不足・露出過多のカットは色調の変化が読み取りにくくなります。

— リセット —

アップロードを削除

アップロードした写真は、ボックス右上の X ボタンで削除し、差し替えられます。

— 推奨 —
ディテールが残った適正露出のポートレートや風景写真が、最も信頼できるグレーディング結果を生みます。

— リファレンス —

スタイルのリファレンスをアップロード

右のボックスは、映画スチールや、使いたい色調を持つ任意の画像用です。リファレンスが伝えるのは色・コントラスト・ライティングの雰囲気であり、構図ではありません。

— 役割 —

色 · コントラスト · ライティングの信号

リファレンスは 色・コントラスト・ライティングの雰囲気 を結果に渡します。これは 「この色調をくれ」という視覚的な指示であり、 「この構図をくれ」ではありません。

— 推奨形式 —

色調がはっきりしたフレーム

色調の方向性が明確な 画像（暖色・寒色・シネマティック・高コントラストなど）が最適です。映画スチール、広告のキービジュアル、アート写真のいずれも使えます。

— リセット —

アップロードを削除

アップロードしたリファレンスは、ボックス右上の X ボタンで削除し、別の画像に差し替えられます。

— 推奨 —
リファレンスを選ぶときは、写真にそのリファレンスの 色・ライティング・コントラスト を取り込みたいかどうかを自問してください — それがフィルターです。

— 2 枚そろった状態 —

2 枚の画像がそろったとき

元の写真とスタイルのリファレンスの両方がアップロードされると、 Generate が有効になります。その状態では、AI は左の写真の被写体を保ちながら、右の画像の色の雰囲気とコントラストを適用します。

— 有効化 —

Generate が有効になる

両方のボックスが埋まると、 Generate ボタンが黄色くなり有効になります。この状態からグレーディングを実行できます。

— 処理の仕組み —

左の被写体 + 右の色調

AI は左の写真から 被写体・構図・ディテール を保ちつつ、 右の画像の色の雰囲気とコントラスト を入力信号として使います。

— 要点 —
左 = 何を。右 = どの色調で.

— 削除 —

アップロードした画像の削除

各アップロードボックスの右上にある X ボタンを押すと、その画像を削除します。間違った写真の差し替えや、リファレンスの入れ替えに使います。

— × ボタン —

各ボックスの右上

赤い X ボタンが2つのアップロードボックスのそれぞれ右上に表示されます。 押すとその画像が削除されます。

— 用途 —

差し替え / 入れ替え

間違った写真の差し替えや、リファレンスを別の色調のものに入れ替えるのに使います。片側だけ削除すると Generate は再び無効になります。

— メモ —
どちらかの画像を削除すると Generate は再び無効になります — 再アップロードで有効に戻ります。

— 生成 —

Generate

両方の画像をアップロードしたら、 Generate を押してカラー転送を開始します。現在のテスト画面では、1 回の生成に 6 クレジットを消費します。

— 条件 —

2 枚とも必須

Your Photo と Reference Movie Still の両方のボックスが埋まらないと Generate は有効になりません。

— コスト —

クレジットの消費

生成ごとに 6 クレジット を消費します（現在のテスト画面）。クレジット残高が不足していると生成は実行されません。

— ベストプラクティス —
再実行を減らすため、押す前にもう一度、両方の画像を確認してから Generate を押しましょう。

— 結果確認 —

出力を確認する

最終画像は、リファレンススチールの暖かなライティングとシネマティックなコントラストを元の写真に適用したものです。最終使用前に、顔の色味・衣装の色・背景の明るさ・全体のコントラストが意図どおりか確認してください。

— 保持 —

被写体と構図は保持

出力は写真の 被写体・構図・ディテールを保ちます。変わるのは色だけで、写真の内容は一貫したままです。

— 適用 —

リファレンスの色調とコントラスト

リファレンスの ライティングの雰囲気・色調・コントラスト が結果に重なります。100% 一致しないこともあるため、複数生成して最良のものを選びましょう。

— 確認 —

顔 · 衣装 · 背景

最終使用前に、 顔の色味・衣装の色・背景の明るさ・全体のコントラスト が意図どおりか確認します。暗すぎたり彩度が高すぎたりする場合は、別のリファレンスで再生成します。

— チェック項目 —
顔の色味 · 衣装の色 · 背景の明るさ · 全体のコントラスト — まずこの4点を確認します。

— 管理 —

ダウンロード / 削除

結果画像にホバーすると、ダウンロードと削除のアイコンが現れます。ダウンロードは結果を保存し、削除は選択した結果を取り除きます。

— ダウンロード —

ダウンロードアイコン

download icon を押すと、結果画像をローカルファイルとして保存します。アプリの外に持ち出す候補に使います。

— 削除 —

削除アイコン

delete icon で選択した結果カードを削除します。不採用の色調候補を消すと結果パネルが整います。

— 表示 —
アイコンはホバー時だけ表示され、通常は画像だけのきれいな状態のままです。

— 削除の確認 —

削除の確認

削除アイコンを押すと、「Delete this media?」という確認が開きます。 Delete で削除し、 Cancel で結果を残します。

— 削除 —

削除を確定

Delete で選択したカードを完全に削除します。削除した結果は復元できないため、慎重に確認してください。

— Cancel —

結果を残す

Cancel でカードはそのまま残ります。他の色調との比較が終わるまでは候補を残しておくほうが安全です。

— まとめ —
最終案をダウンロード → 不要なカードを整理 → セッション完了。これが標準的な締めの手順です。
