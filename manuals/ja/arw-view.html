— 目的 —

Arrow View でできること

1 枚の画像から さまざまなカメラアングルの視点 を生成します。画像上に矢印を描くと、その方向から見たシーンを AI が生成します。 従来の方法：3D ソフトでカメラアングルを調整するか、空間認識を必要とする他の AI アングルツールに頼る必要があります。 Arrow View の方法：画像に矢印を 1 本描くだけ。3D の知識は不要で、完全に直感的です。

— メモ —
3D モデリング・レンダリング・空間認識をすべて省略 — 矢印 1 本で視点が変わります。

— 利用シーン —

利用シーン

1. 商品カットのアングル展開 — 正面からの 1 枚を、真上・側面・45° などのアングルに展開します。 2. 真上からの俯瞰生成 — 生成 AI が苦手とする正確な真上視点を得られます。 3. ストーリーボードのアングル展開 — ストーリーボード制作で、同じシーンを複数のカメラアングルから見せられます。 4. 建築・インテリアの視点変更 — 空間画像を別の視点から再構成します。 5. 広告クリエイティブのバリエーション — 1 枚の元画像からバナー・ポスター・SNS 用カットを作成します。

— メモ —
最も効果を発揮するのは 1 ショット → 多数のアングル を目的とする場面です — 商品、俯瞰、ストーリーボード、空間表現、広告クリエイティブなど。

— 機能 —

Arrow View の主な機能

矢印による視点指定 — 画像に矢印を描くだけで、カメラの向きを直感的に指定できます。3D の知識は不要です。 自由なアングル生成 — 俯瞰・あおり・横・斜めなど、あらゆる視点変更が可能です。 元のトーンを保持 — 元画像の色・ライティング・質感はそのままに、視点だけを変えます。

— メモ —
3 つの柱： 方向指定 → 視点変更 → トーン保持.

Chapter 05コツ
P. 005
05
— コツ —

使い方のコツ

矢印の描き方：始点 → 終点がカメラの移動方向です。短い矢印は小さな角度変更、長い矢印は大きな変更になります。矢印の向きが明確なほど、結果の精度が上がります。 良質な元画像：被写体が明確で、背景がシンプルで、解像度が高いもの。 結果が不安定になりやすいケース：元画像に写っていない領域が見えてしまう極端なアングル変更、背景が複雑な場合、被写体の重要な面が元画像で見えていない場合。

— メモ —
短く明確な矢印 + クリーンな元画像 + 妥当な角度変更 が最も信頼できる結果につながります。

— 開始 —

Arrow View を開く

左側の縦サイドバーの 15 番目のアイコン をクリックします。アイコンは 右向きの矢印です。クリックすると Arrow View のワークスペースが開きます。

— メモ —
Xconda のサイドバーは、固有のアイコンを持つツールを決まった順序で並べています。Arrow View は右向き矢印のアイコンです。

— アップロード —

画像のアップロード

アップロードエリアをクリックして画像を選択します。画面には 「Upload an image to get started」と表示されます。アップロードすると、元画像が編集エリアに表示されます。画像がない場合、 Generate ボタンは無効のままです。

— メモ —
画像がないと何も進みません — まずアップロードしてください。

Chapter 08矢印を描く
P. 008

— 描画 —

矢印の方向を描く

画像上をドラッグして矢印を描きます。視点は 始点から終点へと矢印に従います。描画すると、ステータスに 「Draw arrow direction」 と表示され、 Generate ボタンが有効になります。矢印がない場合、Generate は無効のままです。

— メモ —
画像と矢印の両方がそろって初めて Generate が有効になります。

Chapter 09クリア / 新規
P. 009
09
— リセット —

Clear Arrow / New Image

Clear Arrow — 画像上に描いた矢印を削除します。 New Image — アップロードした画像を別の画像に差し替えます。方向を描き直すには Clear Arrow をクリックし、画像上に新しい矢印を描いてください。

— メモ —
同じ画像で向きを変えるときは Clear Arrow、別の画像でやり直すときは New Image を使います。

Generate

画像のアップロードと矢印の描画が終わったら、黄色い Generate ボタンをクリックして生成を開始します。

— メモ —
画像と矢印の両方が準備できたときだけ Generate が有効になります。

— 結果確認 —

結果の確認

生成が完了すると、結果が 右側の結果エリアに表示されます。 矢印を描いた元画像 は左側に残るので、向きと出力を並べて確認できます。

— メモ —
左（元画像 + 矢印）と右（結果）を並べて、視点が意図どおりかを確認してください。

Chapter 12やり直し

— やり直し —

編集・やり直し

結果が意図した向きと違う場合は、 Clear Arrowをクリックします。古い矢印を削除し、正しい方向に新しい矢印を描いてください。別の元画像で作業する場合は、 New Image.

— メモ —
矢印の長さと角度を変えながら複数回生成し、最も良い結果を選ぶのが標準的な進め方です。

— ダウンロード —

ダウンロード

結果画像の右側にある ダウンロードアイコン をクリックすると、生成結果を保存できます。結果カードには 削除アイコン も表示されます — クリックすると、その結果をワークスペースから削除します。

— メモ —
必要なものはダウンロードし、不要なものは削除する — ワークスペースを整える最後のステップです。
