— 概要 · エンドツーエンドの流れ —

ワークフローの全体像

上部の 4 つのステージを順番に進めます: 1. PRE-PRODUCTION → 2. LOCATION_SCOUTING → 3. CAMERA_TEST → 4. MASTER_STILL。

1
PRE-PRODUCTION
参照画像または文章から 360° 空間を作成します。(動画 4)
2
LOCATION_SCOUTING
3D Preview で視点を回転させ、部屋のサイズや壁を調整します。(動画 1、2、4)
3
CAMERA_TEST
Freeze Frame に被写体とスタイルを加えてキー画像を作成します。(動画 3)
4
MASTER_STILL
最終マスタースチルのステージです。このステージはデモ動画には登場しません。
— ステップ 01 —

動画で示される一連の流れは次のとおりです: 画像を 1 枚アップロード → Analyze Space → Confirm Room Layout (壁の範囲を指定) → 360° 空間を生成 → 3D Preview を開く → (必要なら) 部屋のサイズ調整 / 壁の編集 → FREEZE FRAME → Step 3 で演出を追加 → キー画像を作成.

— ステップ 02 —

上部のステージタブは進行に合わせて解放されます。動画の冒頭では 1. PRE-PRODUCTION だけが有効で、空間が生成されると 2. LOCATION_SCOUTING が有効になります。Freeze Frame の後は 3. CAMERA_TEST が有効になります。

FRONT 画像をアップロード→ Analyze Space→ Confirm Room Layout→ 360° 空間→ 3D Preview / Wall Edit→ FREEZE FRAME→ キー画像
— メモ —

デモのナレーションより — ①「Turn は 1 枚の画像から仮想スタジオのセットを作ります。」②「部屋が大きすぎる場合は幅と奥行きを小さくします。天井を高くすることもできます。」③「Wall Edit では、オブジェクトを自由に追加・削除できます。」④「構図を決めてプロンプトを書き、被写体と衣装の写真を加えるとキー画像が完成します。」

— ステップ 1 · 空間ビルド —

1 枚の画像から 360° 空間を作る

韓屋（ハノク）の写真 1 枚と「Analyze Space」の 1 クリックで、自由に回転できる 3D 空間が作られます。

— ステップ 01 · 画像をアップロード —

FRONT スロットに韓屋の写真をアップロードします。アップロード後、右側の大きなボタンは Create Space from Description から Analyze Spaceに変わります。左上には「Auto-saved at 9:34 AM」のような保存表示が出ます。

— ステップ 02 · 空間を解析 —

Analyze Space を選択すると “Confirm Room Layout” ダイアログが開きます。推定値は 4 つです: Room Width (m) 8 Room Depth (m) 6 Ceiling Height (m) 3.5 Camera Height (m) 1.2注意: “These are not exact measurements taken from a single photo. Please review the estimated dimensions and wall area.”

— ステップ 03 · 壁の範囲を指定 —

“Drag the four corners to select only the wall.” 画像上の 4 つの紫のポイントをドラッグして 床と壁の境界 に合わせます（ナレーション:「Select Space を押して、このようにポイントを床と壁の境界まで上げます。」）。右側の “Unwrapped Front Wall Result” が、選択が正しいかをその場で確認させてくれます。

— ステップ 04 · 統合プロンプト —

チェックボックスをオンにします: Unwarp the selected front-wall area and use it as a generation reference。続いて「Space Design · Expand from One Reference」ブロックで Common Wall Finish, Common Molding & Wood Finish プロンプトを確認し、生成を開始します。

— 結果 —

生成が完了すると、自由に回転できる仮想 3D 空間が作られ、2. LOCATION_SCOUTING タブが開きます。

— 部屋サイズ · カメラ —

部屋サイズとカメラを調整

空間を再生成せずに、部屋の幅・奥行き・天井高をその場で調整します。

— 開く —

緑色の Room Size · Camera ボタンを選択すると “Room Size & Camera” ダイアログが開きます。ここでも同じ 4 つの項目（部屋の幅、奥行き、天井高、カメラ高）を設定できます。

— 小さくする —

ナレーションのとおり、「部屋が大きすぎる場合」は Room Width 8→4, Room Depth 6→4 が縮小の入力例です。ダイアログには次の説明があります:「天井の梁と間接照明は、写真の上部要素を延長して推測されます。床は座るのに適した木の床と仮定されます。家具のような要素はすべて壁に統合された構造として設計されます。」

— 天井を高くする —

天井高 を上げると、同じ部屋のまま天井が高くなります。ナレーションのとおり、「天井を高くすることもできます」。

— 適用 —

紫色の Apply Room Size · No Additional Generation ボタンを押すと、設定が適用されます。 新しい画像は生成されず、 既存の表面画像を使って新しい比率だけが反映されます（近くの注記:「Uses existing surface images」）。右側の Close でキャンセルできます。

— ステップ 2 · 壁の編集 —

壁の編集: 方向ごとにオブジェクトを変更

6 つの方向カードで参照画像とブラシを組み合わせ、欲しいオブジェクトを追加・削除します。

— 開始 —

左上で Wall Edit を選択すると、6 つの方向カード（LEFT / FRONT / RIGHT / BACK / UP (ZENITH) / DOWN) が並んで表示されます。ナレーション:「Wall Edit を選択すると、ここでオブジェクトを自由に追加・削除できます。」

各カードには + Add Reference Image （DRAG & DROP）エリアがあります。画像を追加すると、 REF LINKED バッジ、 ACTIVE ラベルと「Applied directly to INPAINT and REGEN」という注記、そして Apply As Is / Change / CLEAR の操作が表示されます。

— アクションボタン —

各カードの下部に 4 つのボタンが並びます: INPAINT (REF) （紫 = マスクした範囲を編集）· REGEN (REF) （オレンジ = 面全体を再生成）· CLEAR （マスクをクリア）· REPLACE （緑 = 差し替え）。その下の Reference instructions or requested changes (optional)… に入力すると、指示を添えて送信できます。

Chapter 07オブジェクトと壁紙
P. 007

— 編集例 —

オブジェクトを追加し、壁紙を差し替える

参照画像 1 枚で小道具の配置を導くことも、壁紙全体を差し替えることもできます。

— 例 1 · オブジェクトを置く —

LEFT カードに 青いアジサイの参照を追加し、マスクを塗って編集を実行します。3D Preview の棚に花瓶が現れます —「用意した参照画像を本棚に置いてみましょうか。棚の上にきれいに収まっているのが分かります。」

— 例 2 · 壁紙を差し替える —

BACK カードに ひまわり柄の壁紙の参照を追加し、「モールディングを削除して、壁紙だけをひまわり柄に変えてください」のような指示を入力して実行します。ナレーション:「壁紙がすべてひまわりに変わったのが分かります。」視点を回転させ、3D 空間全体で同じ壁が一貫して適用されているか確認しましょう。

— 主な違い —

INPAINT は塗った範囲だけを編集します（オブジェクトの追加・削除・差し替え）。 REGEN はその方向の画像全体を再生成し、 REPLACE は選択した範囲を参照画像で置き換え、 CLEAR はマスクだけをクリアします。

— ステップ 3 · キー画像 —

カメラテスト: キー画像を作成

構図のプロンプト、被写体の写真、衣装の写真、シネマスタイルを組み合わせてキー画像を作ります。

— 開始 —

ステップ 2 で FREEZE FRAME を選択すると 3. CAMERA_TEST が開き、選んだ構図が中央に表示されます。

— 演出 —

PRODUCTION: SUBJECT & CASTING ここに被写体の動作と感情を入力します。動画の例:「女性が悲しげな表情で陶器の器を抱えている。」

— CINEMA STYLE —

8 つのスタイル — Normal Hollywood （既定で選択） Korean Japanese Chinese Noir Neon-Punk Anime Style.

— Cast —

FACE ID CALIBRATION を使い (LIKENESS PRIORITY: MAX, UPLOAD) で被写体の写真をアップロードし、 OUTFIT REFERENCE (ADD IMAGE) で衣装の写真を追加します。ナレーション:「被写体の写真と衣装の写真を加えるとキー画像が完成します。」

右側に 3 つのボタンがあります: DOWNLOAD FREEZE FRAME （参照フレームを保存）· GENERATE_STILL_1K （白）· GENERATE_STILL_2K (HQ) （紺）。2K の結果が動画用の最終キー画像です。

— コツ · よくあるミスを避ける —

よくあるミスとコツ

デモ動画で示された 6 つの実践的なコツです。

— コツ 01 —

画像をアップロードすると、ホームのボタンは “Create Space from Description” → “Analyze Space”に変わります。このラベルの変化は正常です。そのまま選択して「Confirm Room Layout」に進みましょう。

— コツ 02 —

きれいな展開図を得るには、 4 つの角すべてを床と壁の境界に合わせます。天井の梁が入りすぎる場合は、ポイントを下げてください。

— コツ 03 —

部屋のサイズを変えても小道具はそのまま残ります。 'Apply Room Size · No Additional Generation' は再生成せずに比率だけを適用するので、クレジットを気にせず値を試せます。

— コツ 04 —

ブラシは、変えたいオブジェクトより 少し大きめ にしてからマスクを塗ります。サイズは BRUSH 40PX スライダーで調整します。塗る範囲を間違えたら CLEAR でクリアします。

— コツ 05 —

オブジェクトの配置には INPAINTを、壁紙のような面全体の差し替えには 参照画像をリンクして指示を添える方法を使い、結果が不自然なら REGENを使います。道具ごとに役割が違うので、目的に合わせて選びましょう。

— コツ 06 —

キー画像はこの順番で作ります: 構図（プロンプト）→ 被写体の写真 → 衣装の写真。FACE ID と OUTFIT を併用すると、顔と衣装の両方を保てます。

Chapter 11まとめ
P. 011

— まとめ · 総括 —

最終まとめ

4 本のデモ動画で確認できた Turn のすべて。

Turn とは

Turn は、1 枚の画像または説明から、自由に回転できる 360° の 3D 仮想スタジオセットを作るローカルのシネマティックワークスペースです。屋内の壁はパース補正され、屋外のシーンは風景・空・地面のキューブマップに拡張されます。

動画で確認できた主要な流れ

① FRONT 画像をアップロード → Analyze Space → Confirm Room Layout（寸法を確認し、4 つの角をドラッグ）→ 360° 空間を生成。② 3D Preview で回転・ズームしながら、必要に応じて部屋サイズやカメラを調整し、壁を編集（参照画像、ブラシ、INPAINT / REGEN / REPLACE）。③ FREEZE FRAME → ステップ 3 で演出、CINEMA STYLE、被写体・衣装の写真を追加 → GENERATE_STILL → キー画像。

出力の理解

Freeze Frame = 演出を加える前の参照構図のキャプチャ（DOWNLOAD FREEZE FRAME）。Final Still = 被写体、スタイル、ライティングを適用した最終画像（GENERATE_STILL_1K / 2K HQ）。用途が異なるため、ダウンロードボタンも別々になっています。

注意

このガイドは 4 本のデモ動画（About Turn 18 秒 · Adjusting Room Size 10 秒 · Editing Objects 27 秒 · Creating a Key Image 7 秒）の画面とナレーションに基づいています。「Generate the Desired View」を含む一部のラベルは、動画の解像度の都合で推測したものです。
