— 理由 —

この機能を使う理由

再撮影なしで、同じ人物に複数の衣装案を適用できます。衣装選び、スタイリングの方向性、広告・ルックブックのコンセプト決定を前倒しできます。

— 人物を保持 —

同じ人物、違う衣装

顔・ポーズ・背景は元のまま、服だけが変わります。再撮影なしで同じモデルのスタイリング案を増やせます。

— 判断の加速 —

本番前に案を比較

色味・シルエット・素材の方向性を数分で並べて可視化できます。社内レビューやクライアント承認の往復が大きく減ります。

— 開始 —

ClothSwap を開く

左の縦メニューで T シャツのアイコンをクリックします。この項目が ClothSwap 機能につながります。

— 場所 —

左メニュー

画面左の縦メニューに機能アイコンが並びます。 T-shirt アイコンが ClothSwap の入口です。

— 開く —

アイコンをクリック

T シャツのアイコンをクリックすると ClothSwap のワークスペースが開きます。ヘッダーには ClothSwap と短い説明が表示され、正しい画面にいることを確認できます。

— ヘッダー —
ヘッダーの説明は、差し替えたい衣装エリアを塗り、リファレンス衣装画像をアップロードして AI で差し替える、という意味です。

Chapter 07元画像

07
— 元画像 —

元画像をアップロード

Drop Image Here または Click to Upload で、衣装を差し替えたい画像を読み込みます。

— アップロード —

ドラッグ＆ドロップまたはクリック

画像エリアにファイルをドラッグするか、エリアをクリックしてローカルのファイルを選びます。アップロードすると、プレースホルダーがプレビューに変わります。

— ガイドライン —

良い元画像の条件

衣装全体が見えており、 腕と体の境界がはっきりしているときに最も安定します。強い影、極端なトリミング、強いポーズの歪みは出力品質を下げます。

— リセット —

アップロードを削除

アップロードした画像は、右上の X ボタンで削除し、別のファイルに差し替えられます。

— 推奨 —
正面・全身・均一なライティング・シンプルな背景のカットが、最も安定した結果になります。

— ブラシ —

ブラシサイズの調整

Brush Size スライダーでブラシ幅を設定します。広い衣装エリアには大きく、襟や袖口のような繊細な縁には小さくします。

— 大 —

広い面を素早く塗る

トップスの中央やパンツのような広い平らな面には大きめのブラシを使います。広い面でのマスク作業が効率的になります。

— 小 —

縁を精密に

襟・袖口・ウエストライン・ボタンの列など繊細な縁には小さめのブラシに切り替えます。縁が雑だと、出力に元の衣装の痕跡が残ることがあります。

— コツ —
内部は大きなブラシで素早く塗り、輪郭は小さなブラシでなぞる — この2段階が最も効率的です。

Chapter 09マスク
P. 009
09
— マスク —

衣装エリアを塗る

差し替えたい衣装の部分を元画像の上に直接塗ります。置き換わるのは塗った領域だけで、塗り残した部分は元の衣装が残る可能性があります。

— ルール —

塗った領域だけが差し替わる

塗った領域が正確に置き換わります。 塗り残した部分は元の衣装が残るため、衣装全体を丁寧に塗ってください。

— 範囲 —

衣装の本体 + 縁

本体だけでなく襟・袖口・裾も含めます。縁が抜けると、出力に元の衣装のシルエットが見えてしまいます。

— 避けるべき例 —

顔・手・背景は塗らない

顔・手・髪・背景はブラシの範囲に入れないでください。塗ると人物の見た目が意図せず歪むことがあります。

— チェックリスト —
トップス・ボトムス・襟・袖口・ボタンの列・裾 — 生成前にすべてマスク内にあることを確認します。

— リファレンス —

Reference Clothing スロット

新しい衣装画像を Reference Clothing スロットにアップロードします。リファレンスがないと Generate ボタンは無効のままです。

— 入力 —

リファレンス枠

下段の Reference Clothing エリアには空のハンガー型スロットが表示されます。適用したい衣装画像をこのスロットにアップロードします。

— 有効化 —

Generate が有効になる条件

Generate は、次の 3 つの入力がそろったときだけ有効になります： 元画像・ブラシのマスク・リファレンス衣装。どれか1つでも欠けるとボタンは無効のままです。

— コスト —
現在のテスト画面では、1 回の生成に 6 クレジット.

— アップロード —

リファレンス衣装をアップロード

リファレンス画像は、新しい衣装の色・形・質感・スタイルの方向性を担います。選んだ画像が出力の雰囲気を直接左右します。

— 役割 —

スタイルの信号源

リファレンスは 色・形・質感・スタイルの方向性 を結果に渡します。「この系統の服を着せる」という視覚的な指示だと考えてください。

— 推奨形式 —

衣装単体のカットが最適

マネキン撮影や平置きで衣装だけが写っている画像が最適です。無関係な要素が多いほど、結果にノイズが混ざりやすくなります。

— 差し替え —

アップロードの取消・差し替え

アップロードしたリファレンスは、右上の X ボタンで削除し、別の画像に差し替えられます。

— 推奨 —
背景がきれいで、全体のシルエットが1フレームに収まった画像が最も安定した結果になります。

— 生成 —

Generate

Generate は、元画像・ブラシのマスク・リファレンス衣装がすべてそろったら押します。現在のテスト画面では、1 回の生成に 6 クレジットを消費します。

— 条件 —

3 つの入力がそろう

元画像, ブラシのマスク、 Reference Clothing がすべて入力されていれば Generate が有効になります。

— コスト —

クレジットの消費

生成ごとに 6 クレジット を消費します（現在のテスト画面）。クレジット残高が不足していると生成は実行されません。

— ベストプラクティス —
もう一度、マスクとリファレンスを確認してから Generate を押しましょう — 再実行を減らせます。

— 確認 —

確認ダイアログ

Generate を押すと、「Would you like to generate an image?」という確認が開きます。 OK で生成を開始し、 Cancel で前の画面に戻ります。

— OK —

生成を開始

OK 実際の生成を開始し、クレジットを消費します。実行中は結果エリアに進行状況が表示されます。

— Cancel —

生成せずに戻る

Cancel 生成せずに前の画面に戻ります。入力内容は保持されるので、すぐに修正してやり直せます。

— 安全策 —
確認ステップは、意図しないクレジット消費を防ぐためにあります。内容を確認してから OK を押してください。

— 結果カード —

結果カードを確認する

生成が完了すると、結果画像が右の結果エリアにカードとして表示されます。生成を繰り返すと下に積み重なり、並べて比較できます。

— 表示 —

右に新しいカード

生成が完了するたびに、右の結果エリアに新しいカードが追加されます。カードには結果画像がサムネイルで表示されます。

— 積み重ね —

複数のテイクを比較

複数回の生成は下に積み重なるため、同じモデルに適用した異なる衣装案を1画面で比較できます。

— ワークフロー —
候補を比較 → 最終案だけダウンロード → 残りを削除。これが効率的な締めの流れです。

— 結果確認 —

出力を確認する

結果は元画像の人物の顔とポーズを保ちながら、マスクした領域にリファレンス衣装の色と形を適用します。最終使用前に、衣装の境界・袖・ネックライン・重なり合う小物を確認してください。

— 保持 —

顔とポーズはそのまま

出力は元画像の人物の 顔とポーズを保ち、衣装エリアにはリファレンス衣装の色と形が反映されます。

— 適用 —

リファレンスの色と形

リファレンス衣装の色・シルエット・ディテールが結果に転写されます。100% 一致しないこともあるため、複数生成して最良のものを選びましょう。

— 確認 —

縁と重なり

最終使用前に、 衣装の境界・袖・ネックライン・バッグのストラップのような重なり が自然に描画されているか確認します。不自然に見える場合はマスクを修正して再生成します。

— チェック項目 —
衣装の境界 · 袖口 · ネックライン · バッグや小物の重なり — まずこれらを確認します。

— 管理 —

ダウンロード / 削除

結果カードにホバーすると、ダウンロードと削除のアイコンが現れます。ダウンロードは結果画像を保存し、ゴミ箱アイコンは選択した結果を削除します。

— ダウンロード —

ダウンロードアイコン

download icon を押すと、結果画像をローカルファイルとして保存します。アプリの外に持ち出す候補に使います。

— 削除 —

ゴミ箱アイコン

trash icon で選択した結果カードを削除します。不採用のテイクを消すと結果パネルが整います。

— 表示 —
アイコンはホバー時だけ表示され、通常は画像だけのきれいなサムネイルのままです。

— 削除の確認 —

削除の確認

ゴミ箱アイコンを押すと、「Delete this media?」という確認が開きます。 Delete で削除し、 Cancel で結果を残します。

— 削除 —

削除を確定

Delete で選択したカードを完全に削除します。削除した結果は復元できないため、慎重に確認してください。

— Cancel —

結果を残す

Cancel でカードはそのまま残ります。他のテイクとの比較が終わるまでは候補を残しておくほうが安全です。

— まとめ —
最終案をダウンロード → 不要なカードを整理 → セッション完了。これが標準的な締めの手順です。
