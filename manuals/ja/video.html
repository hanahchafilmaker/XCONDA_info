— 開始 —

Tools メニューを開く

メイン画面上部の Tools をクリックします。Xconda のすべての生成ツールは、この Tools メニューにまとめられています。

— メモ —
Video Generator は、動画制作ツールとして Tools メニュー内にあります。

— モデル —

Models — 動画エンジンを選択

画面上部の Models ドロップダウンから動画エンジンを選択します。選択肢は Veo 3.1 / Veo 3.1 Fast, Runway Gen-4.5, Kling 3.0 Pro / Kling OMNI, Grok Imagine Video, Vidu Q3、 Seedance 2.0 / Seedance 2.0 Fastです。（モデル構成は変更される場合があります — 最終更新 2026-04-28）

— メモ —
モデルごとに対応する解像度・長さ・機能が異なります。プロジェクトの要件に合わせて選んでください。

— Text to Video（テキストから動画）—

Text to video

上部の Text to video タブを選択します。次に Prompt フィールドをクリックし、生成したいシーンを描写します。解像度（480p / 720p / 1080p）、長さ、アスペクト比（モデルにより異なります）を設定できます。出力から除外したい要素は Negative Prompt に列挙してください。

— メモ —
安定した結果を得るには、シーン → アクション → カメラ/ライティングの順でプロンプトを書きます。不要な要素は Negative Prompt で明示的に除外してください。
005 — Text To VideoTEXT-TO-VIDEO
Chapter 06Image To Video
P. 006
06
— Image to Video（画像から動画）—

Image to video

上部の Image to video タブを選択します。開始ショットを Start frame に、 End frame にアップロードすると、その間のシーンを AI が生成します。 Reference Mode （Seedance 2.0 のみ）： Frame は画像を正確な開始/終了フレームとして使用し、 Reference はスタイル・雰囲気・構図の参照として使用します。

— メモ —
開始/終了画像は、カメラの雰囲気・構図・表情をそろえると、間のシーンが自然につながります。

— 仕様 —

モデル仕様

モデルごとに対応する解像度・長さ・アスペクト比・機能オプションが異なります。開始前に仕様を確認してください。 Multi-Shot は Kling 3.0 Pro と Kling OMNI専用です。（最終更新 2026-04-28）

— メモ —
正確な仕様は画面の表を参照してください。Veo 3.1 の Audio Sync、Seedance の Reference Mode など、モデルごとに得意分野があります。

— プロンプト例 —

プロンプト例

参考用のプロンプト例です（Text to Video の場合）： Text to Video: "A woman walks alone down a rain-soaked alley at night, neon signs reflecting on the wet pavement. She stops in front of a glass door, hesitates, then pushes it open — warm golden light spills out into the..." — シーン・アクション・雰囲気・ライティングを具体的に描写します。

— メモ —
良いプロンプトのコツは、 設定 → キャラクターの動作 → カメラワーク → ライティング/トーン を 1 文の流れにまとめることです。

Chapter 09Generate
P. 009
09
— 生成 —

Generate

すべての設定が完了したら、画面下部の黄色い Generate ボタンをクリックします。マルチショットの場合は、 Shots エリアで各ショットの長さを秒単位で設定し、 + Add Shot でショットを追加します。合計の長さは 15 秒以内に収めてください。1 回の生成で 50 credits を消費します（マルチショットは 180 credits）。Generate を押すと進行状況が表示されます。速度はモデルによって異なります。

— メモ —
Multi-Shot は 1 本の動画を複数のカットに分割する機能です。Kling 3.0 Pro と Kling OMNI でのみ利用できます。

— 結果 —

結果の確認と保存

生成が完了すると、結果が一覧で表示されます。右側のパネルには 日付 / 解像度 / アスペクト比 / 長さ / モデルが表示されます。再生ボタンでプレビュー、動画本体をクリックすると全画面になります。動画にカーソルを合わせると Save / Delete アイコンが現れます。Save はファイルをダウンロードし、右側の Share アイコンはアプリ外へ共有します。

— メモ —
結果はリストに蓄積されます。必要なものをダウンロードし、それ以外は削除するとワークスペースが整理されます。
