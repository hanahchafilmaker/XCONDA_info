— 目的 —

SpinAngle の機能

SpinAngle は1枚の画像を基準に、同じシーンを別の視点から生成します。カメラ位置を円で、視線の向きを矢印で記すと、AI がその印を読み取り、新しいカメラアングルからの写実的な画像を制作します。

— 理由 —

この機能を使う理由

再撮影や新しい 3D セットの構築なしで、同じ人物とシーンを異なる視点から試せます。複数のアングル候補（ストーリーボード、広告カット、ルックブック、映像プリビズ）を比較したいとき、制作時間が大きく減ります。

— 再撮影なし —

1枚から複数アングル

1枚の元画像から、同じ人物とシーンを 複数のカメラアングル に展開して比較できます。モデルやロケを呼び戻さずに案を増やせます。

— 3D セット不要 —

セットなしで視点変更

視点変更に物理的なセットも 3D モデリングも不要 — プリプロダクションのコンセプト検証コストが大きく下がります。

ヘッダーの説明は、2 つの印を描くとシステムがその正確な視点から写実的な画像を生成する、という意味です。

画面の基本構成

— ステータス —

Circle = カメラ / Arrow = 方向

上部の2つのステータス表示は、カメラ位置と方向が両方とも設定されたかを示します。最初は空で、円と矢印を描くと緑のチェックに変わります。

— Circle ステータス —

Circle = カメラ

キャンバスに円を描くと、 Circle = Camera 表示が 緑のチェックに変わり、カメラ位置が登録されたことを示します。

— Arrow ステータス —

Arrow = 方向

矢印を描くと、 Arrow = Direction 表示が緑のチェックに変わり、視線の向きが登録されたことを示します。

— 有効化 —
両方の表示が 緑のチェック に変わらないと Generate は有効になりません。

— Circle ツール —

Circle ツール

Circleを選び、画像の上に円を描いてカメラが置かれる位置を記します。円は新しい視点の基準点になります。

— 選択 —

Circle モードを有効化

下部ツールバーの Circle ボタンをクリックすると Circle モードになります。有効になるとキャンバスに円を描けます。

— 記入 —

カメラ位置を描く

画像の上をドラッグして円を描きます。この円が 新しい視点の基準点 を決めます — 被写体のどちら側から撮りたいかを考えて置きましょう。

— 配置のコツ —

被写体との関係で考える

円をどこに置くか（被写体の左・右・上・下）で結果のアングルが変わります。「カメラはここに座る」と想像しながら置くと、意図した結果になります。

— 意味 —
円の位置 = 仮想カメラの位置。被写体からの方向と距離を決めます。

— Arrow ツール —

Arrow ツール

Arrowを選び、画像の上に矢印を描いてカメラが見る方向を示します。円と矢印の両方がそろって初めて新しい視点を計算できるため、押す前に両方を描いてください Generate.

— 選択 —

Arrow モードを有効化

下部ツールバーの Arrow ボタンをクリックすると Arrow モードになります。有効になるとキャンバスに矢印を描けます。

— 記入 —

視線の向きを描く

円から被写体へ向かう矢印を描きます。矢印は カメラの視線 を表し、結果の構図を形づくります。

— 対の入力 —

Circle + Arrow = 新しい視点

AI が新しい視点を計算するには円と矢印の両方が必要です。両方を描いてから Generateを押します。片方だけでは Generate は無効のままです。

— 意味 —
矢印 = カメラがどこを見ているか。円が「どこから」なら、矢印は「何に向かって」です。

— 生成 —

Generate

Generate は、カメラ位置と方向が両方設定されると有効になります。現在のテスト画面では、1 回の生成に 6 クレジットを消費します。

— 条件 —

円と矢印の両方が必要

Circle = カメラ と Arrow = 方向 の両方が 緑のチェック にならないと Generate は有効になりません。

— コスト —

クレジットの消費

生成ごとに 6 クレジット を消費します（現在のテスト画面）。クレジット残高が不足していると生成は実行されません。

— ベストプラクティス —
再実行を減らすため、押す前にもう一度、円と矢印の位置を確認してから Generate を押しましょう。

— 確認 —

確認ダイアログ

Generate を押すと、「Would you like to generate an image?」という確認が開きます。 OK で生成を開始し、 Cancel で前の画面に戻ります。

— OK —

生成を開始

OK 実際の生成を開始し、クレジットを消費します。実行中は結果エリアに進行状況が表示されます。

— Cancel —

生成せずに戻る

Cancel 生成せずに前の画面に戻ります。描いた円と矢印は保持されるので、すぐに修正してやり直せます。

— 安全策 —
確認ステップは、意図しないクレジット消費を防ぐためにあります。内容を確認してから OK を押してください。

— 結果カード —

結果カード

生成が完了すると、新しい視点の画像が右の結果エリアにカードとして表示されます。生成を繰り返すと右エリアに積み重なり、アングル候補を比較できます。

— 表示 —

右に新しいカード

生成が完了するたびに、右の結果エリアに新しいカードが追加されます。カードの右下にダウンロードと削除のアイコンが表示されます。

— 積み重ね —

アングル候補が積み重なる

複数回の生成が積み重なり、同じシーンの 異なるアングル候補 を1画面で比較できます。

— ワークフロー —
候補を比較 → 最終案だけダウンロード → 残りを削除。これが効率的な締めの流れです。

— 結果確認 —

出力を確認する

結果は元の雰囲気を保ちながら、記入したカメラ位置と方向を反映し、新しいアングルからシーンを生成します。最終使用前に、顔・衣装・背景の歪み、被写体の向きが意図どおりか確認してください。

— 保持 —

元の雰囲気を保持

結果は元画像の 全体の雰囲気・トーン・色を保ちます。変わるのは視点だけで、シーンの空気感は一貫したままです。

— 適用 —

新しいカメラアングルを反映

円の位置と矢印の方向 が新しいカメラアングルとして反映されます。100% 一致しないこともあるため、複数生成して最良のものを選びましょう。

— 確認 —

歪みと向き

最終使用前に、 顔・衣装・背景の歪みと、被写体の視線や姿勢が意図どおりか確認します。不自然な場合は円と矢印の位置を調整して再生成します。

— チェック項目 —
顔の比率 · 衣装のディテール · 背景のパース · 被写体の向き — まずこの4点を確認します。

— 管理 —

ダウンロード / 削除

各結果カードの右下にダウンロードと削除のアイコンが表示されます。ダウンロードは生成結果を保存し、削除は選択した結果を一覧から取り除きます。

— ダウンロード —

ダウンロードアイコン

download icon を押すと、結果画像をローカルファイルとして保存します。アプリの外に持ち出す候補に使います。

— 削除 —

削除アイコン

delete icon で選択した結果を一覧から削除します。不採用のテイクを消すと結果パネルが整います。

— 位置 —
両方のアイコンは各結果カードの 右下に配置されています。

— 削除の確認 —

削除の確認

削除アイコンを押すと、「Are you sure you want to delete all selected media?」という確認が開きます。 OK で削除し、 Cancel で結果を残します。

— OK —

削除を確定

OK で選択したカードを完全に削除します。削除した結果は復元できないため、慎重に確認してください。

— Cancel —

結果を残す

Cancel でカードはそのまま残ります。他のアングルとの比較が終わるまでは候補を残しておくほうが安全です。

— まとめ —
最終案をダウンロード → 不要なカードを整理 → セッション完了。これが標準的な締めの手順です。
