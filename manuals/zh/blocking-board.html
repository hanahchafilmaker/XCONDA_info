— 概览 · 关于工具 —

Blocking Board 帮你解决什么

在生成视频之前，用来检查演员、空间与相机是否冲突的数字排练工具。

1
PLAN / 平面图
整理位置、路径与道具。
2
PREVIEW / 3D
播放场景，检查高度、视线与碰撞。
3
OUTPUT / 镜头
把结果作为时间轴与提示词延续下去。
— 说明 01 · 核心理念 —

在生成视频之前，Blocking Board 让你 确认演员、空间与相机不会冲突 —— 它就是数字排练工具。

— 说明 02 · 顺序 —

在平面图上设置位置与路径，再在 3D 舞台上检查高度与视线。结果会流入镜头、时间轴与提示词。

「开拍之前，先可视化检视并调整」

比自动生成更重要的，是 创造一个可检视的中间状态.

剧本→平面图→3D 舞台→镜头 / 输出

— 安装设置 · 本地网页应用 —

启动应用并准备工作区

Blocking Board 是一个本地网页应用。开始使用只需要项目文件夹和浏览器。

— 步骤 01 · 安装依赖 —

在仓库根目录运行 npm ci.

— 步骤 02 · 构建 —

npm run build —— 这会构建应用包。

— 步骤 03 · 本地服务器 —

node tools/static-server.js 8010 ，然后 localhost:8010 在浏览器中打开。

# 在仓库根目录运行
$ npm ci
$ npm run build
$ node tools/static-server.js 8010

# 在浏览器中打开
http://localhost:8010

请使用本地 HTTP 服务器，而不是双击文件直接打开。

— 输入 · 1-Click —

把剧本结构化，用 1-Click 生成草稿

把自然语言转成舞台数据。字段越清晰，结果越可靠。

— 步骤 01 · 输入 —

选择示例了解输入格式，或粘贴剧本。用动词描述动作，并区分静止姿势与移动。

— 步骤 02 · 空间 —

选择空间设置。若未指定，场景会从空空间开始。

— 步骤 03 · 1-Click —

1-Click 会生成演员、空间、路径与相机的草稿布局。请查看报告中的遗漏与警告。

— 注意 —

再次运行会用新的分析结果替换当前场景。 请先保存。

Scene / Title

Actors / Props

明确指定姓名、体型与互动对象。

数量 · 景别 · 运动
指定相机数量、景别与运动。

— 布置 · 空间 / 演员 / 路径 —

先布置空间，再放置演员与路径

自动布置只是起点。请调整空间、放置演员，然后在平面图上绘制路径。

— 步骤 01 · 空间 —

在左侧面板中选择 Add Object，选择类别，然后在平面图上放置墙体、门、窗与家具。

— 步骤 02 · 演员 —

放置演员并指定姓名、体型、起始位置与朝向。

— 步骤 03 · 路径 —

在平面图上点击路点来绘制路径。 Enter 确认， Esc 取消。

— 步骤 04 · 微调 —

在 3D 工具中， E 移动 · R 旋转 · T 缩放。 平面图网格 1 格 = 1 m —— 以此为尺度基准。

Chapter 07相机

— 相机 · 多机位 —

设计相机与景别

定义每台相机的用途，设定景别、视角、跟踪对象与运动。

— 说明 01 · 相机管理 —

在相机面板中管理 CAM1~4。为每台相机设定景别、视角（FOV）、跟踪对象与运动。

— 说明 02 · 景别 —

WIDE 框住演员全身， MEDIUM 用于对话， CLOSE 捕捉反应， OTS 用于过肩镜头。

— 说明 03 · 面板设置 —

确认镜头与 FOV、跟踪对象、相机运动、角度以及高度 Z（m）。

— 技巧 —

在考虑镜头数值之前， 先确定这个镜头需要呈现什么。.

— 时间 · 镜头与台词 —

在时间轴上放置镜头与台词

镜头是故事时间的单位。请调整演员动作与台词，避免不自然的重叠。

— 步骤 01 · 镜头 —

在主时间轴添加镜头，设定时长与相机。检查镜头之间的空隙与连贯性警告。

— 步骤 02 · 台词 —

台词在独立轨道上管理。 确认谁在何时说话， 让台词与动作分段对齐。

— 步骤 03 · 播放 —

使用下方时间轴的播放、暂停与拖动。在特定帧检查姿势，并从整体动作检查碰撞。

— 说明 · FPS 与曲线 —

FPS 决定最终视频的速度，曲线则调整运动速度的变化。

— 检查 01 · 视线 —

确认每台相机的视锥朝向其目标演员。

— 检查 02 · 轴线 —

注意演员与相机之间的动作轴线 —— 也就是 180 度轴线。.

— 检查 03 · 碰撞 —

检查演员是否重叠或穿墙，以及是否存在无法到达的路径。

— Fix —

若导演检查出现警告，回到布置或路径设置修正后再次播放场景。

— 总结 · 收尾 —

好的调度能给流程中的下一位带来信心

回顾从剧本到导出的单个场景检视步骤。

单个场景的流程

剧本 → 空间 → 演员 → 相机 → 时间 → 检查 → 导出。若发现问题，回到之前的步骤修改。

进入场景时

按时间段书写事件与动作，并对演员、道具与相机使用一致的名称。

评审时

在平面图上规划路径，并在 3D 中播放场景。解决视线、碰撞与连贯性警告。

交付时

检视后导出英文提示词、镜头清单、PNG 与镜头手册 PDF。最终输入按「场景 / 标题 / 演员 / 道具 / 相机 / 时间 · 动作」的顺序组织。
