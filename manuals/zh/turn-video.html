— 概览 · 端到端流程 —

工作流程一览

按顺序走完顶部的四个阶段：1. PRE-PRODUCTION → 2. LOCATION_SCOUTING → 3. CAMERA_TEST → 4. MASTER_STILL。

1
PRE-PRODUCTION
从参考图或文字描述创建 360° 空间。（视频 4）
2
LOCATION_SCOUTING
在 3D Preview 中旋转视角，调整房间尺寸或墙面。（视频 1、2、4）
3
CAMERA_TEST
在 Freeze Frame 中加入主体与风格，生成关键图像。（视频 3）
4
MASTER_STILL
最终母版静帧阶段。演示视频中没有展示该阶段。
— 步骤 01 —

视频中展示的完整顺序如下： 上传一张图像 → Analyze Space → Confirm Room Layout （标注墙面范围）→ 生成 360° 空间 → 打开 3D Preview →（如需）调整房间尺寸 / 编辑墙面 → FREEZE FRAME → 在 Step 3 中添加方向 → 生成关键图像.

— 步骤 02 —

顶部的阶段标签会随进度逐步解锁。视频开始时只有 1. PRE-PRODUCTION 处于激活状态；空间生成后， 2. LOCATION_SCOUTING 变为激活。经过 Freeze Frame 后， 3. CAMERA_TEST 变为激活。

上传 FRONT 图像→ Analyze Space→ Confirm Room Layout→ 360° 空间→ 3D Preview / Wall Edit→ FREEZE FRAME→ 关键图像
— 说明 —

依据演示旁白 — ①“Turn 用一张图像创建虚拟摄影棚布景。”②“如果房间太大，就减小宽度和进深；也可以把天花板调高。”③“在 Wall Edit 中可以自由添加或移除物件。”④“设定构图、写好提示词，再加上主体与服装照片，就能完成关键图像。”

— 步骤 1 · 空间搭建 —

用一张图像创建 360° 空间

一张韩屋照片加上一次点击 “Analyze Space”，就能生成可自由旋转的 3D 空间。

— 步骤 01 · 上传图像 —

在 FRONT 槽位上传韩屋照片。上传后，右侧的大按钮会由 Create Space from Description 变为 Analyze Space。左上角会出现保存提示，例如 “Auto-saved at 9:34 AM”。

— 步骤 02 · 解析空间 —

Analyze Space 会打开 “Confirm Room Layout” 对话框，其中包含四项估算值： Room Width (m) 8 Room Depth (m) 6 Ceiling Height (m) 3.5 Camera Height (m) 1.2注意：“These are not exact measurements taken from a single photo. Please review the estimated dimensions and wall area.”

— 步骤 03 · 标注墙面范围 —

“Drag the four corners to select only the wall.” 拖动图像上的四个紫色控制点，使其与 地面与墙面的交界线 对齐（旁白：“Select Space，然后像这样把控制点移到地面与墙面的交界处。”）。右侧的 “Unwrapped Front Wall Result” 会立即确认选区是否正确。

— 步骤 04 · 组合提示词 —

勾选： Unwarp the selected front-wall area and use it as a generation reference。然后检查 “Space Design · Expand from One Reference” 区块中的 Common Wall Finish, Common Molding & Wood Finish 提示词，再开始生成。

— 结果 —

生成完成后，会得到一个可自由旋转的虚拟 3D 空间，并打开 2. LOCATION_SCOUTING 标签。

— 房间尺寸 · 相机 —

调整房间尺寸与相机

无需重新生成空间，即可就地调整房间宽度、进深与天花板高度。

— 打开 —

选择绿色的 Room Size · Camera 按钮，即可打开 “Room Size & Camera” 对话框。这里同样提供四个字段（房间宽度、进深、天花板高度与相机高度）。

— 缩小房间 —

正如旁白所说，“如果房间太大”， Room Width 8→4, Room Depth 6→4 就是输入的缩小示例值。对话框说明：“天花板横梁与间接照明是通过延伸照片上部元素推断的。地面假定为适合席坐的木地板。所有类家具元素都设计为与墙面整合的结构。”

— 抬高天花板 —

天花板高度 可以在保持同一房间的前提下抬高天花板。正如旁白所说，“也可以把天花板调高”。

— 应用 —

紫色的 Apply Room Size · No Additional Generation 按钮会应用这些设置， 不会生成新图像， 而是使用现有的表面图像，仅反映新的比例（旁边的注记：“Uses existing surface images”）。在右侧选择 Close 即可取消。

— 步骤 2 · 预览 —

在 3D 预览中查看

— 步骤 2 · 墙面编辑 —

墙面编辑：按方向修改物件

在六张方向卡片上组合参考图与画笔，添加或移除想要的物件。

— 进入 —

在左上角选择 Wall Edit 后，会并排显示六张方向卡片（LEFT / FRONT / RIGHT / BACK / UP (ZENITH) / DOWN）。旁白说：“选择 Wall Edit，就可以在这里自由添加或移除任何物件。”

— FACE REFERENCE —

每张卡片都有 + Add Reference Image （DRAG & DROP）区域。添加图像后，会出现 REF LINKED 徽章、 ACTIVE 标签与“Applied directly to INPAINT and REGEN”的注记，以及 Apply As Is / Change / CLEAR 这些控件。

— 画笔 —

在图像上拖动即可涂抹 红色蒙版。用 BRUSH 40PX 滑块调整其大小。

— 操作按钮 —

每张卡片底部有四个按钮： INPAINT (REF) （紫色 = 编辑蒙版区域）· REGEN (REF) （橙色 = 重新生成整个面）· CLEAR （清除蒙版）· REPLACE （绿色 = 替换）。下方的 Reference instructions or requested changes (optional)… 可以输入随操作一起发送的指令。

Chapter 07物件与壁纸

— 编辑示例 —

添加物件并替换壁纸

一张参考图既能引导道具摆放，也能替换整面壁纸。

— 示例 1 · 放置物件 —

在 LEFT 卡片上添加 蓝色绣球花的参考图，然后涂抹蒙版并执行编辑。3D Preview 的架子上会出现花瓶 —“把准备好的参考图放到书架上看看？可以看到它很自然地摆在架子上。”

— 示例 2 · 替换壁纸 —

在 BACK 卡片上添加 向日葵壁纸参考图，输入类似“移除线脚，只把壁纸换成向日葵壁纸”的指令并执行。旁白说：“可以看到所有壁纸都变成了向日葵。”旋转视角，确认整面墙在整个 3D 空间中保持一致。

— 关键区别 —

INPAINT 只编辑涂抹的区域（添加、移除或替换物件）， REGEN 则重新生成该方向的整张图像， REPLACE 用参考图替换选中的区域， CLEAR 只清除蒙版。

— 步骤 3 · 关键图像 —

相机测试：创建关键图像

把构图提示词、主体照片、服装照片与电影风格组合起来，生成关键图像。

— 进入 —

在步骤 2 中选择 FREEZE FRAME 就会打开 3. CAMERA_TEST，选定的构图会显示在中央。

— 方向 —

PRODUCTION: SUBJECT & CASTING 在这里输入主体的动作与情绪。视频示例：“一位女性带着悲伤的表情捧着一件陶瓷器皿。”

— CINEMA STYLE —

八种风格 — Normal Hollywood （默认选中） Korean Japanese Chinese Noir Neon-Punk Anime Style.

— Cast —

使用 FACE ID CALIBRATION (LIKENESS PRIORITY: MAX, UPLOAD）上传主体照片，再用 OUTFIT REFERENCE (ADD IMAGE）添加服装照片。旁白说：“加上主体照片和服装照片，就完成了关键图像。”

— 生成与保存 —

右侧有三个按钮： DOWNLOAD FREEZE FRAME （保存参考帧）· GENERATE_STILL_1K （白色）· GENERATE_STILL_2K (HQ) （深蓝）。2K 的结果就是用于视频的最终关键图像。

— 技巧 · 避免常见错误 —

常见错误与技巧

演示视频中给出的六条实用技巧。

— 技巧 01 —

上传图像后，首页按钮会由 “Create Space from Description” → “Analyze Space”。该标签变化属于正常现象，直接选择它进入 “Confirm Room Layout” 即可。

— 技巧 02 —

要得到干净的墙面展开图，请 四个角全部对准地面与墙面的交界线。如果包含过多天花板横梁，就把控制点往下移。

— 技巧 03 —

改变房间尺寸时，道具会保持在原位。 'Apply Room Size · No Additional Generation' 只应用比例而不重新生成，因此可以放心试不同数值，不必担心积分。

— 技巧 04 —

画笔要比想修改的物件 稍大一些 ，然后再涂抹蒙版。用 BRUSH 40PX 滑块调整大小。如果涂错区域，选择 CLEAR 清除即可。

— 技巧 05 —

放置物件用 INPAINT；替换壁纸这类整个面用 关联参考图并附上指令；结果不理想时用 REGEN。每种工具用途不同，请按目的选择。

— 技巧 06 —

关键图像按这个顺序制作： 构图（提示词）→ 主体照片 → 服装照片。同时使用 FACE ID 与 OUTFIT，可以同时保留面部与服装。

— 总结 · 收尾 —

最终总结

四段演示视频中确认的 Turn 全部内容。

Turn 是什么

Turn 是一个本地电影感工作空间，可以从一张图像或一段描述创建可自由旋转的 360° 3D 虚拟摄影棚布景。室内墙面会做透视校正；室外场景会扩展为包含景物、天空与地面的立方体贴图。

视频中确认的主要流程

① 上传 FRONT 图像 → Analyze Space → Confirm Room Layout（检查尺寸并拖动四个角）→ 生成 360° 空间。② 在 3D Preview 中旋转与缩放；按需调整房间尺寸或相机，并编辑墙面（参考图、画笔、INPAINT / REGEN / REPLACE）。③ FREEZE FRAME → 在步骤 3 中加入方向、CINEMA STYLE 与主体/服装照片 → GENERATE_STILL → 关键图像。

理解输出结果

Freeze Frame = 添加方向之前的参考构图截图（DOWNLOAD FREEZE FRAME）。Final Still = 应用了主体、风格与光线后的最终图像（GENERATE_STILL_1K / 2K HQ）。两者用途不同，因此有各自的下载按钮。

注意

本指南依据四段演示视频（About Turn 18 秒 · Adjusting Room Size 10 秒 · Editing Objects 27 秒 · Creating a Key Image 7 秒）的画面与旁白编写。由于视频分辨率所限，包括 “Generate the Desired View” 在内的部分标签为推测。
