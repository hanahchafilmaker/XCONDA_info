— 目的 —

ClothSwap 的功能

ClothSwap 可让你在源图像上涂抹人物服装区域，并用参考服装的风格进行替换。面部、姿态和背景保持不变，而衣物的颜色、形状和氛围会改变。

Chapter 03理由

— 理由 —

为什么使用此功能？

无需重拍即可为同一人物套用多种服装方案。加快服装选择、造型方向和广告 / lookbook 概念的前期决策。

— 保持人物特征 —

同一人物，不同服装

面部、姿态和背景与原图完全一致，只有衣物改变。无需重拍即可为同一模特扩展造型方案。

— 更快决策 —

在制作前比较方案

几分钟内即可并排可视化色调、轮廓和材质方向。内部评审和客户审批轮次会大幅减少。

何时使用

Chapter 07源图像
P. 007
07
— 原图 —

上传源图像

Drop Image Here 或 Click to Upload 来载入要更换服装的图像。

— 上传 —

拖放或点击

把文件拖入图像区域，或点击该区域选择本地文件。上传后，预览会替换占位图。

— 指南 —

什么样的源图算好

当整件衣物可见，且 手臂与身体的边界清晰时结果最稳定。强烈阴影、过度裁切或极端姿态扭曲都会降低输出质量。

— 重置 —

移除上传

上传的图像可用右上角的 X 按钮移除，然后换另一个文件。

— 建议 —
正面、全身、光线均匀且背景干净的图像能得到最可靠的结果。

Chapter 08画笔大小
P. 008
08
— 画笔 —

调整画笔大小

Brush Size 滑块设定画笔宽度。大面积服装用大笔，衣领、袖口等精细边缘用小笔。

— 大 —

快速覆盖大范围

上衣中央或裤子等大片平坦区域使用较大的画笔，能让大面积的蒙版操作更高效。

— 小 —

边缘更精细

衣领、袖口、腰线、纽扣排等精细边缘改用较小的画笔。边缘处理粗糙会让输出中残留原衣物痕迹。

— 技巧 —
先用大笔快速填满内部，再用小笔描出轮廓 —— 这个两遍法最高效。

Chapter 09蒙版
P. 009
09
— 蒙版 —

涂抹服装区域

直接在源图像上涂抹想替换的服装部分。只有被涂抹的区域会被替换，漏涂的地方可能保留原衣物。

— 规则 —

只有涂抹区域会被替换

被涂抹的区域正是被替换的部分。 漏涂的地方会保留原衣物，因此请仔细覆盖整件服装。

— 覆盖范围 —

服装本体 + 边缘

不仅包括本体，还包括衣领、袖口和下摆。边缘漏掉会让原衣物的轮廓在输出中显现。

— 应避免 —

不要涂抹面部、手和背景

让面部、手、头发和背景留在画笔范围之外。涂抹这些部位可能让人物外观产生意外的变形。

— 检查清单 —
上衣、下装、衣领、袖口、纽扣排、下摆 —— 生成前确认这些都在蒙版内。

— 参考 —

Reference Clothing 位置

把新的服装图像上传到 Reference Clothing 位置。若没有参考， Generate 按钮会保持不可用。

— 输入 —

参考位置

下方的 Reference Clothing 区域显示一个空的衣架式位置。把想套用的服装图像上传到这个位置。

— 激活 —

Generate 何时变为可用

Generate 只在三种输入齐备时才激活： 源图像、画笔蒙版和参考服装。缺任何一项按钮都会保持不可用。

— 消耗 —
在当前测试界面，每次生成使用 6 积分.

Chapter 11上传

— 上传 —

上传参考服装

参考图像承载新衣物的颜色、形状、质感和风格方向。你选择的图像会直接决定输出氛围。

— 作用 —

风格信号的载体

参考图像把 颜色、形状、质感和风格方向 传递给结果。可以把它理解为一条视觉指令：「让这个人穿上这类衣物」。

— 推荐格式 —

衣物单独成图最佳

人台拍摄或平铺拍摄中衣物单独呈现的图像效果最好。参考图里无关细节越多，越容易把噪声带进结果。

— 替换 —

取消或更换上传

已上传的参考图可通过右上角的 X 按钮移除，并换成另一张图像。

— 建议 —
背景干净、完整轮廓收在一帧内的图像能得到最稳定的结果。

— 生成 —

Generate

Generate 在源图像、画笔蒙版和参考服装都齐备后按下。在当前测试界面，每次生成使用 6 积分。

— 条件 —

三种输入齐备

源图像, 画笔蒙版和 Reference Clothing 必须全部填写， Generate 才会激活。

— 消耗 —

积分扣除

每次生成扣除 6 积分 （当前测试界面）。若积分余额不足则不会执行生成。

— 最佳实践 —
按下之前再确认一次蒙版和参考图，然后 Generate —— 可以减少重复运行。

— 确认 —

确认对话框

Generate 会打开「Would you like to generate an image?」确认框。 OK 开始生成， Cancel 返回上一界面。

— OK —

开始生成

OK 会真正启动生成并扣除积分。运行过程中结果区域会显示进度。

— Cancel —

不生成直接返回

Cancel 不生成直接返回上一界面。输入内容会保留，因此可以立即修改重试。

— 安全 —
确认步骤用于避免意外消耗积分。确认内容后再按 OK。

— 结果卡片 —

查看结果卡片

生成完成后，结果图像会以卡片形式出现在右侧结果区域。重复生成会向下堆叠，便于并排比较。

— 显示 —

右侧出现新卡片

每次生成完成后，右侧结果区域都会新增一张卡片。卡片以缩略图显示结果图像。

— 堆叠 —

比较多次结果

多次生成会向下堆叠，可在同一视图比较套用到同一模特的不同服装方案。

— 工作流程 —
比较候选 → 只下载最终选择 → 删除其余。这就是高效的收尾流程。

Chapter 15查看
P. 015

— 查看结果 —

查看输出

结果保留源人物的面部和姿态，同时把参考服装的颜色与形状应用到蒙版区域。最终使用前，请检查衣物边界、袖子、领口以及重叠的物品。

— 保持 —

面部与姿态保持不变

输出保留源人物的 面部与姿态，而服装区域则采用参考服装的颜色与形状。

— 应用 —

参考的颜色与形状

参考衣物的颜色、轮廓和细节会转移到结果中。但不一定 100% 一致 —— 多生成几次并挑选最好的一版。

— 检查 —

边缘与重叠

最终使用前，确认 衣物边界、袖子、领口，以及包带等重叠物品 是否渲染自然。若有不自然之处，请修正蒙版后重新生成。

— 检查点 —
衣物边界 · 袖口 · 领口 · 包与配饰的重叠 —— 先检查这些。

— 管理 —

下载 / 删除

将鼠标悬停在结果卡片上会显示下载和删除图标。下载会保存结果图像；垃圾桶图标会删除所选结果。

— 下载 —

下载图标

download icon 会把结果图像保存为本地文件。适合准备带到应用之外的候选图。

— 删除 —

垃圾桶图标

trash icon 会删除所选结果卡片。清除不采用的结果能让结果面板保持整洁。

— 显示 —
图标只在悬停时出现 —— 平时卡片是干净的纯图缩略图。

Chapter 17删除确认

— 删除确认 —

删除确认

按下垃圾桶图标会打开「Delete this media?」确认框。 Delete 会删除它； Cancel 会保留结果。

— 删除 —

确认删除

Delete 会永久删除所选卡片。已删除的结果无法恢复，请谨慎确认。

— Cancel —

保留结果

Cancel 会让卡片保持不变。在与其他结果比较完成之前，保留候选更安全。

— 收尾 —
下载最终选择 → 清理不需要的卡片 → 会话结束。这是标准的收尾流程。
