SpinAngle 的功能

SpinAngle 以一张图像为基础，从不同视角生成同一场景。用圆圈标记机位、用箭头标记视线方向 —— AI 读取这些标记，并从那个新机位产出写实图像。

— 理由 —

为什么使用此功能？

无需重拍，也无需搭建新的 3D 场景，就能从不同视角测试同一人物与场景。当需要比较多个角度候选 —— 分镜、广告镜头、lookbook、视频预演 —— 制作时间会大幅缩短。

— 无需重拍 —

一张图像多个角度

从单张源图像出发，把同一人物与场景转换为 多个相机角度 进行比较。无需召回模特或场地即可扩展方案。

— 无需 3D 场景 —

无需布景即可换视角

视角变化不需要实体布景或 3D 建模 —— 前期概念验证的成本大幅下降。

— 使用场景 —

何时使用

当你想把正面镜头改为低角度或侧面，或围绕人物 / 商品镜头移动机位时，使用 SpinAngle。非常适合在保持场景氛围的同时寻找更有动感的镜头，或一次向客户展示多个角度候选。

快速验证相机角度候选
快速比较同一场景的不同视角 —— 分镜、商品 / 人像镜头、电影感预演。

点击图标

点击图标会打开 SpinAngle 工作区。标题显示 SpinAngle ，并附说明「画一个圆标记机位，画一个箭头指示方向」。

— 标题栏 —
标题栏说明：两个标记都画好后，系统会从那个精确视角产出写实图像。

什么样的源图算好

— 状态 —

Circle = 机位 / Arrow = 方向

顶部的两个状态指示器显示机位与方向是否都已设定。它们初始为空，画好圆和箭头后会变成绿色对勾。

— Circle 状态 —

Circle = 机位

在画布上画好圆后， Circle = Camera 指示器会切换为 绿色对勾，表示机位已登记。

— Arrow 状态 —

Arrow = 方向

画好箭头后， Arrow = Direction 指示器会切换为绿色对勾，表示视线方向已登记。

— 激活 —
两个指示器都必须变成 绿色对勾 ， Generate 才会激活。

— Circle 工具 —

Circle 工具

Circle，然后在图像上画一个圆，标记相机的所在位置。这个圆是新视角的锚点。

— 选择 —

启用 Circle 模式

点击底部工具栏的 Circle 按钮进入 Circle 模式。激活后即可在画布上画圆。

— 标记 —

画出机位

在图像上拖动即可画圆。这个圆定义了 新视角的锚点 —— 放置时思考你希望镜头从主体的哪一侧来。

— 放置技巧 —

以主体为参照思考

圆放在哪里 —— 主体的左、右、上、下 —— 会改变最终的机位。放置时想象「相机就坐在这里」，结果最符合意图。

— 含义 —
圆的位置 = 虚拟相机的位置。它决定相对主体的方向与距离。

— Arrow 工具 —

Arrow 工具

Arrow，然后在图像上画一个箭头，指示相机看向的方向。只有圆和箭头都存在时才能计算新视角，因此按下前请把两者都画好 Generate.

— 选择 —

启用 Arrow 模式

点击底部工具栏的 Arrow 按钮进入 Arrow 模式。激活后即可在画布上画箭头。

— 标记 —

画出视线方向

从圆向主体画一个箭头。箭头代表 相机的视线 ，并塑造结果的构图。

— 成对输入 —

Circle + Arrow = 新视角

AI 计算新视角需要圆和箭头同时存在。两者都画好后再按下 Generate。只有一个标记时，Generate 保持不可用。

— 含义 —
箭头 = 相机在看向哪里。如果圆是「从哪里」，箭头就是「朝向什么」。

工具按钮

重置标记

从画布上删除圆和箭头。用于重做位置与方向。源图像保持不变。

替换源图

按下 New Image 会把当前源图像换成另一张，从而用不同图像重新开始。之前画的圆和箭头会被重置。

— 生成 —

Generate

Generate 在机位与方向都设定后才会激活。在当前测试界面，每次生成使用 6 积分。

— 条件 —

圆和箭头都必需

Circle = 机位 和 Arrow = 方向 都必须显示 绿色对勾 ，Generate 才会激活。

— 消耗 —

积分扣除

每次生成扣除 6 积分 （当前测试界面）。若积分余额不足则不会执行生成。

— 最佳实践 —
为减少重复运行，按下前再确认一次圆和箭头的位置，然后 Generate 。

— 确认 —

确认对话框

Generate 会打开「Would you like to generate an image?」确认框。 OK 开始生成； Cancel 返回上一界面。

— OK —

开始生成

OK 会真正启动生成并扣除积分。运行过程中结果区域会显示进度。

— Cancel —

不生成直接返回

Cancel 不生成直接返回上一界面。你画的圆和箭头都会保留，因此可以立即修改重试。

— 安全 —
确认步骤用于避免意外消耗积分。确认内容后再按 OK。

— 结果卡片 —

结果卡片

生成完成后，新视角的图像会以卡片形式出现在右侧结果区域。重复生成会在右侧区域堆叠，便于比较角度候选。

— 显示 —

右侧出现新卡片

每次生成完成后，右侧结果区域都会新增一张卡片。卡片右下角会显示下载和删除图标。

— 堆叠 —

角度候选不断累积

多次生成会堆叠，可在同一视图比较同一场景的 不同角度候选 。

— 工作流程 —
比较候选 → 只下载最终选择 → 删除其余。这就是高效的收尾流程。

— 查看结果 —

查看输出

结果保留原有的氛围，同时反映你标记的机位与方向，从新角度生成场景。最终使用前，请确认面部、服装、背景变形以及主体朝向符合你的意图。

— 保持 —

保持原有氛围

结果保留源图的 整体氛围、调性与色彩。只有视角改变 —— 场景的空气感保持一致。

— 应用 —

反映新的相机角度

圆的位置与箭头的方向 会作为新的相机角度反映出来。结果不一定 100% 一致 —— 多生成几版并挑选最好的一版。

— 检查 —

变形与朝向

最终使用前，确认 面部、服装和背景的变形以及主体的视线与姿态符合意图。若有异常，调整圆与箭头的位置后重新生成。

— 检查点 —
面部比例 · 服装细节 · 背景透视 · 主体朝向 —— 先检查这四项。

— 管理 —

下载 / 删除

每张结果卡片的右下角都会显示下载和删除图标。下载会保存生成结果；删除会把所选结果从列表中移除。

— 下载 —

下载图标

download icon 会把结果图像保存为本地文件。适合准备带到应用之外的候选图。

— 删除 —

删除图标

delete icon 会把所选结果从列表中移除。清除不采用的结果能让结果面板保持整洁。

— 位置 —
两个图标都位于每张结果卡片的 bottom-right 右下角

— 删除确认 —

删除确认

按下删除图标会打开「Are you sure you want to delete all selected media?」确认框。 OK 会删除它； Cancel 会保留结果。

— OK —

确认删除

OK 会永久删除所选卡片。已删除的结果无法恢复，请谨慎确认。

— Cancel —

保留结果

Cancel 会让卡片保持不变。在与其他角度比较完成之前，保留候选更安全。

— 收尾 —
下载最终选择 → 清理不需要的卡片 → 会话结束。这是标准的收尾流程。
