Chapter 02进入

02
— 进入 —

打开 Directors Sequence

点击左侧竖排边栏中的第 16 个图标。

— 步骤 01 —

点击边栏第 16 个图标

点击左侧竖排边栏中的第 16 个图标，即可打开 Directors Sequence 工作区。

002 — 进入打开
Chapter 03Key Frame
P. 003
03
— 关键帧 —

上传关键帧

点击 KEY FRAME 区域的空上传框，或点击 New Key Frame 按钮上传基础图像。

— 步骤 01 —

点击上传框或 New Key Frame

点击 KEY FRAME 区域的空上传框，或点击 New Key Frame 按钮上传基础图像。

— 作用 —

用作基础帧

所上传的图像将作为 Directors Sequence 生成连续场景时的基础帧。

— 必填 —
如果缺少关键帧，Generate 按钮将不可用。
003 — 关键帧上传
Chapter 04剧情梗概
P. 004
04
— 剧情梗概 · 可选 —

输入剧情梗概

点击空白字段，输入故事、氛围和场景设定。该字段为可选项。

— 步骤 01 —

点击并输入

点击 SYNOPSIS 字段，输入想要生成的故事、氛围和设定。

— 可选 —

非必填字段

这是可选的输入字段，可以留空。

004 — 剧情梗概可选
Chapter 05Directors Note
P. 005
05
— Directors Note（导演备注）—

输入 Directors Note

点击空白字段，输入或编辑要在下一个场景中体现的导演备注。

— 步骤 01 —

点击并输入或编辑

点击 DIRECTORS NOTE 字段，输入或编辑要在下一个场景中体现的导演备注。

— 默认值 —

已提供默认值

默认值为 “make the next scene with high cinematic tension”。可根据需要修改。

Chapter 06Generate
P. 006
06
— 生成 —

点击 Generate 按钮

完成 KEY FRAME 上传和输入设置后，点击底部的黄色 Generate 按钮。

— 步骤 01 —

点击 Generate

完成 KEY FRAME 上传和输入设置后，点击底部的黄色 Generate 按钮，即开始生成 8 个连续场景。

— 必填 —
如果缺少 KEY FRAME，Generate 按钮将不可用。

查看 8 个场景的结果
