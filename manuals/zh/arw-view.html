— 目的 —

Arrow View 能做什么

从单张图像中生成 多种相机角度视图 。在图像上绘制箭头，AI 便会生成从该方向看到的场景。 传统方式：在 3D 软件中调整相机角度，或依赖需要空间推理的其他 AI 角度工具。 Arrow View 的方式：在图像上画一个箭头即可。无需 3D 知识，完全直观。

— 说明 —
跳过 3D 建模、渲染和空间推理 —— 一个箭头就能改变视角。

— 使用场景 —

使用场景

1. 商品图角度扩展 — 把单张正面商品图扩展为俯视、侧视、45° 等角度。 2. 俯视航拍生成 — 获得生成式 AI 一向薄弱的高精度俯视图。 3. 分镜角度变化 — 在分镜制作中从多个相机角度呈现同一场景。 4. 建筑 / 室内视角转换 — 从不同视角重构空间图像。 5. 广告创意变体 — 用一张原图制作横幅、海报和社媒素材。

— 说明 —
最适用的场景是 一个镜头 → 多种角度 —— 商品、俯视图、分镜、空间表现和广告创意等。

Chapter 04功能

— 功能 —

Arrow View 核心功能

用箭头指定视角 — 在图像上绘制箭头即可直观设定相机方向，无需 3D 知识。 自由角度生成 — 俯视、仰视、侧视、斜向等任意视角变化都可以实现。 保留原有色调 — 原图的色彩、光线和质感保持不变，只改变视角。

— 说明 —
三大支柱： 方向指定 → 视角转换 → 色调保留.

Chapter 05技巧
P. 005
05
— 技巧 —

使用技巧

箭头的绘制：起点 → 终点即相机的移动方向。箭头短则角度变化小，箭头长则变化更大。箭头方向越明确，结果越准确。 优质原图：主体清晰、背景简洁、分辨率高。 结果可能不稳定的情况：要求暴露原图中不可见区域的极端角度变化、背景杂乱，或主体的关键面在原图中不可见时。

— 说明 —
短而清晰的箭头 + 干净的原图 + 合理的角度变化 能得到最可靠的结果。

— 进入 —

打开 Arrow View

点击左侧竖排边栏的 第 15 个图标 。该图标是一个 向右的箭头。点击后会打开 Arrow View 工作区。

— 说明 —
Xconda 的边栏按固定顺序排列带有专属图标的工具，Arrow View 就是向右箭头的图标。

— 上传 —

上传图像

点击上传区域选择图像。界面会显示 “Upload an image to get started”。上传后原图会显示在编辑区域。如果没有图像， Generate 按钮将保持不可用。

— 说明 —
没有图像就无法继续 —— 请先上传。

— 绘制 —

绘制箭头方向

在图像上拖动即可绘制箭头。视角会沿箭头 从起点到终点变化。绘制后，状态会显示 “Draw arrow direction” ，并且 Generate 按钮被激活。没有箭头时，Generate 保持不可用。

— 说明 —
图像和箭头两者齐备，Generate 才会启用。

— 重置 —

Clear Arrow / New Image

Clear Arrow — 删除当前在图像上绘制的箭头。 New Image — 将已上传的图像替换为另一张。若想重新绘制方向，请点击 Clear Arrow 并在图像上绘制新的箭头。

— 说明 —
在同一张图上换方向请用 Clear Arrow；换一张原图重来请用 New Image。

— 查看结果 —

查看结果

生成完成后，结果显示在 右侧结果区域。 带箭头的原图 会保留在左侧，便于对照方向与输出。

— 说明 —
对照左侧（原图 + 箭头）与右侧（结果），确认视角是否符合预期。

— 重做 —

编辑 / 重做

如果结果与预期方向不符，请点击 Clear Arrow。删除旧箭头并在正确方向上绘制新箭头。若要从另一张原图开始，请点击 New Image.

— 说明 —
标准做法是多次生成，变化箭头的长度和角度，然后挑选最佳结果。
