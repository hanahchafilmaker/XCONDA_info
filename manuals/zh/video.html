Models — 选择视频引擎

点击 Models 下拉菜单选择视频引擎。可选引擎包括 Veo 3.1 / Veo 3.1 Fast, Runway Gen-4.5, Kling 3.0 Pro / Kling OMNI, Grok Imagine Video, Vidu Q3、 Seedance 2.0 / Seedance 2.0 Fast。（模型阵容可能变动 — 最后更新 2026-04-28）

— 说明 —
各模型在支持的分辨率、时长和功能上有所不同，请根据项目需求选择。

— Text to Video（文本生成视频）—

Text to video

选择 Text to video 标签页。点击 Prompt 字段，描述想要生成的场景。可以设置分辨率（480p / 720p / 1080p）、时长和画面比例（因模型而异）。如需排除某些元素，请使用 Negative Prompt 列出要排除的内容。

— 说明 —
为获得稳定结果，请按场景 → 动作 → 镜头/光线的顺序编写提示词。可使用 Negative Prompt 强制排除不想要的元素。

— Image to Video（图像生成视频）—

Image to video

选择 Image to video 标签页。将开场镜头上传到 Start frame ，将结束镜头上传到 End frame ，AI 会生成两者之间的场景。 Reference Mode （仅限 Seedance 2.0）： Frame 会将图像作为精确的起始/结束帧， Reference 则将其作为风格、氛围和构图的参考。

— 说明 —
请让起始/结束图像保持一致的镜头氛围、构图和表情，这样中间场景才能自然衔接。

模型规格

各模型在支持的分辨率、时长、画面比例和功能选项上有所不同，开始前请确认规格。 Multi-Shot 仅 Kling 3.0 Pro 和 Kling OMNI支持。（最后更新 2026-04-28）

准确规格请参阅界面上的表格。每个模型各有强项，例如 Veo 3.1 的 Audio Sync、Seedance 的 Reference Mode 等。

— 提示词示例 —

提示词示例

以下为参考用提示词示例（Text to Video）： Text to Video: "A woman walks alone down a rain-soaked alley at night, neon signs reflecting on the wet pavement. She stops in front of a glass door, hesitates, then pushes it open — warm golden light spills out into the..." — 请具体描写场景、动作、氛围和光线。

— 说明 —
优秀提示词的关键：把 场景 → 角色动作 → 镜头运动 → 光线/影调 融入一个流畅的句子中。

— 生成 —

Generate

所有设置就绪后，点击底部的黄色 Generate 按钮。多镜头（multi-shot）时，在 Shots 区域以秒为单位设置每个镜头的时长，并使用 + Add Shot 添加更多镜头。总时长必须控制在 15 秒以内。每次生成消耗 50 credits （多镜头为 180 credits）。按下 Generate 后会显示进度，速度因模型而异。

— 说明 —
Multi-Shot 可将一段视频拆分为多个镜头，仅在 Kling 3.0 Pro 和 Kling OMNI 上可用。

— 结果 —

查看并保存结果

生成完成后，结果会以列表形式显示。右侧面板显示 日期 / 分辨率 / 画面比例 / 时长 / 模型。点击播放可预览，点击视频本身可全屏。将鼠标悬停在视频上会显示 Save / Delete 图标 —— Save 用于下载文件，右侧的 Share 图标可将其分享到应用外部。

— 说明 —
结果会在列表中不断累积。请下载需要的部分并清理其余内容，以保持工作区整洁。
