— Use Cases · 사용 사례 —

이 기능을 왜, 어떤 경우에 쓰는가

모델의 인물성은 유지하면서 미소, 놀람, 진지함 같은 감정만 바꿔야 할 때 사용합니다. 촬영 전 표정 방향을 먼저 제안하거나 클라이언트와 시안을 비교할 때 유용합니다.

06
— Prompt · 표정 입력 —

원하는 표정을 텍스트로 묘사하기

바꾸고 싶은 표정을 프롬프트로 입력하고, 같은 인물·의상을 유지하려면 preserve identity / preserve clothing을 함께 적습니다.

— Prompt —

바꾸고 싶은 표정 입력

바꾸고 싶은 표정을 텍스트로 입력합니다. 예: gentle smile, surprised expression, serious cinematic expression.

— 인물성 유지 —

preserve identity / clothing

같은 인물과 의상을 유지하려면 preserve identity, preserve clothing을 함께 입력합니다.

— Prompt 입력 예시 —
— 예시 프롬프트 —
A gentle confident smile, natural eyes, subtle happy facial expression, preserve the same person and outfit, clean studio lighting.

Chapter 07Camera 옵션

07
— Camera Options · 카메라 조건 —

뷰 · 샷 사이즈 · 앵글 설정

Camera View, Shot Size, Camera Angle 세 가지 카메라 조건을 조합해 같은 표정도 다른 구도로 만들 수 있습니다. 모두 선택 사항입니다.

— 1. Camera View / Position —

바라보는 방향

Front View, 3/4 View, Profile View 등 인물이 카메라를 바라보는 방향을 선택합니다. 정면 컷은 Front View, 약간 돌아본 컷은 3/4 View를 사용합니다.

— 2. Shot Size / Distance —

화면에 잡히는 크기

Wide Shot, Medium Shot, Close-Up 등 인물 크기를 선택합니다. 표정을 강조하려면 Close-Up 계열, 의상·포즈를 보려면 Medium 계열이 적합합니다.

— 3. Camera Angle / Height —

카메라 높이와 시선

Eye Level, Low Angle, High Angle 등 카메라 높이와 시선의 느낌을 선택합니다. Eye Level은 자연스럽고, Low Angle은 인물을 더 강하게 보이게 합니다.

— Optional —
카메라 옵션은 모두 선택 사항입니다. 표정 변환만 필요하면 비워 두고 진행할 수 있습니다.

08
— Generate · 생성 —

생성 실행과 진행 확인

원본과 프롬프트가 준비되면 Generate(6 credits)를 누르고, 확인 팝업과 진행률을 통해 생성 상태를 확인합니다.

— Generate —

생성 버튼 활성화

원본 이미지와 프롬프트가 준비되면 Generate 버튼이 활성화됩니다. 생성 1회에 6 credits가 사용됩니다.

— 생성 확인 —

확인 팝업

Would you like to generate an image? 팝업이 표시됩니다. OK를 누르면 생성이 시작되고, Cancel은 이전 화면으로 돌아갑니다.

— 진행 상태 —

생성 진행률

Creating your image… 상태에서 진행률이 퍼센트로 표시됩니다. 완료되면 오른쪽 결과 영역에 이미지 카드가 추가됩니다.

— 크레딧 —
생성 1회당 6 credits. 표정 후보를 여러 번 생성할 때 크레딧 소모를 고려하세요.

— Download & Tips · 다운로드 —

결과 저장과 안정적 사용법

하단 아이콘으로 결과를 내려받거나 정리하고, 표정을 먼저 테스트한 뒤 필요할 때 카메라 옵션을 더하는 방식으로 인물성을 지킵니다.

— Download / Delete —

내려받기와 정리

결과 영역 하단의 다운로드 아이콘으로 이미지를 내려받고, 휴지통 아이콘으로 결과를 정리합니다.

— 활용 팁 —
표정·시선·구도·조명을 한 번에 너무 많이 바꾸면 원본 인물성이 약해질 수 있습니다. 먼저 표정만 테스트하고, 필요할 때 카메라 옵션을 추가하는 방식이 안정적입니다.
