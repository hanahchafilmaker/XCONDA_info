Key Frame 업로드

— Step 01 —

업로드 박스 또는 New Key Frame 클릭

KEY FRAME 영역의 빈 업로드 박스를 클릭합니다. 또는 New Key Frame 버튼을 클릭하여 기준 이미지를 업로드합니다.

— 역할 —

기준 프레임으로 사용

Directors Note 입력

기본 입력값 제공

기본 입력값은 make the next scene with high cinematic tension입니다. 필요에 따라 수정합니다.
