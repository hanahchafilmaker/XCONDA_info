03
— Image Engine Selection —

이미지 엔진 선택

이미지 엔진을 선택합니다. 두 가지 엔진 중 작업 목적에 맞는 것을 고릅니다.

— Standard / Cinema Pro — 두 가지 엔진
— Standard —

초안 · 아이디어 탐색용

생성 속도가 빠르고 기본적인 구도를 잘 잡지만 디테일은 부족합니다. 초안 뽑기, 아이디어 탐색, 레퍼런스 만들기에 적합합니다.

— Cinema Pro —

광고 · 영상용 최종 결과물

디테일이 매우 높고(피부, 질감, 광원) 카메라 연출(클로즈업, 로우앵글, 심도 표현) 이해도가 높습니다. 라이팅이 자연스럽고 일관성 유지가 잘 되며, 광고/영상용으로 바로 사용 가능합니다. 단, 생성 속도는 느립니다.

— Engine A —

STANDARD

Gemini 2.5 Flash · 4 credits per cut
  • 속도빠름
  • 구도기본 구도 잘 잡음
  • 디테일부족
  • 추천초안, 아이디어 탐색, 레퍼런스
— Engine B —

CINEMA PRO

Gemini 3.1 Pro · 7 credits per cut
  • 속도느림
  • 디테일매우 높음 (피부·질감·광원)
  • 카메라클로즈업·로우앵글·심도
  • 라이팅자연스러움
  • 일관성유지 잘됨
  • 추천광고·영상용 바로 사용

연출 스타일 선택

연출과 톤앤무드를 결정하는 핵심 단계입니다. 빨간색 박스 안에 있는 5가지 스타일 중 선택합니다.

5가지 스타일은 각각 고유한 연출 문법을 가지며, 각 스타일에 대한 상세 설명은 다음 페이지에서 확인할 수 있습니다.

— 5 styles · red frame — 5가지 스타일

5가지 스타일 상세

각 디렉터 스타일의 특징을 화면에서 확인할 수 있습니다. 이전 페이지의 5가지 스타일에 대한 설명입니다.

— On-screen reference — 화면 내 설명
— 선택 가이드 —

작업 목적에 맞춰 선택

정돈된 구도가 필요하면 Wes Anderson, 감성적 분위기는 Spike Jonze, 강한 메시지는 Wieden+Kennedy, 트렌디한 광고는 The Baker Brothers, 잔잔한 정서 표현은 Show Yanagisawa를 선택합니다.

— 재시도 —

다른 스타일로 재생성

결과물이 의도와 다를 경우 디렉터 스타일을 변경하여 다시 생성할 수 있습니다.

아트 스타일 선택

빨간색 박스 안에 4가지 중 선택합니다. 결과물의 매체(실사, 애니메이션, 클레이메이션, 3D)를 결정하는 단계입니다.

선택한 매체에 따라 결과물의 시각적 언어가 완전히 달라집니다. 광고 목적과 타깃 오디언스에 맞춰 선택합니다.

09
— Product / Model Images · Optional —

제품 · 모델 이미지 첨부

생체인식(얼굴 잠금)을 통해 시각적 연속성을 유지하는 9컷을 생성하기 위한 단계입니다. 필수는 아니며 제품 중심 광고도 가능합니다.

— Hero Product · Hero Muse — 제품 · 모델 이미지
— 첨부 방법 —

클릭 또는 드래그

바로 아래의 회색 빈칸을 클릭하여 파일을 선택하거나, 첨부할 이미지 파일을 드래그하여 사진을 첨부합니다.

— 권장 —

배경 없는 이미지 사용

공통 사항으로, 배경이 없는 이미지를 사용하면 인식 정확도가 높아지고 결과물의 일관성 유지에 도움이 됩니다.

— 좌측 / 빨간색 박스 — Optional

HERO PRODUCT

히어로 프로덕트 — 제품 이미지

광고에 노출될 제품 이미지를 첨부합니다. 결과물 내에서 핵심 오브젝트로 작동합니다. 바로 아래의 회색 빈칸을 클릭하여 삽입하거나, 첨부할 이미지 파일을 드래그하여 사진을 첨부합니다.

— 우측 / 노란색 박스 — Optional

HERO MUSE

히어로 뮤즈 — 모델 이미지

제품을 광고할 모델 이미지를 첨부합니다. 이때 가능한 정면 사진을 넣어줍니다. 생체인식 얼굴 잠금을 통해 9컷 전체에 동일한 모델이 등장합니다.

— Note —
반드시 필수는 아니며, 제품 중심 광고도 가능합니다. 배경이 없는 이미지를 사용하면 인식 정확도가 높아지고 결과물의 일관성 유지에 도움이 됩니다.

— Per-frame Editing —

개별 이미지 수정

각 이미지의 개별 수정이 가능합니다. 펜 모양 아이콘을 클릭하여 프롬프트를 수정한 후, 재생성 버튼으로 해당 이미지만 다시 생성합니다.

— Pen icon · Regenerate — 개별 수정
— Step 01 —

펜 아이콘 클릭

사진의 우측 바로 밑 노란색 박스 안의 펜 모양 아이콘을 클릭하면 이미지의 프롬프트가 나옵니다.

— Step 02 —

프롬프트 수정

수정할 프롬프트를 새로 입력합니다.

— Step 03 —

재생성 버튼 클릭

빨간색 박스 안에 있는 활성화된 노란색 재생성 버튼을 클릭하면 해당 이미지만 다시 생성됩니다.

01

펜 아이콘 클릭

사진 우측 하단 노란색 박스 안의 펜 아이콘 → 프롬프트 표시

02

프롬프트 입력

수정할 프롬프트를 새로 입력

03

재생성

빨간색 박스 안 노란색 재생성 버튼 클릭 → 해당 이미지만 재생성
