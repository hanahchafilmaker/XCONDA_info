— Purpose · 사용 목적 —

CineGrade AI는 무엇을 하는 기능인가

CineGrade AI는 사용자의 사진에 레퍼런스 영화 스틸의 컬러 그레이딩, 대비, 무드감을 적용하는 기능입니다. 편집할 사진과 스타일 기준 이미지를 각각 업로드하면, AI가 레퍼런스의 색감 방향을 해석해 원본 사진을 새로운 톤으로 변환합니다.

03
— Why · 사용 이유 —

왜 이 기능을 사용하는가

사진의 구도나 피사체는 유지하면서 색감과 분위기만 빠르게 바꿀 수 있기 때문입니다. 후반 색보정 전 단계에서 원하는 룩을 테스트하거나, 클라이언트에게 여러 톤 후보를 보여줄 때 작업 시간을 줄일 수 있습니다.

— 구도 유지 —

피사체는 그대로, 색감만 변경

사진의 구도·피사체·자세는 그대로 두고 색감·대비·무드만 바꿉니다. 컬러 그레이딩 방향만 빠르게 테스트할 수 있습니다.

— 후반 색보정 단축 —

색보정 룩 사전 테스트

실제 후반 색보정에 들어가기 전, 원하는 룩 방향을 미리 시뮬레이션해 의사결정과 작업 시간을 줄여줍니다.

— Use Cases · 사용 사례 —

어떠한 경우에 사용하는가

영화 같은 색감, 광고 캠페인 톤, 룩북 무드, SNS 비주얼 톤을 한 장의 레퍼런스 이미지로 맞추고 싶을 때 사용합니다. 여러 사진의 색감 방향을 통일하거나, 촬영본을 다른 장르의 무드로 빠르게 테스트하는 경우에 적합합니다.

레퍼런스 색감을 빠르게 맞추기
영화 스틸, 광고 톤, 룩북 색감처럼 원하는 무드를 기준 이미지로 정해 여러 사진에 같은 방향을 적용할 수 있습니다.

01

시네마틱 룩

영화 스틸 한 장으로 사진에 영화 같은 컬러 그레이딩과 대비를 부여합니다.

02

광고 캠페인 톤

캠페인 키비주얼의 색감을 다른 컷에도 통일감 있게 확장합니다.

03

룩북 무드 통일

여러 컷의 색감 방향을 하나의 레퍼런스로 맞춰 룩북 전체 무드를 통일합니다.

04

SNS 비주얼 톤

피드 전체의 컬러 톤을 일관되게 유지하기 위한 빠른 톤 매칭 도구로 사용합니다.

05

장르 톤 테스트

같은 촬영본을 누아르·웜·콜드·바이오 등 다른 장르의 무드로 즉시 테스트합니다.

06

색보정 시안

본 색보정 전, 의사결정용으로 톤 후보 여러 개를 빠르게 만들어 비교합니다.

— Entry · 진입 —

CineGrade AI 메뉴 진입

왼쪽 세로 메뉴에서 마법봉 모양 아이콘을 클릭합니다. 해당 메뉴가 CineGrade AI 기능입니다.

— 위치 —

왼쪽 사이드 메뉴

화면 좌측 세로 메뉴 영역에 기능별 아이콘이 정렬되어 있습니다. 이 중 마법봉 모양 아이콘이 CineGrade AI 진입점입니다.

— 진입 —

아이콘 클릭

마법봉 아이콘을 클릭하면 CineGrade AI 작업 화면이 열립니다. 상단에 CineGrade AI 제목과 “Upload a reference movie still and transfer its color grading, contrast, and mood to your own photo instantly using AI.” 안내 문구가 표시됩니다.

— 화면 식별 —
상단 문구는 “레퍼런스 영화 스틸을 업로드하면 AI가 그 컬러 그레이딩·대비·무드를 사용자 사진에 즉시 적용한다”는 의미입니다.

기본 화면 구성

— 오른쪽 박스 —

Upload the style reference

— 활성 조건 —
두 박스가 모두 채워져야 Generate 버튼이 활성화됩니다.

07
— Your Photo · 원본 사진 —

Upload the photo to edit

왼쪽 박스에는 색보정을 적용할 원본 사진을 업로드합니다. 피사체와 배경이 또렷하고 노출이 안정적인 사진일수록 레퍼런스 색감을 적용했을 때 결과를 판단하기 쉽습니다.

— 업로드 —

원본 사진 등록

왼쪽 박스를 클릭하거나 파일을 드래그&드롭해 색보정을 적용할 사진을 업로드합니다. 업로드가 완료되면 박스에 미리보기가 표시됩니다.

— 가이드라인 —

좋은 원본 사진의 조건

피사체와 배경이 또렷하고 노출이 안정적인 사진일수록 결과 판단이 쉽습니다. 노출이 너무 어둡거나 밝아 톤이 뭉개진 사진은 색감을 적용해도 변화를 평가하기 어렵습니다.

— 제거 —

업로드 취소

업로드한 사진은 박스 오른쪽 위 X 버튼으로 제거하고 다시 선택할 수 있습니다.

— 권장 —
잘 노출된 인물 또는 풍경 컷, 디테일이 살아 있는 사진이 가장 안정적인 결과를 만듭니다.

Chapter 08Reference Still

08
— Reference · 스타일 레퍼런스 —

Upload the style reference

오른쪽 박스에는 참고할 영화 스틸이나 원하는 색감의 이미지를 업로드합니다. 레퍼런스는 구도보다 색, 대비, 조명 분위기를 전달하는 역할을 합니다.

— 역할 —

색·대비·조명 무드 신호

레퍼런스는 결과에 적용될 색감·대비·조명 분위기를 전달합니다. 구도나 피사체가 아닌 “이런 톤으로 만들어달라”는 시각적 지시문 역할입니다.

— 권장 형식 —

색감이 분명한 한 컷

웜·콜드·시네마틱·하이콘트라스트 등 색감 방향이 분명한 한 장의 이미지가 가장 잘 작동합니다. 영화 스틸·광고 키비주얼·사진 작품 모두 사용 가능합니다.

— 제거 —

업로드 취소

업로드한 레퍼런스는 박스 오른쪽 위 X 버튼으로 제거하고 다른 이미지로 다시 선택할 수 있습니다.

— 권장 —
레퍼런스를 고를 때는 “이 사진에 가져가고 싶은 게 색·조명·대비인지”를 기준으로 판단하세요.

09
— Both Ready · 두 이미지 준비 상태 —

두 이미지가 모두 준비된 상태

원본 사진과 스타일 레퍼런스가 모두 업로드되면 Generate 버튼이 활성화됩니다. 이 상태에서 AI는 왼쪽 사진의 피사체를 유지하고, 오른쪽 이미지의 컬러 무드와 콘트라스트를 반영합니다.

— 활성화 —

Generate 버튼 활성

두 박스가 모두 채워지면 Generate 버튼이 노란색으로 활성화됩니다. 이때부터 색감 변환을 실행할 수 있습니다.

— 처리 원리 —

왼쪽 피사체 + 오른쪽 톤

AI는 왼쪽 사진의 피사체·구도·디테일은 유지하면서, 오른쪽 이미지의 컬러 무드와 콘트라스트를 입력 신호로 사용합니다.

— 핵심 —
왼쪽은 “무엇을”, 오른쪽은 “어떤 톤으로”에 해당합니다.

10
— Remove · 업로드 이미지 제거 —

업로드 이미지 제거

각 업로드 이미지 오른쪽 위의 X 버튼을 누르면 해당 이미지를 제거할 수 있습니다. 잘못 올린 사진이나 레퍼런스를 교체할 때 사용합니다.

— X 버튼 —

각 박스 우측 상단

두 업로드 박스 각각의 오른쪽 위 모서리에 빨간 X 버튼이 표시됩니다. 이 버튼을 누르면 해당 이미지가 제거됩니다.

— 활용 —

교체 / 재선택

잘못 올린 사진을 바꾸거나, 레퍼런스를 다른 색감의 이미지로 교체할 때 사용합니다. 한쪽만 제거하면 Generate는 다시 비활성화됩니다.

— 주의 —
한쪽 이미지를 제거하면 Generate 버튼이 다시 비활성화되므로, 교체 후에는 새 이미지를 다시 올려야 합니다.

11
— Generate · 생성 실행 —

Generate 실행

두 이미지가 모두 들어간 상태에서 Generate를 누르면 색감 변환 생성을 시작합니다. 현재 테스트 화면 기준으로 1회 생성에 6 credits가 사용됩니다.

— 조건 —

두 이미지 모두 필요

Your Photo와 Reference Movie Still 두 박스가 모두 채워져야 Generate가 활성화됩니다.

— 비용 —

크레딧 차감

현재 테스트 화면 기준 1회 생성에 6 credits가 차감됩니다. 잔여 크레딧이 부족하면 생성이 진행되지 않습니다.

— 권장 흐름 —
두 이미지를 한 번 더 검토한 뒤 Generate를 누르면 재생성 횟수를 줄일 수 있습니다.

Chapter 12생성 확인

12
— Confirm · 생성 확인 팝업 —

생성 확인 팝업

Generate를 누르면 “Would you like to generate an image?” 확인 팝업이 표시됩니다. OK를 누르면 실제 생성이 시작되고, Cancel을 누르면 이전 화면으로 돌아갑니다.

— OK —

실제 생성 시작

OK를 누르면 실제 생성이 시작되고 크레딧이 차감됩니다. 생성 중에는 결과 영역에 진행 상태가 표시됩니다.

— Cancel —

이전 화면 복귀

Cancel을 누르면 생성하지 않고 이전 화면으로 돌아갑니다. 업로드한 두 이미지는 유지되어 바로 수정·재시도가 가능합니다.

— 안전 장치 —
확인 팝업은 실수로 인한 크레딧 소모를 막기 위한 단계입니다. 최종 검토 후 OK를 누르세요.

Chapter 13결과 카드

13
— Result Card · 결과 카드 —

결과 카드

생성이 끝나면 오른쪽 결과 영역에 변환된 이미지가 카드 형태로 표시됩니다. 결과 카드는 원본 사진의 피사체를 유지하면서 레퍼런스 이미지의 색감과 분위기를 반영합니다.

— 표시 —

우측 결과 영역에 카드 추가

생성이 완료되면 오른쪽 결과 영역에 결과 카드가 하나 추가됩니다. 카드에는 변환된 색감의 결과 이미지가 들어갑니다.

— 누적 비교 —

톤 후보 누적

레퍼런스를 바꿔가며 여러 번 생성하면 결과 카드가 누적되어, 같은 사진의 여러 톤 후보를 한 화면에서 비교할 수 있습니다.

— 활용 —
톤 후보를 비교한 뒤, 최종 채택할 카드만 다운로드하고 나머지는 삭제하는 워크플로우가 효율적입니다.

Chapter 14결과 확인
P. 014
14
— Review · 결과 점검 —

최종 생성 이미지 확인

최종 이미지는 레퍼런스 스틸의 따뜻한 조명과 영화적인 대비가 원본 사진에 적용된 결과입니다. 최종 사용 전에는 얼굴 톤, 의상 색, 배경 밝기, 전체 대비가 의도와 맞는지 확인합니다.

— 유지 —

피사체·구도 유지

결과 이미지는 원본 사진의 피사체·구도·디테일을 유지합니다. 색감만 바뀌고 사진의 내용은 일관성을 유지합니다.

— 반영 —

레퍼런스 톤·대비 반영

레퍼런스의 조명 무드·컬러 톤·대비가 결과에 입혀집니다. 결과는 100% 동일하지 않을 수 있으므로 여러 번 생성해 가장 적합한 톤을 선택합니다.

— 점검 —

얼굴·의상·배경 점검

Download / Delete

결과 이미지 위에 마우스를 올리면 다운로드 아이콘과 삭제 아이콘이 표시됩니다. 다운로드 아이콘은 결과 저장, 삭제 아이콘은 선택한 결과 제거에 사용합니다.

— 다운로드 —

다운로드 아이콘

다운로드 아이콘을 누르면 해당 결과 이미지가 로컬 파일로 저장됩니다. 최종 채택한 톤을 외부에서 사용할 때 이 버튼을 사용합니다.

— 삭제 —

삭제 아이콘

삭제 아이콘은 선택한 결과 카드를 제거합니다. 불필요한 톤 후보를 정리해 결과 영역을 깔끔하게 유지할 수 있습니다.

— 표시 조건 —
아이콘은 결과 이미지 위에 마우스를 올렸을 때 나타나며, 평소에는 결과만 깨끗하게 표시됩니다.

— Confirm Delete · 삭제 확인 —

삭제 확인 팝업

삭제 아이콘을 누르면 “Delete this media?” 확인 팝업이 표시됩니다. Delete를 누르면 결과가 삭제되고, Cancel을 누르면 결과가 유지됩니다.

— Delete —

결과 삭제

Delete를 누르면 선택한 결과 카드가 실제로 삭제됩니다. 삭제된 결과는 복구되지 않으므로 신중히 결정합니다.

— Cancel —

삭제 취소

Cancel을 누르면 결과가 그대로 유지됩니다. 다른 톤 후보와 비교가 끝나기 전까지는 일단 보관해 두는 편이 안전합니다.

— 마무리 —
최종 채택 톤 다운로드 → 불필요한 카드 정리 → 작업 종료의 순서로 마무리합니다.
