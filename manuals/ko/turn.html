— Overview · 개요 —

Turn은 무엇을 하는 기능인가

360도 배경을 만들고, 원하는 시점의 최종 이미지를 만드는 기능입니다.

— Note 01 —

Turn은 공간을 먼저 만들고, 3D Preview에서 카메라 시점을 고른 뒤, Production에서 인물과 연출을 더합니다.

— Note 02 —

Freeze Frame은 기준 장면이고, Final Still은 인물·액션·라이팅·스타일이 적용된 최종 결과입니다.

— Use Case · 사용 이유 —

왜 Turn을 사용하는가

같은 공간에서 여러 연출 방향을 빠르게 비교할 수 있습니다.

— Note 01 —

실제 촬영 전에 조명, 인물 위치, 스타일 분위기를 여러 버전으로 테스트할 수 있습니다.

— Note 02 —

광고 컷, 제품 화보, 쇼핑몰 상세페이지, 콘티처럼 클라이언트에게 시안을 빠르게 보여줘야 할 때 유용합니다.

— When to Use · 사용 시점 —

어떤 경우에 쓰는가

배경 생성, 부분 수정, 인물 합성이 한 흐름에 필요할 때 사용합니다.

— Note 01 —

Reference 이미지가 없어도 프롬프트만으로 시작할 수 있고, 1장 또는 4방향 이미지를 넣어 공간 기준을 더 명확히 잡을 수 있습니다.

— Note 02 —

생성된 배경은 Cube Map에서 방향별로 수정하고, 마지막에는 Cast Reference로 얼굴과 의상 기준을 적용합니다.

— Input Modes · 입력 방식 —

입력 방식별 사용 기준

상황에 따라 가장 적합한 입력 방식을 선택할 수 있도록 네 가지 사용 기준을 정리했습니다.

— Mode 01 —
프롬프트만 입력

빠르게 공간 시안을 잡거나 레퍼런스 이미지가 아직 없을 때 사용합니다.

4방향 이미지 입력

공간의 앞, 왼쪽, 오른쪽, 뒤쪽 방향을 명확히 유지해야 할 때 사용합니다.

— Mode 04 —
Cube Map 수정

생성 후 특정 방향의 창문, 가구, 소품, 인물, 벽면 디테일만 바꾸고 싶을 때 사용합니다.

— Summary · 정리 —

최종 정리

Turn 워크플로우의 핵심 정리. 각 단계의 역할과 결과물의 용도를 한눈에 파악합니다.

전체 흐름

Turn은 배경 생성, 3D 시점 선택, 부분 수정, 인물 연출, 최종 스틸 생성까지 한 흐름으로 이어지는 기능입니다.

단계별 역할

Reference 단계에서는 입력 재료를 준비하고, HDRI 단계에서는 공간과 시점을 확정하며, Production 단계에서는 인물과 영화적 디테일을 추가합니다.

결과물 차이
