Upscale은 무엇을 하는 기능인가

이 기능을 쓰는 주된 목적

— Models · 모델 선택 —

Models: Topaz / Xconda

Models 드롭다운에서는 Topaz와 Xconda 모델을 선택할 수 있습니다. Topaz는 배율, Enhance Model, Subject Detection, Output Format, Face Enhancement, Creativity 조정 항목이 함께 표시됩니다. Xconda는 Xconda 자체 업스케일 모델을 사용하는 선택지입니다.

— Note —
기본은 Topaz. 세밀한 컨트롤이 필요한 작업에 적합합니다. Xconda는 한 번에 빠르게 결과가 필요할 때.

— Xconda Model —

Xconda 자체 모델

Xconda를 선택하면 Xconda가 자체 학습한 업스케일 모델로 작업이 진행됩니다. Topaz 대비 옵션이 단순하며, 빠른 결과를 우선하는 경우에 사용합니다.

— Note —
Xconda 모델은 옵션이 단순한 만큼 결과도 빠릅니다. 미세 컨트롤은 Topaz가 강합니다.

— Upload · 업로드 —

이미지 업로드

Drop Image Here 또는 Click to Upload 영역에 원본 이미지를 넣습니다. 업로드가 완료되면 왼쪽 패널에 미리보기가 표시되고, 우측 상단 X 버튼으로 이미지를 제거할 수 있습니다.

— Note —
얼굴 보정 테스트에서는 얼굴이 정면에 가깝고 충분히 보이는 이미지가 가장 안정적인 결과를 만듭니다.

P. 008
08
— Scale · 배율 —

2X / 4X 배율 선택

2X는 원본보다 두 배 크게, 4X는 네 배 크게 업스케일하는 옵션입니다. 작업 목적이 웹 미리보기라면 2X, 큰 화면이나 고해상도 납품용이라면 4X를 선택합니다.

— Note —
2X는 가볍고 빠릅니다. 4X는 크레딧·시간이 더 들지만 큰 출력물에 적합합니다.

Chapter 09Enhance Model
P. 009
09
— Enhance Model —

Enhance Model

이미지 성격에 맞는 보정 모델을 선택합니다. Standard V2, Low Resolution V2, CGI, High Fidelity V2, Text Refine 등으로 원본 유형에 맞춰 보정 방향을 바꿀 수 있습니다.

— Note —
사진은 Standard / High Fidelity, 작은 원본은 Low Resolution, 일러스트·렌더는 CGI, 글자 위주는 Text Refine.

— Subject Detection —

Subject Detection

보정 기준이 되는 피사체 영역을 지정하는 옵션입니다. Foreground는 전경 피사체를 중심으로 인식해 보정하며, 인물이나 제품처럼 배경과 구분되는 대상에 적합합니다.

— Note —
배경이 단순한 인물·제품 컷에서 Foreground가 가장 안정적입니다.

— Output Format —

Output Format

결과 이미지의 저장 형식을 선택합니다. JPG는 용량이 가볍고 일반 공유에 적합하며, PNG는 투명도나 후편집이 필요한 작업에서 활용하기 좋습니다.

— Note —
공유·미리보기는 JPG, 합성·후편집은 PNG가 기본.

Chapter 12Face Enhancement
P. 012
12
— Face Enhancement —

Face Enhancement

얼굴이 포함된 이미지에서 눈·코·입·피부·얼굴 윤곽의 선명도를 보강하는 옵션입니다. 값을 높이면 얼굴 디테일을 더 적극적으로 복원하고, 낮추면 원본 느낌을 더 많이 유지합니다. 얼굴 보정이 필요한 인물 이미지에서는 핵심 옵션입니다.

— Note —
얼굴 컷의 핵심 옵션. 값을 너무 높이면 인공적으로 보일 수 있으니 중간값에서 시작해 조정하세요.
012 — Face EnhancementFACE-ENHANCEMENT
Chapter 13Creativity
P. 013
13
— Creativity —

Creativity

업스케일 과정에서 모델이 디테일을 얼마나 새로 해석할지 조절하는 값입니다. 낮은 값은 원본 유지, 높은 값은 질감과 디테일 재구성에 더 적극적인 결과를 만듭니다.

— Note —
원본을 그대로 살리려면 낮게. 질감을 더 살리려면 높게. 인물 얼굴은 보통 낮음~중간이 안전합니다.
013 — CreativityCREATIVITY
Chapter 14Generate
P. 014
14
— Generate · 생성 실행 —

Generate

설정이 끝나면 Generate 버튼을 눌러 업스케일을 시작합니다. 버튼 오른쪽에는 생성에 필요한 크레딧이 표시되며, 현재 예시에서는 8 credits가 표시됩니다.

— Note —
옵션 조합에 따라 크레딧이 달라질 수 있습니다. Generate 직전 한 번 더 확인하세요.

Chapter 15생성 확인 팝업
P. 015
15
— Confirm · 생성 확인 —

생성 확인 팝업

Generate를 누르면 "Would you like to generate an image?" 확인 창이 표시됩니다. OK를 누르면 실제 생성이 시작되고, Cancel을 누르면 설정 화면으로 돌아갑니다.

— Note —
실수로 인한 크레딧 소모를 막는 안전 단계입니다.

Chapter 16Latest Result / Download
P. 016
16
— Result · 결과 관리 —

Latest Result / Download

생성이 끝나면 우측 Latest Result 영역에서 업스케일된 이미지를 확인합니다. 우측 상단 Download 아이콘으로 결과물을 저장하고, Delete 아이콘으로 필요 없는 결과를 정리할 수 있습니다. 하단 History에는 이전 생성 결과가 남아 있어 다시 확인할 수 있습니다.

— Note —
Latest Result는 최신 결과 한 장. History는 시안 비교용 누적 목록입니다.
