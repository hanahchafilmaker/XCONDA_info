— Purpose —

YouTube Ref 사용 목적

클라이언트가 "이 영상처럼 만들어주세요"라며 레퍼런스 영상을 보내올 때, 해당 영상의 톤과 무드를 빠르게 시각화하여 스토리보드 초안을 뽑는 데 사용합니다.

— 기존 방식 —
영상을 반복 시청하며 수동으로 키프레임을 캡처하고 정리
→ 시간 소모가 크고, 주관적 해석에 의존
— YouTube Ref 방식 —
링크 입력만으로 AI가 9씬 스토리보드를 자동 생성
→ 빠른 초안 확보, 팀 내 방향성 공유에 활용

Chapter 03사용 사례

03
— Use Cases —

어떤 경우에 사용하나요?

레퍼런스 분석, 기획 회의 초안, 스토리보드 제작, 벤치마크 분석 등에 활용됩니다.

01

클라이언트 레퍼런스 분석

클라이언트가 보낸 레퍼런스 영상의 시각적 톤, 구도, 색감을 빠르게 파악할 때

02

내부 기획 회의용 초안

영상 기획 단계에서 레퍼런스 영상을 기반으로 방향성을 잡고 팀원과 공유할 때

03

스토리보드 초안 제작

촬영/제작 전 전체 흐름을 시각적으로 확인하고 싶을 때

04

경쟁사/벤치마크 분석

경쟁 브랜드의 광고 영상을 분석하여 구성과 연출 패턴을 파악할 때

— 주의 —
원본 영상의 실제 콘텐츠 맥락까지 정확하게 반영하지는 않습니다. 시각적 톤과 무드 중심의 참고용으로 활용합니다.

Chapter 04주요 기능
P. 004
04
— Key Features —

YouTube Ref 주요 기능

링크 입력 → 9씬 자동 생성, 톤앤무드 추출, 씬 자동 분할, 캐릭터 레퍼런스, 개별 씬 수정.

— 01 —

링크 입력 → 9씬 자동 생성

YouTube 영상 링크를 입력하면 AI가 영상을 분석하여 9개의 키프레임 스토리보드를 생성합니다.

— 02 —

톤앤무드 추출

영상의 색감, 조명, 구도 등 시각적 분위기를 기반으로 이미지를 생성합니다.

— 03 —

씬 구성 자동 분할

영상 흐름을 AI가 자동으로 9개 장면으로 분할하여 시퀀스를 구성합니다.

— 04 —

캐릭터 레퍼런스 (선택)

Body/Outfit, Face Detail 이미지 업로드 시 스토리보드에 해당 캐릭터가 반영됩니다.

05
— Prompt Tips —

프롬프트 입력 시 주의사항

씬 설명을 수정(Regenerate)할 때, 구체적인 공간/환경 정보를 포함하면 결과물의 정확도가 높아집니다.

— 좋은 예시 —
"교실 안에서 학생들이 수업을 듣는 장면"
"도심 거리에서 비 오는 밤, 네온 사인 조명"
"해변에서 석양을 배경으로 달리는 인물"
— 피해야 할 예시 —
"실내" → 어떤 실내인지 특정되지 않음
"밖에서" → 환경이 모호함
"좋은 분위기" → AI가 해석할 수 없는 추상적 표현
— 핵심 원칙 —
장소 + 상황 + 분위기를 구체적으로 서술합니다. 추상적 표현보다 시각적으로 떠오르는 단어를 사용합니다.

개별 씬 수정 및 재생성

장면 오른쪽의 연필 아이콘을 클릭하여 장면 설명을 수정한 후, Regenerate로 해당 장면을 다시 생성합니다.

장면 설명 수정

— Step 03 —

Regenerate 클릭

수정한 설명으로 해당 장면을 다시 생성합니다. Cancel을 클릭하면 수정을 취소합니다.
