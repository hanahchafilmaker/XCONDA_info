P. 001
01
— 개요 · 전체 흐름 —

한눈에 보는 워크플로

상단의 네 단계를 순서대로 진행합니다: 1. PRE-PRODUCTION → 2. LOCATION_SCOUTING → 3. CAMERA_TEST → 4. MASTER_STILL.

1
PRE-PRODUCTION
참조 이미지나 글 설명으로 360° 공간을 만듭니다. (영상 4)
2
LOCATION_SCOUTING
3D Preview에서 시점을 돌리며 방 크기나 벽을 조정합니다. (영상 1, 2, 4)
3
CAMERA_TEST
Freeze Frame에 피사체와 스타일을 더해 키 이미지를 만듭니다. (영상 3)
4
MASTER_STILL
최종 마스터 스틸 단계입니다. 이 단계는 데모 영상에 나오지 않습니다.
— 단계 01 —

영상에 나오는 전체 순서는 다음과 같습니다: 이미지 1장 업로드 → Analyze Space → Confirm Room Layout (벽 범위 지정) → 360° 공간 생성 → 3D Preview 열기 → (필요하면) 방 크기 조정 / 벽 편집 → FREEZE FRAME → Step 3에서 연출 추가 → 키 이미지 생성.

— 단계 02 —

상단 단계 탭은 진행에 따라 열립니다. 영상 초반에는 1. PRE-PRODUCTION 만 활성화되어 있고, 공간이 생성되면 2. LOCATION_SCOUTING 가 활성화됩니다. Freeze Frame 이후에는 3. CAMERA_TEST 가 활성화됩니다.

FRONT 이미지 업로드→ Analyze Space→ Confirm Room Layout→ 360° 공간→ 3D Preview / Wall Edit→ FREEZE FRAME→ 키 이미지
— 메모 —

데모 내레이션 기준 — ①“Turn은 이미지 한 장으로 가상 스튜디오 세트를 만듭니다.” ②“방이 너무 크면 너비와 깊이를 줄이세요. 천장을 높일 수도 있습니다.” ③“Wall Edit에서는 오브젝트를 자유롭게 추가하거나 삭제할 수 있습니다.” ④“구도를 잡고 프롬프트를 쓴 다음 피사체와 의상 사진을 더하면 키 이미지가 완성됩니다.”

Chapter 02홈 화면
P. 002
02
— 홈 · 화면 구성 —

홈 화면과 공통 헤더

모든 작업은 1. PRE-PRODUCTION 홈 화면에서 시작합니다. 헤더는 모든 단계에서 같습니다.

— 메모 01 —

상단 단계 바 — 왼쪽에 TURN 로고, 오른쪽에 네 개의 단계 탭이 있습니다. 활성 단계는 흰색으로 강조됩니다.

— 메모 02 —

모델 선택(REPLICATE) — Nano Banana Pro(보라색 = 선택됨) / GPT Image 2.5 두 엔진을 번갈아 사용할 수 있습니다.

— 메모 03 —

오른쪽 유틸리티 버튼 — Undo Face Edit Save Projects History API Connected(초록 점 = 연결됨).

— 메모 04 —

상태 표시줄 — 왼쪽에는 “Project is automatically saved to your PC.”가 표시됩니다. 오른쪽에는 “LOCAL STUDIO · Generation model: Nano Banana Pro.”가 나옵니다. 생성 중에는 “Waiting to save...”가 나타납니다.

— 메모 05 —

입력 영역 — FRONT / LEFT / RIGHT / BACK 네 개의 방향 슬롯, Describe the space you want to create... 입력란, 그리고 보라색 Create Space from Description 버튼이 있습니다. 이미지를 업로드하면 버튼이 Analyze Space.

002 — 홈 화면홈
Chapter 03단계 1: 공간 만들기
P. 003
03
— 단계 1 · 공간 빌드 —

이미지 한 장으로 360° 공간 만들기

한옥 사진 한 장과 “Analyze Space” 클릭 한 번으로 자유롭게 회전하는 3D 공간이 만들어집니다.

— 단계 01 · 이미지 업로드 —

FRONT 슬롯에 한옥 사진을 업로드합니다. 업로드 후 오른쪽의 큰 버튼이 Create Space from Description 에서 Analyze Space로 바뀝니다. 왼쪽 위에는 “Auto-saved at 9:34 AM” 같은 저장 표시가 나타납니다.

— 단계 02 · 공간 분석 —

Analyze Space 를 누르면 “Confirm Room Layout” 대화상자가 열리고, 추정값 네 가지가 표시됩니다: Room Width (m) 8 Room Depth (m) 6 Ceiling Height (m) 3.5 Camera Height (m) 1.2참고: “These are not exact measurements taken from a single photo. Please review the estimated dimensions and wall area.”

— 단계 03 · 벽 범위 지정 —

“Drag the four corners to select only the wall.” 이미지 위의 보라색 점 네 개를 끌어 바닥과 벽의 경계 에 맞춥니다(내레이션: “Select Space를 누르고, 이렇게 점을 바닥과 벽의 경계까지 올립니다.”). 오른쪽의 “Unwrapped Front Wall Result” 가 선택이 맞는지 바로 확인해 줍니다.

— 단계 04 · 통합 프롬프트 —

체크박스를 켭니다: Unwarp the selected front-wall area and use it as a generation reference. 이어서 “Space Design · Expand from One Reference” 블록에서 Common Wall Finish, Common Molding & Wood Finish 프롬프트를 확인한 뒤 생성을 시작합니다.

— 결과 —

생성이 끝나면 자유롭게 회전할 수 있는 가상 3D 공간이 만들어지고, 2. LOCATION_SCOUTING 탭이 열립니다.

Chapter 04방 크기 조정
P. 004
04
— 방 크기 · 카메라 —

방 크기와 카메라 조정

공간을 다시 생성하지 않고 방의 너비, 깊이, 천장 높이를 그 자리에서 조정합니다.

— 열기 —

초록색 Room Size · Camera 버튼을 선택하면 “Room Size & Camera” 대화상자가 열립니다. 여기서도 같은 네 항목(방 너비, 깊이, 천장 높이, 카메라 높이)을 설정할 수 있습니다.

— 더 작게 만들기 —

내레이션대로 “방이 너무 클 때”는 Room Width 8→4, Room Depth 6→4 가 축소 입력 예시입니다. 대화상자에는 이런 설명이 있습니다: “천장 서까래와 간접 조명은 사진 상단 요소를 확장해 추정합니다. 바닥은 앉기에 적합한 나무 바닥으로 가정합니다. 가구 같은 요소는 모두 벽에 통합된 구조로 설계됩니다.”

— 천장 높이기 —

천장 높이 를 올리면 같은 방 그대로 천장이 높아집니다. 내레이션대로 “천장을 더 높일 수도 있습니다”.

— 적용 —

보라색 Apply Room Size · No Additional Generation 버튼을 누르면 설정이 적용됩니다. 새 이미지를 생성하지 않고 기존 표면 이미지를 사용해 새 비율만 반영합니다(옆의 안내: “Uses existing surface images”). 오른쪽에서 Close 를 선택하면 취소됩니다.

Chapter 053D 미리보기
P. 005
05
— 단계 2 · 미리보기 —

3D 미리보기 살펴보기

생성된 공간을 자유롭게 회전해 구도를 확인하고, Freeze Frame으로 고정합니다.

— 시점 회전 —

화면을 클릭한 채 드래그 하면 카메라가 360° 회전합니다. ELEVATION(수평 각도)과 FOV 값이 왼쪽 아래에 실시간으로 표시됩니다.

— 줌 —

하단의 FIELD OF VIEW (ZOOM) 슬라이더로 화각을 조정합니다(영상에서는 105°에서 82°로 바뀝니다).

— 왼쪽 위의 네 버튼 —

3D PREVIEW (현재 보기) · Wall Edit · Restyle Space from Reference · v2 · Room Size · Camera.

— FREEZE FRAME —

마음에 드는 구도를 찾으면 보라색 FREEZE FRAME 를 눌러 현재 시점을 Step 3의 참조 프레임으로 고정합니다. 옆의 원형 화살표 버튼은 시점을 초기화합니다.

P. 006
06
— 단계 2 · 벽 편집 —

벽 편집: 방향별로 오브젝트 수정

여섯 개 방향 카드에 참조 이미지와 브러시를 조합해 원하는 오브젝트를 추가하거나 삭제합니다.

— 시작 —

왼쪽 위에서 Wall Edit 를 선택하면 여섯 개 방향 카드(LEFT / FRONT / RIGHT / BACK / UP (ZENITH) / DOWN)가 나란히 표시됩니다. 내레이션: “Wall Edit을 선택하면 이 안에서 오브젝트를 자유롭게 추가하거나 삭제할 수 있습니다.”

— FACE REFERENCE —

각 카드에는 + Add Reference Image (DRAG & DROP) 영역이 있습니다. 이미지를 추가하면 REF LINKED 배지, ACTIVE 라벨과 “Applied directly to INPAINT and REGEN” 안내, 그리고 Apply As Is / Change / CLEAR 컨트롤이 나타납니다.

— 브러시 —

이미지 위를 드래그해 빨간 마스크를 칠합니다. 크기는 BRUSH 40PX 슬라이더로 조정합니다.

— 액션 버튼 —

각 카드 하단에 네 개의 버튼이 있습니다: INPAINT (REF) (보라색 = 마스크 영역 편집) · REGEN (REF) (주황색 = 면 전체 재생성) · CLEAR (마스크 지우기) · REPLACE (초록색 = 교체). 아래 Reference instructions or requested changes (optional)… 에 입력하면 지시를 함께 보낼 수 있습니다.

Chapter 07오브젝트와 벽지
P. 007
07
— 편집 예시 —

오브젝트 추가하고 벽지 교체하기

참조 이미지 한 장으로 소품 배치를 이끌 수도 있고, 벽지 전체를 바꿀 수도 있습니다.

— 예시 1 · 오브젝트 배치 —

LEFT 카드에 파란 수국참조를 추가한 뒤 마스크를 칠하고 편집을 실행합니다. 3D Preview의 선반 위에 꽃병이 나타납니다 —“준비한 참조 이미지를 책장에 올려 볼까요? 선반 위에 잘 자리 잡은 모습이 보입니다.”

— 예시 2 · 벽지 교체 —

BACK 카드에 해바라기 벽지 참조를 추가하고 “몰딩을 지우고 벽지만 해바라기 벽지로 바꿔 주세요” 같은 지시를 입력해 실행합니다. 내레이션: “벽지가 모두 해바라기로 바뀐 것을 볼 수 있습니다.” 시점을 돌려 3D 공간 전체에서 같은 벽이 일관되게 적용됐는지 확인하세요.

— 주요 차이 —

INPAINT 은 칠한 영역만 편집합니다(오브젝트 추가·삭제·교체). REGEN 는 해당 방향의 이미지 전체를 다시 생성하고, REPLACE 는 선택 영역을 참조 이미지로 바꾸고, CLEAR 는 마스크만 지웁니다.

Chapter 08단계 3: 키 이미지
P. 008
08
— 단계 3 · 키 이미지 —

카메라 테스트: 키 이미지 만들기

구도 프롬프트, 피사체 사진, 의상 사진, 시네마 스타일을 조합해 키 이미지를 만듭니다.

— 시작 —

단계 2에서 FREEZE FRAME 를 선택하면 3. CAMERA_TEST가 열리고, 고른 구도가 가운데 표시됩니다.

— 연출 —

PRODUCTION: SUBJECT & CASTING 여기에 피사체의 동작과 감정을 입력합니다. 영상 예시: “한 여성이 슬픈 표정으로 도자기 그릇을 들고 있다.”

— CINEMA STYLE —

여덟 가지 스타일 — Normal Hollywood (기본 선택) Korean Japanese Chinese Noir Neon-Punk Anime Style.

— Cast —

FACE ID CALIBRATION을 사용해 (LIKENESS PRIORITY: MAX, UPLOAD) 피사체 사진을 업로드하고, OUTFIT REFERENCE (ADD IMAGE) 의상 사진을 추가합니다. 내레이션: “피사체 사진과 의상 사진을 더하면 키 이미지가 완성됩니다.”

— 생성 및 저장 —

오른쪽에 세 개의 버튼이 있습니다: DOWNLOAD FREEZE FRAME (참조 프레임 저장) · GENERATE_STILL_1K (흰색) · GENERATE_STILL_2K (HQ) (남색). 2K 결과가 영상에 쓰이는 최종 키 이미지입니다.

— 용어집 · UI 용어 —

버튼과 필드 용어집

흔한 실수와 팁

데모 영상에서 소개된 여섯 가지 실전 팁입니다.

— 팁 01 —

이미지를 업로드하면 홈 버튼이 “Create Space from Description” → “Analyze Space”로 바뀝니다. 이 라벨 변화는 정상이며, 그대로 선택해 “Confirm Room Layout”으로 넘어가면 됩니다.

— 팁 02 —

깔끔한 벽 전개도를 얻으려면 네 모서리 모두를 바닥과 벽의 경계에로 맞추세요. 천장 서까래가 너무 많이 들어오면 점을 아래로 내리면 됩니다.

— 팁 03 —

방 크기를 바꿔도 소품은 그대로 남습니다. 'Apply Room Size · No Additional Generation' 는 재생성 없이 비율만 적용하므로, 크레딧 걱정 없이 여러 값을 시험해 볼 수 있습니다.

— 팁 04 —

브러시는 바꾸려는 오브젝트보다 조금 크게 잡은 뒤 마스크를 칠하세요. 크기는 BRUSH 40PX 슬라이더로 조정합니다. 잘못 칠했다면 CLEAR 로 지우면 됩니다.

— 팁 05 —

오브젝트 배치에는 INPAINT를, 벽지처럼 면 전체를 바꿀 때는 참조를 연결하고 지시를 함께 쓰는 방법을, 결과가 어색하면 REGEN을 사용하세요. 도구마다 역할이 다르니 목적에 맞게 고르면 됩니다.

— 팁 06 —

키 이미지는 다음 순서로 만듭니다: 구도(프롬프트) → 피사체 사진 → 의상 사진. FACE ID와 OUTFIT을 함께 쓰면 얼굴과 의상 모두 유지됩니다.

최종 요약

네 개의 데모 영상에서 확인한 Turn의 모든 것.

Turn이란

Turn은 이미지 한 장 또는 설명으로 자유롭게 회전하는 360° 3D 가상 스튜디오 세트를 만드는 로컬 시네마틱 워크스페이스입니다. 실내 벽은 원근 보정되고, 실외 장면은 풍경·하늘·바닥의 큐브맵으로 확장됩니다.

영상에서 확인된 핵심 흐름

① FRONT 이미지 업로드 → Analyze Space → Confirm Room Layout(치수 확인 및 네 모서리 드래그) → 360° 공간 생성. ② 3D Preview에서 회전·줌하며 필요에 따라 방 크기나 카메라를 조정하고 벽을 편집(참조 이미지, 브러시, INPAINT / REGEN / REPLACE). ③ FREEZE FRAME → 단계 3에서 연출, CINEMA STYLE, 피사체·의상 사진 추가 → GENERATE_STILL → 키 이미지.

출력물 이해하기

Freeze Frame = 연출을 더하기 전 참조 구도를 캡처한 것(DOWNLOAD FREEZE FRAME). Final Still = 피사체, 스타일, 조명이 적용된 최종 이미지(GENERATE_STILL_1K / 2K HQ). 용도가 달라 내려받기 버튼도 따로 있습니다.

참고

이 가이드는 네 개의 데모 영상(About Turn 18초 · Adjusting Room Size 10초 · Editing Objects 27초 · Creating a Key Image 7초)의 화면과 내레이션을 바탕으로 작성했습니다. “Generate the Desired View”를 포함한 일부 라벨은 영상 해상도 때문에 추정한 것입니다.
