01
— 개요 · 도구 소개 —

Blocking Board가 해결하는 것

영상을 생성하기 전에 배우·공간·카메라가 충돌하지 않는지 확인하는 디지털 리허설 도구.

1
PLAN / 평면도
위치·경로·소품을 정리합니다.
2
PREVIEW / 3D
장면을 재생해 높이·시선·충돌을 확인합니다.
3
OUTPUT / 컷
결과를 타임라인과 프롬프트로 이어갑니다.
— 메모 01 · 핵심 개념 —

영상을 생성하기 전에 Blocking Board는 배우·공간·카메라가 충돌하지 않는지 확인하는 것을 가능하게 합니다 — 디지털 리허설 도구입니다.

— 메모 02 · 순서 —

평면도에서 위치와 경로를 설정하고 3D 스테이지에서 높이와 시선을 검토합니다. 결과는 컷·타임라인·프롬프트로 이어집니다.

「돌리기 전에 시각적으로 검토하고 조정한다」

자동 생성 자체보다 중요한 것은, 검토 가능한 중간 상태를 만드는 것입니다.

대본→평면도→3D 스테이지→컷 / 출력

02
— 설치 · 로컬 웹 앱 —

앱을 실행하고 작업 공간을 준비합니다

Blocking Board는 로컬 웹 앱입니다. 시작하는 데 필요한 것은 프로젝트 폴더와 브라우저뿐입니다.

— 단계 01 · 의존성 설치 —

저장소 루트에서 다음을 실행합니다 npm ci.

— 단계 02 · 빌드 —

npm run build — 앱 번들을 빌드합니다.

— 단계 03 · 로컬 서버 —

node tools/static-server.js 8010 를 실행하고, localhost:8010 를 브라우저에서 엽니다.

# 저장소 루트에서 실행
$ npm ci
$ npm run build
$ node tools/static-server.js 8010

# 브라우저에서 열기
http://localhost:8010

파일을 더블클릭해 여는 대신 로컬 HTTP 서버를 사용하세요.

— 단계 01 · 장면 —

대본과 프롬프트를 입력해 초안을 만듭니다. 공간과 소품을 다듬은 뒤 배우의 시작 지점과 경로를 설정합니다.

— 단계 02 · 검토 —

3D 스테이지에서 장면을 재생해 충돌과 시선 문제를 확인합니다. 문제를 찾았다면, 스테이징 단계로 돌아가 수정합니다..

홈 화면과 상단 바

Chapter 06공간과 경로

06
— 스테이징 · 공간 / 배우 / 경로 —

공간을 배치한 뒤 배우와 경로를 놓습니다

자동 배치는 출발점입니다. 공간을 다듬고 배우를 놓은 뒤 평면도에 경로를 그립니다.

— 단계 01 · 공간 —

왼쪽 패널에서 Add Object를 선택하고 카테고리를 골라 벽·문·창·가구를 평면도에 배치합니다.

— 단계 02 · 배우 —

배우를 배치하고 이름·체형·시작 위치·방향을 지정합니다.

— 단계 03 · 경로 —

평면도에서 웨이포인트를 클릭해 경로를 그립니다. Enter 로 확정, Esc 로 취소합니다.

— 단계 04 · 세부 조정 —

3D 도구에서, E 로 이동 · R 로 회전 · T 로 크기 조정. 평면도 그리드 1칸 = 1 m — 이것을 스케일 기준으로 사용합니다.

Chapter 07카메라
P. 007
07
— 카메라 · 멀티캠 —

카메라와 숏 사이즈를 설계합니다

각 카메라의 역할을 정하고 숏 사이즈·화각·추적 대상·움직임을 설정합니다.

— 메모 01 · 카메라 관리 —

카메라 패널에서 CAM1~4를 관리합니다. 각 카메라마다 숏 사이즈, 화각(FOV), 추적 대상, 움직임을 설정합니다.

— 메모 02 · 숏 사이즈 —

WIDE 는 배우 전신을 담고, MEDIUM 는 대화를 담당하며, CLOSE 는 리액션을 잡고, OTS 는 어깨 너머 뷰에 사용합니다.

— 메모 03 · 패널 설정 —

렌즈와 FOV, 추적 대상, 카메라 움직임, 각도, 높이 Z(m)를 확인합니다.

— Tip —

렌즈 수치를 고민하기 전에, 그 숏이 무엇을 보여줘야 하는지를 먼저 정하세요..

08
— 시간 · 컷과 대사 —

타임라인에 컷과 대사를 배치합니다

컷은 이야기 시간의 단위입니다. 배우 동작과 대사가 어색하게 겹치지 않도록 배치합니다.

— 단계 01 · 컷 —

마스터 타임라인에 컷을 추가하고 길이와 카메라를 설정합니다. 컷 사이의 빈 구간과 연속성 경고를 확인합니다.

— 단계 02 · 대사 —

대사는 별도 트랙에서 관리합니다. 누가 언제 말하는지 확인하고, 대사를 액션 구간에 맞춥니다.

— 단계 03 · 재생 —

하단 타임라인의 재생·일시정지·스크럽을 사용합니다. 특정 프레임에서 자세를 확인하고 전체 움직임에서 충돌을 검토합니다.

— 메모 · FPS와 커브 —

FPS는 최종 영상의 속도를, 커브는 움직임 속도의 변화를 조정합니다.

프리비즈와 고급 도구

Photo Path로 실제 로케이션에 맞추고, 대안 연출안을 나란히 비교합니다.

— 단계 01 · 프리비즈 —

장면을 재생하고 프리비즈 영상(WebM)을 내보냅니다. 최종 생성 전에 팀과 타이밍과 프레이밍을 맞추는 데 사용합니다.

— 단계 03 · 연출안 A/B —

연출안을 저장하면 카메라나 경로를 바꿔도 원래 안을 보존할 수 있습니다. 새 시도를 하기 전에 원래 안에 이름을 붙이고 목적을 적어 둡니다.

— Note —

프리비즈 영상은 최종 산출물이 아니라 , 블로킹과 컷을 합의하기 위한 중간 결과입니다.

13
— 요약 · 마무리 —

좋은 블로킹은 다음 단계 담당자에게 확신을 줍니다

대본에서 내보내기까지, 한 장면을 검토하는 절차의 정리.

한 장면의 순서

대본 → 공간 → 배우 → 카메라 → 타이밍 → 점검 → 내보내기. 문제가 생기면 앞 단계로 돌아가 수정합니다.

장면에 들어갈 때

사건과 액션을 시간 구간으로 쓰고, 배우·소품·카메라에 일관된 이름을 사용합니다.

검토할 때

평면도에서 경로를 계획하고 3D로 장면을 재생합니다. 시선·충돌·연속성 경고를 해소합니다.
