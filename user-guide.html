Introduction

왜 XCONDA인가?

기존 AI 생성은 컷마다 배경이 바뀌고 인물이 달라지는 문제가 있습니다. XCONDA는 공간 고정 → 인물 고정 → 연출 고정의 3단계로 시네마틱 일관성을 보장합니다.

🧱
공간 일관성
Turn으로 360° 큐브맵을 고정하면 앙각·부감·동선이 바뀌어도 같은 방, 같은 거리에서 촬영한 것처럼 유지됩니다.
🎭
캐릭터 일관성
Face ID Source + Wardrobe Ref + 캐릭터 시트(3뷰)로 9컷 내내 같은 배우, 같은 의상을 유지합니다.
🎥
연출 일관성
Director Style, Art Style, Camera/Optics 프리셋으로 광고·영화 문법을 일관되게 적용합니다.
Quick Start

가입부터 첫 9컷까지 4단계

처음이라면 Director's Cut으로 시작하는 것을 추천합니다. 가장 빠르고 직관적입니다.

STEP 01
계정 만들기

xconda.ai 접속 → 가입 → 워크스페이스가 즉시 열립니다. 별도 설치 없음.

STEP 02
크레딧 준비

Starter V1 $6.90부터 1회 결제. 구독 아님. 툴별 소모량은 생성 버튼에 표시됩니다.

STEP 03
툴 선택

처음 → Director's Cut, 공간부터 → Turn, 인물 합성 → Cinematic Blender, 표정 → Expression

STEP 04
시나리오 → Generate

Year/Location/Scenario 입력 후 Generate. 마음에 안 드는 컷만 펜 아이콘으로 개별 재생성.

Core Workflow

프로가 쓰는 핵심 워크플로우

광고·브랜드 필름 제작 시 가장 많이 사용하는 5단계 파이프라인입니다.

① Turn사진 1장으로 360° 공간 고정, Freeze Frame 추출
→
② Blocking Board공간에 인물 동선·카메라 무브 배치, 연출 검증
→
③ Director's Cut / Art Director Pro9컷 시네마틱 스토리보드 생성, 캐릭터 고정
→
④ Video GeneratorSeedance 2.5 / Kling 3.0으로 영상화
→
⑤ UpscalerTopaz 2X/4X 업스케일, Face Enhancement
💡 팁: Turn은 0단계 필수 도구입니다. 공간을 먼저 고정하지 않으면 컷마다 방 구조가 바뀌는 문제가 발생합니다.
Core Studio

핵심 스튜디오 5종

XCONDA의 심장. 이 5개만 익혀도 광고 한 편을 완성할 수 있습니다.

🔄

Turn (턴)

Core

사진 1장으로 360° 공간 생성 및 배경·공간 고정 — 컷마다 방이 바뀌지 않게 만드는 0단계 도구

  1. Reference 단계에서 Front / Left / Right / Back 이미지를 넣거나 Description만 작성
  2. Generate로 360° HDRI 큐브맵 생성, 3D Preview에서 카메라 시점 지정
  3. 필요하면 Cube Map Inpaint로 방향별 디테일 수정 (Brush / Replace / Clear / REGEN)
  4. 원하는 시점을 Freeze Frame으로 저장
  5. Production에서 인물·액션·조명·Cinema Style과 캐스트 레퍼런스 설정해 최종 컷 완성
⚡ Reference Generate는 크레딧 소모. Inpaint 마스크는 대상보다 약간 크게 잡는 것이 안정적입니다.
📖 Cube Map 5가지 편집 도구 자세히 보기 ▼
  • Brush: 수정할 영역에 빨간 마스크. 작은 소품·얼굴은 작은 브러시, 벽·바닥은 큰 브러시
  • Replace with: 선택 영역에 추가/변경할 내용 텍스트 입력
  • Inpaint: 프롬프트 있으면 오브젝트 추가·변경, 비우면 오브젝트 제거
  • Clear: 마스크만 지움, 결과는 유지
  • REGEN: 선택 방향 화면 전체 재생성 (구성이 완전히 어색할 때만)
🎨 Cinema Style 8종 ▼
  • Normal, Hollywood, Korean, Japanese, Chinese, Film Noir, Cyberpunk, Anime — 같은 Freeze Frame도 스타일에 따라 색감·조명·대비 완전히 달라짐
🧭

Blocking Board (블로킹보드)

Core

공간 내 인물·카메라 동선 및 공간 연출 블로킹 — 씬 간 시각적 연속성 설계

  1. Turn에서 고정된 360° 공간 또는 배경 이미지 불러오기
  2. 공간 뷰포트 위에 캐릭터 위치와 이동 동선 배치
  3. 카메라 시점(샷 앵글, 화각, 이동 궤적) 설정
  4. 씬별 인물과 카메라 공간 관계 검증 후 렌더링 단계로 전달
💡 프레임 좌/중/우 및 전경/중경/후경 배치를 명확히 하면 일관성이 극대화됩니다.
🗂️

FlexBoard (플렉스보드)

Core

시나리오 기반 9컷 스토리보드 생성 & 원하는 컷만 선택 재생성

  1. Standard(빠른 초안) 또는 Cinema Pro(고품질 최종) 엔진 선택
  2. Year, Location과 구체적인 시나리오 작성
  3. 감독 연출 스타일과 아트 스타일 프리셋 선택
  4. Generate로 3×3 9컷 그리드 일괄 생성
  5. 수정이 필요한 컷만 펜 아이콘 → 프롬프트 수정 → 개별 Regenerate (횟수 무제한)
🎬 전체 보드를 다시 만들 필요 없이 어색한 컷만 선택 재생성. Claude 스킬(xconda-new-prompt)로 10블록 프롬프트 고도화 가능.
🎬

Director's Cut

Most Popular

엔진·연출·아트 스타일로 완성하는 9컷 스토리보드 — 가장 많이 쓰이는 메인 툴

  1. Standard(Gemini 2.5 Flash, 4cr/컷) 또는 Cinema Pro(Gemini 3.1 Pro, 7cr/컷) 선택
  2. Year, Location, Scenario(최소 글자 수 충족) 입력
  3. Director Style 5종, Art Style 4종 중 선택
  4. Hero Product(제품) / Hero Muse(정면 모델 사진) 첨부 — 선택이지만 배경 없는 이미지일수록 일관성 ↑
  5. Generate → 9컷 그리드 → 개별 컷 펜 아이콘으로 재생성 → Download All
🎭 Director Style 5종 / Art Style 4종 ▼
  • Wes Anderson: 대칭, 파스텔, 동화적 미장센
  • Spike Jonze: 현실+환상 경계, 서정적 무드
  • Wieden+Kennedy: 강한 메시지, 브랜드 아이덴티티 중심
  • The Baker Brothers: 빠른 템포, 트렌디한 리듬감
  • Show Yanagisawa: 자연광, 여백, 일본식 미니멀
  • Live Action (Arri Alexa): 현실적 영화·광고 룩
  • Studio Ghibli: 따뜻한 판타지 애니메
  • Stop-motion Claymation: 수공예 질감
  • 3D Animation (Pixar): 대중적 캐릭터
🎨

Art Director Pro

Core

포커스 모드·캐릭터 시트·카메라로 만드는 일관된 9컷 — 인물 일관성 최강

  1. Dialogue(감정·표정) / Action(동작·동선) / Atmosphere(조명·색감) 중 포커스 모드 선택
  2. 시나리오에 Role Name 반드시 포함, Plate Product에 공간 구조 명확한 배경 업로드
  3. 캐스트별 Role Name, Face ID Source(밝고 정면 사진), Wardrobe Ref 설정
  4. Detect Face로 좌·정면·우 3뷰 캐릭터 시트 생성 (필수, 없으면 Generate 비활성)
  5. Camera 6종 + Optics 10종 선택 후 Generate → Preview 1~4 (최대 36장) → 업스케일/다운로드
⚠️ 시나리오 이름과 Role Name 철자까지 정확히 일치해야 합니다. 애니메이션 캐릭터 입력 시 실사화될 수 있음.
📷 Camera 6종 / Optics 10종 ▼
  • ARRI ALEXA 35: 17-stop, 광고·영화 표준
  • SONY VENICE 2: 부드러운 그림자, 감성적
  • RED V-RAPTOR: 초고해상도, 강한 대비
  • PANAVISION DXL2: 대형 포맷 깊이감
  • ARRIFLEX 16SR: 16mm 그레인, 빈티지
  • IMAX MKIV: 70mm 스케일
  • Cooke S4(따뜻·크리미), ARRI Signature Prime(현대적), Zeiss Ultra Prime(강한 대비), Canon K-35(빈티지 글로우), Panavision C-Series(블루 플레어), Hawk V-Lite(레트로), JDC Xtal(왜곡), Helios 44-2(소용돌이 보케), Angénieux Optimo(줌), Leica Summilux-C(자연)
Storyboard Tools

스토리보드 3종

이미지 한 장, 유튜브 링크, 키프레임 하나로 빠르게 콘티를 확장합니다.

🖼️

Scene Snap

이미지 1장 → 6키프레임 스토리보드. 63cr/회

  1. 필름 프레임 아이콘 클릭
  2. 분석할 장면 이미지 업로드
  3. Generate → KF 번호·숏 라벨·CAMERA/LENS 정보 포함 카드 생성
공간·인물·조명·오브젝트가 잘 보이는 이미지가 결과 구체적. 결과는 초안으로 보고 좋은 컷 저장 후 연출안 다듬기.
▶️

YouTube Ref

유튜브 링크 → 9씬 스토리보드. 시각적 톤·무드 기반

  1. 클랩보드 아이콘 클릭
  2. YouTube URL 입력 (썸네일·제목 자동 인식)
  3. (선택) Character References Body/Face 업로드
  4. Generate → SCENE 01~09, 연필 아이콘으로 개별 씬 Regenerate
⚠️ 원본 콘텐츠 맥락 정확 반영 아님. 시각적 톤·무드 참고용. 프롬프트는 장소+상황+분위기 구체적으로.
🎞️

Directors Sequence

키프레임 1장 → 연속 8씬 자동 생성

  1. 16번째 사이드바 아이콘 클릭
  2. KEY FRAME 업로드 (필수)
  3. (선택) Synopsis 입력, Directors Note 수정 (기본: high cinematic tension)
  4. Generate → SCENE 01~08 그리드
Camera · Angle

카메라·앵글 3종

촬영 장비 없이 앵글을 자유자재로. 3D 모델링 없이 직관적으로 시점을 바꿉니다.

⭕

SpinAngle

원=카메라 위치, 화살표=방향으로 포토리얼 뷰 생성. 6cr/회

  1. 원형 화살표 아이콘 클릭
  2. 이미지 업로드
  3. Circle로 카메라 위치, Arrow로 방향 그리기 (둘 다 초록 체크 필요)
  4. Generate
피사체 윤곽·공간감 분명한 이미지가 안정적. 모션블러·노이즈·복잡 배경은 품질 저하.
➡️

Arrow View

화살표 하나로 새로운 시점. 탑뷰·에어리얼 강점

  1. 오른쪽 화살표 아이콘 클릭
  2. 이미지 업로드 후 드래그로 화살표 그리기
  3. Generate → 원본+화살표(왼쪽) vs 결과(오른쪽) 비교
짧은 화살표=소폭 변화, 긴 화살표=대폭 변화. Clear Arrow로 화살표만 재그리기 가능.
📐

Auto Angle Generator

1장으로 최대 34가지 카메라 앵글 자동 생성

  1. 각도 삼각형 아이콘 클릭
  2. 원본 업로드 (흰 배경·중앙 배치·고해상도·정면·단일 피사체 권장)
  3. 생성할 앵글 선택 (Select All/Deselect All 지원) → Generate Angles
Eye Level, High/Low, Aerial, Top View, Close Up, Side Profile, OTS, POV, Dutch Angle, Silhouette 등 34종.
Image Editing

이미지 편집 4종

의상·표정·얼굴·배경을 바꾸되 인물 정체성과 포즈는 그대로 유지합니다.

👕

ClothSwap

칠하고 올리면 의상 교체. 6cr/회

  1. 티셔츠 아이콘 클릭
  2. Source Image 업로드 (전신·정면·단색 배경 권장)
  3. Brush Size 조절해 바꿀 옷 영역 칠하기 (옷깃·소매·밑단 포함)
  4. Reference Clothing 업로드 (마네킹·평면 컷 권장) → Generate
얼굴·손·헤어·배경은 칠하지 말 것. 큰 브러시로 안쪽 채우고 작은 브러시로 외곽 정리하는 2단계가 효율적.
😊

Expression Transformer

텍스트로 표정 변경, 정체성은 그대로. 6cr/회

  1. 웃는 얼굴 아이콘 클릭
  2. 원본 이미지 업로드
  3. Prompt에 표정 입력: gentle smile, surprised, serious cinematic 등
  4. (선택) Camera View/Shot Size/Angle 설정 → Generate
preserve identity, preserve clothing 프롬프트로 인물·의상 유지. 표정·시선·구도·조명 한 번에 너무 많이 바꾸면 인물성 약화.
🔄

Face Swap

포즈·의상·배경 유지, 얼굴만 교체. 6cr/회

  1. Face Swap 열고 Nano Banana 2 / Nano Banana 모델 선택
  2. Original image 업로드
  3. Brush Size 조절해 교체할 얼굴 영역 마스크
  4. Swap to image에 정면/3/4 얼굴 업로드 → Generate → OK
🛡️ 본인 또는 동의 받은 얼굴만 사용. 마스크는 얼굴 주변 너무 좁거나 넓지 않게. 공유 전 권리 확인 필수.
🌄

Cinematic Image Blender

인물 + 배경 → 시네마틱 합성. 조명·색감 자동 매칭

  1. 풍경+반짝임 아이콘 클릭
  2. Upload person Image (배경 없거나 단색일수록 정확도 ↑)
  3. Upload Background Image
  4. Prompt에 포즈/조명/카메라 느낌 구체적으로 (최대 2500자) → Generate
좋은 예: "Standing by the window, rim lighting, emotional expression" / 피해야 할 예: "합성해줘", "예쁘게"
Generate · Enhance

생성·보정 4종

색보정부터 이미지·영상 생성, 고해상도 업스케일까지 마무리 도구들.

🎨

CineGrade AI

영화 스틸의 색감을 내 사진에. 구도 유지, 톤만 변경. 6cr/회

  1. 마법봉 아이콘 클릭
  2. Your Photo(원본) 업로드 — 노출 안정적인 사진 권장
  3. Reference Movie Still(색감 기준) 업로드 — 웜/콜드/시네마틱 방향 분명한 컷
  4. Generate → 얼굴 톤·의상 색·배경 밝기·전체 대비 4가지 체크
왼쪽=무엇을, 오른쪽=어떤 톤으로. 레퍼런스 바꿔가며 생성하면 톤 후보 카드 누적 비교 가능.

Image Generator

7가지 AI 모델 한곳에서. Nano Banana, Kling, Seedream 등

  1. 첫 번째 사이드바 아이콘에서 Image Generator 열기
  2. 모델 선택 (레퍼런스 제한 확인): Banana 2/Pro 14장, Kling O1 10장, Z Image 미지원, Grok 1장/Pro 3장

Video Generator

Veo 3.1, Runway, Kling 3.0, Seedance 2.0 등 멀티 엔진. 50cr/회, 멀티샷 180cr

  1. Tools 메뉴 → 2번째 아이콘 Video Generator
  2. Models 드롭다운에서 엔진 선택
  3. Text to video: Prompt + Negative Prompt + 해상도/길이/비율
  4. Image to video: Start/End 프레임 업로드, Reference Mode(Seedance 전용) 선택
  5. Multi-Shot(Kling 3.0 전용): 샷별 길이 설정, +Add Shot, 총 15초 제한
모델별 강점: Veo 3.1=Audio Sync, Seedance=Reference Mode, Kling=Multi-Shot. 목적에 맞춰 모델 먼저 선택.

Upscaler

Topaz·Xconda 모델로 2X/4X 디테일 업스케일. 8cr 예시

  1. Upscaler 열고 Topaz(세밀) / Xconda(빠름) 선택
  2. 이미지 업로드, 2X(웹용) / 4X(고해상도 납품) 선택
  3. Topaz 옵션: Enhance Model(Standard/High Fidelity/Low Res/CGI/Text), Subject Detection, Output Format(JPG/PNG), Face Enhancement(중간값 시작 권장), Creativity(얼굴은 낮음~중간)
  4. Generate → OK → Latest Result 다운로드, History에서 비교
Face Enhancement와 Creativity를 동시에 높이지 말 것. 공유용 JPG, 합성·후편집용 PNG.

Pro Tips

프로가 알려주는 10가지 팁

1. Turn 먼저, 나머지는 나중에
어떤 광고든 공간을 먼저 고정하세요. 360° 큐브맵이 있으면 이후 모든 툴의 일관성이 3배 이상 좋아집니다.
2. 배경 없는 레퍼런스가 정답
Hero Product/Muse, Face ID, ClothSwap 참조 이미지는 배경이 없거나 단색일수록 AI 인식 정확도가 높습니다.
3. Role Name 철자 일치 필수
Art Director Pro에서 시나리오의 "Mina"와 Role Name의 "Mina"가 한 글자라도 다르면 얼굴·의상 연결이 끊깁니다.
4. 선택 재생성을 적극 활용
전체 9컷 중 1컷만 어색하면 전체를 다시 만들지 마세요. 펜 아이콘 → 프롬프트 수정 → 해당 컷만 Regenerate. 횟수 무제한.
5. 영어 프롬프트가 더 정확
Image Generator, Video Generator는 영어 프롬프트일 때 텍스트 이해 정확도가 높습니다. 장면→행동→카메라/조명 순서로 작성.
6. 마스크는 대상보다 약간 크게
Turn Inpaint, ClothSwap, Face Swap 모두 마스크를 대상보다 약간 크게 잡아야 경계가 자연스럽습니다.
7. Face Enhancement는 중간부터
Upscaler에서 얼굴 보정 시 너무 높이면 인공적으로 보입니다. 중간값에서 시작해 점진적으로 높이세요.
8. 짧고 명확한 화살표
Arrow View/SpinAngle에서 짧고 방향이 명확한 화살표 + 깔끔한 원본이 가장 안정적입니다.
9. 표정은 하나씩, 카메라는 나중에
Expression에서 표정·시선·구도·조명을 한 번에 바꾸면 인물성이 약해집니다. 표정만 먼저 테스트하세요.
10. Video는 모델을 먼저 고르기
Veo=오디오 싱크, Seedance=레퍼런스 모드, Kling=멀티샷. 목적에 맞는 엔진을 먼저 선택해야 크레딧을 아낄 수 있습니다.
FAQ

자주 묻는 질문

Q. 구독인가요? ▼
A. 아닙니다. 모든 팩은 1회 결제입니다. 구독 플랜은 곧 출시 예정이며 공지사항에서 안내됩니다.
Q. Turn 없이 바로 Director's Cut 써도 되나요? ▼
A. 가능합니다. 다만 컷마다 공간이 미세하게 바뀔 수 있습니다. 광고·브랜드 필름처럼 공간 일관성이 중요한 경우 Turn으로 먼저 고정하는 것을 강력 권장합니다.
Q. 얼굴·의상이 컷마다 바뀌어요. ▼
A. Art Director Pro를 사용하세요. Face ID Source에 밝고 정면 얼굴, Wardrobe Ref에 의상 이미지를 넣고 Detect Face로 3뷰 캐릭터 시트를 반드시 생성해야 합니다. Role Name 철자도 시나리오와 정확히 일치시켜야 합니다.
Q. 크레딧이 부족하다고 나와요. ▼
A. 스튜디오 우측 상단 크레딧 잔액을 확인하고, 필요하면 xconda.ai에서 팩을 추가 구매하세요. 툴별 소모량은 생성 버튼 옆에 표시됩니다.
Q. Face Swap, ClothSwap 사용 시 주의사항은? ▼
A. 본인 또는 명시적 사용 동의를 받은 얼굴·의상만 사용해야 합니다. 공개 공유 전 결과와 권리를 반드시 확인하세요.
Q. 영어로만 프롬프트 써야 하나요? ▼
A. 한글도 동작하지만, Image Generator, Video Generator, Turn Production 등에서는 영어 프롬프트가 모델 이해 정확도가 더 높습니다.
