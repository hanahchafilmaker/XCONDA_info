FLEXBOARD でストーリーボードを作る 7 ステップ - AI 動画制作の流れ

日本語 · XCONDA Hub

この記事で学ぶこと：シナリオをカットごとのストーリーボードにして、問題のあるカットだけを選んで直し、Seedance 2.5 に渡す方法

こんな方へ：AI 動画を初めて作る方、動画を回してクレジットを無駄にした経験のある方

用意するもの：XCONDA アカウントとクレジット、シナリオの 1 場面、あれば Turn で作った背景画像。画像生成・再生成のボタンには必要なクレジットが画面に表示されます。

この記事は「AI 動画制作の流れ」連載のストーリーボード編です。前回の記事「XCONDA Turn で 360 度のセットを作る」で作った背景とキーイメージをここで使います。

FLEXBOARD はどこにありますか

XCONDA の左メニューから Studio に入り、Storyboard を開くと FLEXBOARD のカードが見えます。「Seedance 2.5 に最適化されたストーリーボードツール」と書かれたカードです。カードを押して New Project を選ぶと始まります。

ステップ 1：プロジェクト設定

画面上部に作業ステップが 3 つのボタンで表示されます。

  1. Project settings：プロジェクトの基本設定
  2. Scene Settings：シナリオ、人物と背景、カット数の設定
  3. Edit Panel：できたカットを見て直す

この記事のステップ 1〜5 が前の 2 つのボタン、ステップ 6〜7 が Edit Panel にあたります。まず 3 つを決めます。

  • 作業方法
  • 画像モデル：画面左上のドロップダウンで、カット画像を描くモデルを選びます。現在選べるモデルは 4 つです。
  • プロジェクト名：後で一覧から探しやすい名前にします。例：「ウェブドラマ_1話_大庁マルシーン」

ステップ 2：シナリオ、ジャンル、雰囲気を書く

Scenario 欄に場面を書きます。「誰が、どこで、何を、どんな感情で」が入っているとカットを検討しやすくなります。出来事が複数あるときは順番に書きます。

たとえばこんな感じです。

雨の夜、韓屋（ハノク）の大庁マル。スヨンが割れた陶磁器の破片を持って立っている。門の方から足音が聞こえ、スヨンは破片を背中に隠す。扉が開いて母が入ってくる。二人は言葉もなく見つめ合う。

次に Genre（例：Suspense）と Tone / Mood（例：Tense）を選び、Save project で保存します。

ステップ 3：人物と背景を登録する（Reference Assets）

カットが変わっても同じ人物、同じ場所が出るようにするステップです。Reference Assets の領域に Cast（人物）カードと Background（背景）カードを登録します。

  1. Add Cast を押して人物カードを作ります。カードごとに @image1、@image2 のような名札（トークン）が自動で付きます。
  2. カードに顔の画像と分かりやすい名前を入れます。例：スヨン、母
  3. 繰り返し出る小道具もカードとして登録できます。例：割れた陶磁器
  4. 背景カード（Background）を追加します。前回の記事で Turn で作った空間の画像をここに入れるとよいです。

トークンの役割：カット説明の中に「@image1」のように表示され、このカットに誰が出るかが一目で分かります。動画プロンプトでも同じ方式で人物を指します。

注意：人物は一人につきカード 1 枚で登録してください。カードを差し替えたり削除した後は、トークン番号とカット説明がまだ合っているか再確認が必要です。

ステップ 4：カット数とカットの長さを決める

  • Number of Panels：カット数を決めます。画面の例は 9 カットです。
  • Shot Length：1 カットの長さを決めます。4 秒から 30 秒の間で調整できます。

たとえば 9 カット × 15 秒に設定すると、単純合計は約 2 分 15 秒です。実際の完成尺はその後の動画作業で変わります。

カット数は場面が変わる地点を基準に決めてください。上の例なら「陶磁器を持つスヨン／足音／隠す手／扉が開く／母の登場／見つめ合う二人」のように分けられます。

ステップ 5：画像より先に文字で確認する（Text Preview）

画面下の黄色い Text Preview Generate ボタンを押すと、画像を作る前にカットごとの文字コンテが先に出ます。各 CUT カードで 3 点を確認します。

  • 場面説明が意図した順番で出ているか
  • @image トークンが正しい人物を指しているか
  • 下の SFX（効果音）の説明が場面の雰囲気に合っているか

カットの順番や人物、場面転換が不自然なら、画像を作る前にシナリオやカット数に戻って直します。文字の段階で直すのがいちばん速いです。

ステップ 6：Edit Panel でカットを確認する（Panel 表示と Sheet 表示）

画像を生成すると Edit Panel の段階に進みます。モデル選択の隣の Panel / Sheet ボタンで見方を切り替えられます。

表示画面いつ使うか
Panelカットごとにカード 1 枚。画像の下に Edit ボタン、場面説明、セリフ（Dialogue）、効果音（SFX）が並ぶカットを 1 つずつ読んで直すとき
Sheet説明なしでカット画像だけを大きく 1 枚にまとめて表示全体の流れを一目で見るとき

まず Sheet で全体の流れを見ます。 文字なしで絵だけを続けて見ると、実際の動画のようにカットがつながるか判断しやすくなります。

  • カットの順番が入れ替わったり抜けた場面はないか
  • 前後のカットが自然につながるか（衣装、小道具、照明、視線の方向）
  • 同じ人物がカットごとに同じ顔で出ているか

画面右上には 3 つのボタンがあります。

  • Download CUT ZIP（Panel 表示）／Download Sheet（Sheet 表示）：カット画像をまとめて、またはシート 1 枚でダウンロードします。チームやクライアントにコンテを共有するときに使います。
  • Regenerate images：画像を作り直します。ボタンに必要なクレジットが表示されるので、押す前に確認してください。
  • Clear Sheet：シートを空にします。元に戻しにくいので、ダウンロードしてから使うのが安全です。

ステップ 7：問題のあるカットだけを選んで直す

うまく出たカットはそのままにし、問題のあるカットだけを直します。Panel 表示で直すカットのカードの Edit を押すと、そのカットだけを個別に修正できます。カットカードには次のツールがあります。

ツール役割
Editクイック修正ウィンドウを開く
+カットで使う要素を追加
ゴミ箱カットを削除
下／上の矢印カット画像をダウンロード／外部画像に差し替え

上の矢印（アップロード）を使うと、Turn で作ったキーイメージをそのカットに直接入れることもできます。プロンプトでは出にくい構図を解決するときに便利です。

クイック修正（Quick Edit）

  1. 直すカットの Edit を押し、ウィンドウ上部のカット番号（例：CUT 04）が合っているか確認します。
  2. 必要なら Reference images に参考画像を追加します。
  3. Edit prompt に変える内容を一文で書きます。@トークンで人物を指せます。
  4. 対象カットと指示内容、クレジットの案内を確認して Apply edit を押します。

指示文のコツ：変えることと残すことを一緒に書いてください。例：「眼鏡だけ変えて、姿勢と背景はそのまま」 例：「@image1 の表情だけ驚いた表情に、手に持った陶磁器と背景はそのまま」

詳細修正（Detailed Edit） はカメラを変えたいときに使います。右側で 3 つを調整します。

  • Shot Size：画面にどれだけ収めるか（例：Extreme Wide Shot、Close-up）
  • Camera Angle：カメラの高さと傾き（例：Low Angle、Dutch Angle）
  • Camera Movement：カメラの動き（例：Handheld、Track Out）

画面の例では「POV・Low Angle・Handheld」だった緊張感のある寄りの構図を「Extreme Wide Shot・Dutch Angle・Track Out」に変え、広く傾いた画面でカメラが後ろに引く構図に作り直しました。設定を確認して Regenerate を押します。このときも画面に表示されるクレジットを確認してください。

参考画像の順番を変える カット生成に使われる人物と背景のカードはリストで管理されます。人物は人物同士、背景は背景同士でドラッグして順番を変えられ、Reset to automatic selection を押すと既定の選択に戻ります。順番を変えた後はカット画像を再生成しないと反映されません。

Seedance に渡す前の最終チェック

ストーリーボードが完成したら動画の段階に進みます。渡す前に以下を確認してください。

  • Sheet 表示でカットが自然につながるか確認したか
  • すべてのカットで画像と説明が合っているか
  • 人物トークンがカットごとに正確か
  • 抜けたカットはないか
  • カットの長さ、画面サイズ、カメラアングル、カメラの動きがカットの意図に合っているか

ここで確認したカット画像が動画プロンプトの基準になります。構図を直すコストはこの段階がいちばん小さいです。動画に進んだ後に構図を直すには、動画を何度も回し直す必要があるからです。

よくある失敗

  • 文字コンテを飛ばしていきなり画像を作る：カット順が違うまま画像を作ると、作り直しになります。
  • 同じ人物を複数のカードで登録する：トークンが分かりにくくなり、顔が混ざることがあります。
  • 修正指示に変えることだけを書く：残すことを書かないと、他の部分まで変わる場合があります。
  • うまく出たカットまで再生成する：問題のあるカットだけを選び、Panel 表示の Edit で直してください。
  • Panel 表示だけで確認する：文字を読みながらだと、絵が実際につながるかを見落としやすいです。Sheet 表示で絵だけを続けて見る段階を必ず入れてください。
  • 途中で画像モデルを変える：カットごとに絵の雰囲気が変わることがあります。
